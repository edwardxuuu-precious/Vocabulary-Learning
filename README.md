# 单词游乐园

给 6–8 岁、中文母语、英语零基础孩子使用的 Windows 本机网页应用。家长准备词书，孩子通过英中自动讲解、图片、发音和随机游戏学习；可自主完成录音挑战，再由家长集中核验。成长页按真实学习和测试记录汇总，不提供发音评分。

## 启动

需要 Node.js 24。第一次在项目目录运行：

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd start
```

打开 [本机页面](http://127.0.0.1:8787)。日常双击 **启动单词游乐园.cmd**，结束时双击 **停止单词游乐园.cmd**。关闭网页不会停止后台服务；修改 `.env` 后先停止再启动。开发命令是 `npm.cmd run dev`，网页位于 [5173](http://127.0.0.1:5173)。

桌面入口：运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install-desktop-shortcut.ps1`，会在当前 Windows 桌面创建带大黄蜂图标的 **单词游乐园** 快捷方式。双击自动启动本机服务，再用 Windows 默认浏览器打开正式入口 `http://127.0.0.1:8787/`；服务已运行时直接打开。项目移动后重新运行安装命令，更新快捷方式路径。

当前继续在本机使用。云端部署已按用户要求暂缓，未创建AWS资源或修改DNS；草案保留在独立工作区，说明见 [部署核验记录](docs/AWS_DEPLOY.md)。

首页突出 **开始玩** 和 **家长空间**。点击开始进入 **学习大厅**，可推荐学习、自己选词或挑战测试，有未完成内容时可继续上次；另有 **伙伴图鉴**、**我的成长**。伙伴图鉴中点开任一角色，可查看大图及约200字中文简介，左右按钮切换伙伴；手机支持滚动阅读。没有可学词书时显示准备提示，不会自动进入示例。

## 家长备课

1. 首次进入家长空间，设置并确认自己的 6 位数字 PIN；以后每次进入需验证，连续输错 5 次暂停 30 秒。
2. 粘贴英文，每行一个单词或短语，也支持文件导入和中英两列。点击 **让 Codex 补全**，审核中文、词性、多义提示和配图思路；可修改、停止和补缺，草稿不会直接创建正式词书。
3. 点击 **确认词义并准备素材**，保存停用的词书，自动缓存发音并排队生图。成功素材保留；网络、认证或额度失败如实显示，由家长决定补缺或重试。
4. **审核图片** 支持放大、分页选择、批量批准和重画。批准只针对所见版本，重画后仍需重新审核。
5. 显式 **给孩子学习**；至少一词准备好时，可 **先学已备好的 N 个词**。交付词必须有批准图片和发音缓存，图片审核本身不会自动启用词书。

12 个内置词属于停用的开发示例，家长可明确开启体验。主题变更、导入失败和重画不会清空已批准图片或学习记录。

## 学习与成长

学习大厅提供 **推荐学习、自己选词、挑战测试**。未完成的轮次单独保存，选择其他词不会覆盖旧进度；点 **继续上次** 恢复冻结的词序、游戏和步骤。完成页显示 **这一轮完成啦**，可以再练一轮、自己选词、挑战本轮或返回大厅。

新词按词书创建顺序、批内录入顺序推进；复习跨所有已交付词书，优先到期和弱项，同优先级混合批次。默认每日推荐最多 **3 个新词**、每轮最多 **6 个复习词**、约 **10 分钟**，受任务预算和积压约束。上海日期内已接触的新词及未完成轮次的新词预留共同占用自动推荐额度，开多轮不重复追加。当天推荐做完仍可混合练旧词，旧词不足时允许重复；额外练习不推进或推迟原复习日期。

**自己选词** 用图片卡多选，可跨词书，按批次、未学或学过筛选；每轮最多5词，并受当前时长预算限制，超出时提醒少选，不偷偷删词。旧词默认 **直接练习**，也可选 **重新认识** 完整重学；未学词始终先认识。主动选新词可超过推荐额度，仍计入当天接触数量。重学不清空历史、不改正式成绩、不刷复习级别。

认识页自动完成 **英文 → 中文释义 → 英文 → 完整图片 → 英中复述 → 进入练习**。词性以小号浅蓝标签与加深的释义同排显示；长词自适应，短语换行。静音或播放失败会显示真实状态并按阅读节奏继续；暂停、离开或切后台取消推进。讲解只完成认识步骤，不写独立答对或掌握证据。

当前有 **50 种已实现玩法**，按目标技能、词数、已审核素材及设置筛选后随机安排；题目、选项、拼图和字母棋盘固定，刷新后可继续。每组最多3类，每轮最多引入1种新机制；故事、编程、双词组合、数量订单与双词分料按两个目标计步。新增30种均只记练习，仍保留原来的客观听辨检查。亲子、进阶情境和拼写默认关闭。

新开的新词学习固定覆盖 **认、听、读**：认识 → 看英文认意思 → 听音找图 → 看图辨音 → 看英文自己读 → 看图回忆；拼写按设置另加。游戏在对应目标内随机，同轮最多3类，不删目标。按每小任务30秒估算题量，时间不足减少新词数量。认词先不播放英文，听辨先听再选；朗读先保存录音，再开放示范对比，已录、跳过、提示后认对与独立答对分别保存。家长在学习记录中分列查看认、听、读；朗读不自动判对，正式读对仍以挑战测试家长核验为准。复习优先答错、提示或跳过的到期目标，再练尚未核验和其他到期目标；旧会话按原计划恢复。

本次认听读新版体验：[打开完整一轮](http://127.0.0.1:8813/__qa)。使用独立示例档案和真实麦克风模式，原8805体验保留。录音设备受浏览器与系统授权约束，可在Chrome打开同一地址试录。

家长在 **家长空间 → 学习记录** 中的“让同一个词，有更多种玩法”面板查看条件，导入后预览词义、图片、关系和答案，确认孩子熟悉相关词句，再审核。缺少讲解可手动使用已配置ElevenLabs的免费包含额度准备；不足即停止，不切换付费服务。儿童开局只检查缓存，缺素材回基础题。高级素材填写格式见 [游戏素材](docs/GAME_MATERIALS.md)。

分批独立体验：[30种](http://127.0.0.1:8803/__qa)、[40种](http://127.0.0.1:8804/__qa)、[50种](http://127.0.0.1:8805/__qa)。右上角“体验设置”可指定玩法或随机完整一轮；选择器仅用于验收，正式儿童页自动安排。体验使用独立示例、已有英文缓存和本机离线示例配音，不写正式孩子档案。

所有引导孩子说词的学习环节接入录音：三遍跟读、神秘传送门、谁不见了、两词联想回想、先想再选、无声哑剧、听线索猜词、口头补空、双人信息差，以及朗读/中译英复习。每段最多20秒，说完自动保存到本机，孩子可回放；刷新或重启可找回已保存录音。家长在 **家长空间 → 学习记录 → 口头练习录音** 验证后回听。空录音不保存，失败可重试保存、重录或跳过；暂停/离页释放麦克风。录音不自动判对、评分或晋级，不调用云端识别。原音在私有 `data/practice-recordings/`，不进入公共素材、Git、日志或普通备份；备份恢复的原音标为缺失。实时聊天和语音指令停用。

**我的成长** 默认显示奖章与词汇，学习打卡、能力进展、单词记录分模块打开。练过与会词分开：当前义项的四项最新完整测评均独立通过才计入会词；同一英文合并计数，跨天巩固另列。奖章册有 **8个系列、128枚不同图案**，默认展示已获得及下一目标，标明还差多少，可按系列筛选、分页和查看详情。奖章首次达成后永久保留，当前会词量仍按最新证据更新；每枚有稳定编号，激励文字预留在`shared/badge-incentives.json`，由家长后续逐枚设置，未预设实际奖励。每轮学习背景保持一致，暂停和刷新不轮换。

麦克风需要同时通过网页和 Windows 的应用授权。若网页已点“允许”但提示系统拦截，请在 **Windows 设置 → 隐私和安全性 → 麦克风** 检查当前浏览器的应用权限；Codex 在部分安装包中显示为 **ChatGPT**。使用 Chrome/Edge 时也需开启桌面应用麦克风访问。内置预览仍受系统限制时，可在 Chrome 打开同一本机地址；换浏览器后需为网页单独授权。设备未找到或暂时占用会分别提示；失败可重试或跳过，不计为录音成功。

## 自主挑战与家长核验

在大厅点 **挑战测试**，默认推荐跨批短测：先测到期能力，没有到期项时补齐已学词的首次测试，初学次日起推荐；进行中或待核验项目不重复推荐。也可自己选1–5个学过的词测试，或在完成页点 **挑战本轮** 立即测试刚练过的词。孩子无需 PIN 即可开始、录音、提交与刷新恢复。每轮最多 5 词、20 项，顺序为中译英、朗读、英译中、看英文选图；到期复测只出对应维度。读和英译中不先播英文示范，中译英直接显示中文文字题面，不播放提示词，进入题目即可录音；录音每段最多 20 秒，提交前可重录，失败或空录音可重试或跳过。

提交后逐段使用 ElevenLabs Scribe v2 文件转写，再由官方 Codex 进行一次整轮结构化初判。AI 建议不晋级口头成绩、不生成发音分数；看词选图由服务端核对。家长在 **家长空间 → 学习记录 → 集中核验与现场测试** 回听、修改并批量确认，仍保留旧现场测试。

挑战界面沿用现有机甲伙伴，准备页展示四关路线和题量；题目页有大字题面、关卡与作答进度，录音按钮区分准备/录制/录好，支持试听、重录和保存。手机与桌面使用对应布局，暂停、提交检查和完成状态分别展示。

核验、回听、失败重试和旧现场测试需要 PIN 产生的 30 分钟授权；刷新后重新验证。儿童自主挑战的创建、回答和提交不要求家长 PIN。弱项练习与正式复测分开，孩子先练、家长再核验；同日重复不会多次晋级。

**挑战原音例外**：自主挑战会把原音暂存在私有 `data/assessment-recordings/`，不经公共素材接口提供，不进入 Git、日志或常规备份；核验保存后删除原音，失败保留待清理并重试，文字和核验历史保留。恢复备份后缺原音的未核验题需重测。

## 外部服务

复制 `.env.example` 为 `.env`，仅在本机填写配置：

| 用途 | 接线与配置 |
| --- | --- |
| 英文发音、中文释义及缓存 | ElevenLabs TTS；填写 `ELEVENLABS_API_KEY`、`ELEVENLABS_VOICE_ID`、`ELEVENLABS_TTS_MODEL`，可分别设置 `_VOICE_ID_EN`、`_VOICE_ID_ZH`；中文首合成需要账户读取 `user_read` |
| 自主挑战录音转写 | 沿用 ElevenLabs 密钥，需录音文件转写权限及 `user_read`；只确认免费包含额度充足且超额计费关闭后发送 |
| 词义补全、生图、挑战初判 | 官方 Codex ChatGPT 登录；项目锁定本地 CLI 版本，`CODEX_BIN` 默认留空，不读取或复制 `auth.json` |
| 三遍跟读 | 浏览器本地录音，无需额外云服务 |

只使用已授权的免费或订阅额度；不足或无法确认即停止，不充值、升级或切换付费 API。重复播放优先缓存；本地费用是保守估算，不是供应商账单或实时余额。没有配置、未登录或服务失败会显示真实状态。新音色试听候选不会自动替换应用当前音色。

当前本机中文讲解采用家长确认的 **机甲伙伴 C - 浑厚普通话男声**，配置在 `ELEVENLABS_VOICE_ID_ZH`；英文单词继续使用原有标准发音。C音色已保存到本机所用的ElevenLabs账户，并在免费方案下通过真实中文合成、缓存复播与流式复播验证；另已生成约22秒的儿童学习引导试听，使用相同讲解设置并保留本地缓存。新中文音频按音色独立缓存，旧音频保留；修改音色后需重启本机服务，免费额度不足或无法确认时停止新增合成。

Codex 生图和初判各在受限隔离环境运行，图片完成先由家长审核。测试中的模拟响应不证明真实云服务可用；已有真实验证和限制见验收文档。本轮结构整理不请求新的云端生成。

## 数据与维护

词书、进度、图片、发音、私有挑战/口头练习原音和 PIN 位于忽略的 `data/`，密钥仅在 `.env`。家长设置可导出/恢复学习备份，保留本机已发生的用量；PIN、密钥、授权与两类原音不进常规备份。迁移整个本机实例前停止服务并单独妥善保存 `data/`，学习数据导出不能代替所有素材的迁移备份。

忘记 PIN：停止服务后运行 `npm.cmd run reset-parent-pin`，再启动并重新设置；词书、学习记录与素材保留。PIN 保护本机网页入口，文件与本机 API 仍依赖操作系统权限。

`node --import tsx scripts/cache-word-audio.ts` 默认只检查正式词书；`--apply` 才生成缺失项，`--include-samples` 才包含示例。生成可能使用外部额度，失败即停止。

## 检查与项目包

```powershell
npm.cmd run check
npm.cmd test
npm.cmd run build
npm.cmd run package:project
```

项目包为 `artifacts/project-package/little-word-playroom.zip`，附 `.sha256`。含核心代码、当前静态素材、锁文件、测试、当前文档和启动入口；包内 `PROJECT_MANIFEST.json` 记录文件哈希。排除凭据、学习数据、依赖、构建、历史资料和验收输出；新电脑解压后需按上文安装、构建、配置服务和家长词书。

结构整理阶段的项目包已完成独立解压、`npm.cmd ci`、构建及隔离本机启动验证，具体结果见 [验收](docs/ACCEPTANCE.md)。本次50种游戏扩展以当前源码和独立体验为准，旧ZIP未重新出包；后续打包时需重新检查。

静态素材修改先审核，再运行 `npm.cmd run assets:update`；`npm.cmd run check` 同时检查清单、引用、缺失和哈希。普通检查、测试、构建及打包不生成云端素材。

当前独立体验和证据保留在原 `artifacts/` 目录，启动/用途见 [项目结构](docs/PROJECT.md)。这些是显式示例及隔离数据，不代表孩子真实能力。
