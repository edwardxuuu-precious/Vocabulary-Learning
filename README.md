# 单词游乐园

给 6–8 岁中文母语孩子使用的 Windows 本机英语学习应用，以电脑浏览器为主。家长准备词书和素材，孩子通过图片、发音、认听读与随机游戏学习；自主录音挑战由家长集中核验，成长页只汇总真实证据。

## 安装与启动

需要 Node.js 24，在项目目录运行：

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd start
```

打开 [本机入口](http://127.0.0.1:8787)。日常双击 **启动单词游乐园.cmd**，结束双击 **停止单词游乐园.cmd**；重启电脑后也从启动器进入，它会先启动本机服务再打开网页。关闭网页不会停止服务。修改 `.env` 后先停止再启动。开发使用 `npm.cmd run dev`，页面在 [5173](http://127.0.0.1:5173)。当前只在本地使用，云端部署暂缓。

桌面快捷方式：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install-desktop-shortcut.ps1
```

桌面与浏览器共用黄色机甲图标。快捷方式自动启动或复用本机服务，再打开默认浏览器；移动项目后重新安装。图标源与重建见 [桌面说明](scripts/desktop/README.md)。

## 家长备课

电脑端从家长空间侧栏进入备课、学习记录或设置。备课卡显示当前词表、交付状态、发音与图片进度。

1. 进入 **家长空间**，首次自设并确认 6 位 PIN；以后每次进入需验证，输错 5 次暂停 30 秒。
2. 在 **备课** 粘贴英文（每行一词或短语），也支持文件和中英两列。点 **让 Codex 补全**，审核中文、词性、多义提示和配图思路。核对页可直接改英文；疑似错词提供可采用的拼写建议，也可保留原词。**待处理** 只看缺项；修正后仅补该词，返回改整份英文也会保留未改词的补全与人工修改。
3. **确认词义并准备素材** 保存初始停用词书，自动缓存发音并串行生图。失败保留成功素材，由家长显式补缺或重试。
4. **审核图片** 支持放大、分页选择、批量批准和重画；只批准所见版本，重画后重新审核。
5. 显式 **给孩子学习**；也可先交付已备好子集。每个交付词都须有批准图片与发音缓存，批准图片不会自动启用整书。

**编辑词表** 可改书名、英文、中文、词性和增删词，保存才生效；删除整书需再次确认。改词撤回该词当前学习状态和图片批准，未改词保留进度；新增/改词须补齐素材再交付。删除停止受影响未完成轮次，保留历史、素材、费用和录音。12 个内置词仅为停用示例，不代表正式词书。

**学习记录** 分别查看挑战核验、练习录音与学习概览；游戏配套素材按需展开。候选关系、动作和短句须家长预览确认，缺发音另行准备，不自动批准。规则与高级格式见 [游戏素材](docs/GAME_MATERIALS.md)。

当前英文语音服务显示在 **家长空间 → 设置 → 服务与用量**。声音不完整时，进入 **声音检查**，用同一份缓存对比原始播放和新版播放；请分别测试蓝牙首播、静置5秒重播和扬声器。新版短音频先完整解码，冷启动前预热；答题提示音可单独关闭，总声音关闭会同时静音。

## 儿童学习

正式页面、独立预览的验收范围和待统一项见[当前验收](docs/ACCEPTANCE.md)。

体系采用[词档案驱动的完整规划](docs/LEARNING_REFACTOR.md)，当前状态见[任务树](docs/TASK_TREE.md)。每个词长期保留学习事实与分项能力；统一执行接口按当前现场、教学覆盖、弱项和到期方向安排下一步。原图、原音、已有学习事实及家长核验门继续保留，正式运行与真人效果分开验收。

**学会当前组，再开下一组。**「学过」来自实际接触，「已学会」需要四项独立通过，口头回答由家长核验。「已熟练」需要四项都有跨日独立通过的证据。学习页显示本组学会几词，并接到补学、弱项练习、独立测试或家长核验。等待核验时可复习已学词。开始下一组时，系统穿插至多两个薄弱或到期旧词，每词只练一个方向。家长可在 **学习记录 → 学习概览** 查看分项依据和复习日期。

首页采用插画式学习大厅，**学习**和**复习**整块可点击；**伙伴图鉴**、**我的成长**位于次级区域，**家长空间**在右上角。基地建筑与地面光轨融入整页背景，卡片保持清晰实底；图鉴显示当前真实解锁数量，角色与基地沿用已批准素材。

默认主线以最多双词的小组认识英文和中文，再按目标安排理解练习与穿插回忆。选中的词作为一份完整任务，学习页和续学入口显示整体进度；小组之间自动衔接，全部完成后才显示完成页。顶部“休息”可随时保存当前题与已录声音，下次接着学；原15/5分钟用屏休息继续执行。已开始的旧轮次保留扩展编排与原进度、录音、奖励；更多玩法在主动游戏目录中保留，仍按已审核素材、缓存与家长开关选择。

新建学习轮次按教学目标轮换适合的游戏，优先安排本轮较少出现的玩法，并控制每段的操作变化；素材审核、缓存和家长开关继续生效，已开始的轮次保持原样。七类基础题面与错配维修沿用同一蓝色主题、原词图比例与圆角；跳过在左下、提示/重听居中、主操作在右下，帮助位于顶部导航。基础听选先依次播放各个声音，对应选项同步亮起；听完点一个选项直接作答，**再听一遍** 单独重播，不需要暂选或再次确认。朗读的任务是看英文自己读：本次学习首次明确打开麦克风，浏览器已授权后后续词直接开始听；读完停顿后尝试自动收音，保留 **说完了** 手动结束。保存成功才开放 **继续**，可回听或再读。基础题不自动弹操作教学，需要时可点顶部 **帮助**；复杂游戏保留有限帮助。声音/设备失败如实反馈，可重试、跳过或保存休息；词汇示范与独立尝试分开。原主题、上传词图及已有轮次保留，音量检测和录音保存都不代表读对。新版运行范围见[当前验收](docs/ACCEPTANCE.md)。

“先听后看”等选图题点下即突出所选卡片；结果只在卡片旁显示一次，不再重复弹出下方提示。听图题将题目与重听放在同一行，卡片与底栏保持清晰留白；答对保留原图和绿色勾选，点 **继续** 才进入下一题。答错显示就地重试标记，可重听重选。

首页先选择 **学习** 或 **复习**：自动新学只从已交付且当前义项未学过的词中安排，默认每天 **5个新词**；已学词按能力状态检查、巩固或复习。新词页标题旁可直接点 **调整词量**，选好后点 **今天目标设为…** 生效，**取消** 保留原目标；临时目标仅今天有效，调整页明确显示明天恢复的常用目标。5词按短段完成，不因旧的10分钟预算缩成3词；15/5用屏休息规则继续生效。

学习入口只保留 **一个当前任务**：中途退出后可继续同一题；明确开始新学习或人工选词后，新任务替换旧任务，不再列出多份已保存学习。已实际认识的本组词继续参加掌握判断，日目标调整、跨天或切换去复习都不放开下一组。人工选词可以重学已接触词，或在本组学会后选未学词。

复习按需要安排：薄弱项先做定向练习，真实保存后进入仍缺结论的检查；正式能力到期进入对应检查，听辨/拼写沿用原客观作答。未教的短句先补学；尚未提交的检查接回原题，提交后的录音等待家长核验。同日练习去重不拦截必要的正式检查，录音、提示、未知与独立通过分开。家长“学习记录 → 学习概览”提供长期词档案、分项依据和下一步原因。

旧综合及大范围手选活动保留作历史，只有当前任务能继续；新任务不会要求孩子先补完这些旧活动。学习和正式检查的事实、原图、原音、成长与永久奖励继续分别保存。

复习页的 **按书加练** → 选择词表 → **开始复习**，只练该书当前义项已经认识的词，完整范围不受推荐数量截断。未学词可明确转学习；尚未备好的词如实提示并排除，不补示例或其他词书。随时保存，下次点 **继续复习**。

**玩游戏** → 选择词表 → 点一个玩法，或点 **随机开始**。这里只安排游戏；指定玩法始终保持该玩法，随机游戏在开始时排好并保存，刷新不重新抽。玩法按实际词类、不同图片、已审核素材、发音缓存和家长开关开放，未备好内容收在下方。每本词表的复习、随机游戏和各指定玩法各自保存进度；返回或 **先休息，回游戏选择** 后，下次可接回已翻开的卡、棋盘或当前题。完成后可再玩同一玩法或再随机一轮。

自选可跨书、筛选和分页，全选覆盖当前筛选的所有页，**清空已选** 清空全部。选好后点 **开始玩**；数量不限，每次先玩一小段，可保存后下次继续。选到接触过的词后，底部直接显示 **从头学** 和 **直接练习**：点从头学会重新讲解再接练习，无需打开菜单或再次确认。新单词点 **开始学**，始终先认识。**接触过** 只代表有讲解/练习记录，不等于记牢。额外练习不刷复习级别或推迟正式日期，其他未完成轮次保留。

大厅学习卡片右上角的 **更多** 可选择 **换一组词** 或 **这些词再练一遍**，确认后才执行；关闭或取消保留当前轮次。结束与重开保留历史、录音和已发生的接触记录，重开作为练习，不清空或重复计算正式成绩。卡片显示本轮词数和实际小任务进度，点击 **继续玩** 恢复。

学习页可点 **选择今日词量**（1–20词）或 **选择学习词语**。今日目标独立于家长的长期默认，第二天恢复默认；选定词语范围与顺序跨天保留，已认识的词不再当新词。选词后先预览原词图和顺序再确认，预算/今日目标外的词留后续，取消不改变安排。当前轮继续原位置，新的选择在下一轮使用；长期默认仍在家长设置中保存。

**推荐量说明** 可查看今日已认识的新词数量。推荐每天3词是默认节奏，不是每轮固定2词；当天已认识1词时，后续通常剩2个推荐新词，仍受本入口的时长预算约束。按词表练习和自己选词可以多练，正式掌握仍按独立测试证据判断。

在 **家长空间 → 备课 → 安排课堂单词** 设置本课范围、本次重点、词序和每段5–15分钟。可整本加入、逐词增删和上下调整；保存后孩子从大厅 **课堂词练一小段** 开始，约40词拆成多个短段。修改安排只影响后续段落，已开始的段落保持原样；要立即换词，先在大厅结束本轮。课堂练习可以超过每日推荐的新词数，仍保留真实接触记录，不直接写入正式掌握成绩。

新轮次默认采用 **连贯学习 · 分段回忆**：最多 2 个词一组穿插认识、听音和认词，再看图自己想起英文；回忆时先不显示英文，不先播放答案，需要时点同一卡片底部的 **听示范**。朗读仍先自己读，录音只记参与，不自动判对。游戏优先选择本轮较少出现的适合玩法，减少连续重复；语义、情境和字母游戏受已审核素材与家长开关约束。家长可在 **设置 → 学习设置** 切回原有顺序，全部 50 类玩法保留。已完成题目不改写，v1/v2轮次的后续小段可在休息点接入v3。

新版流程先完成 **单词练习 → 短句用法 → 学习完成**，然后由孩子另点 **开始测试**；未学完短句时，学习页顶部显示 **继续学短句**，已完成教学才显示 **本轮测试 / 继续测试**。当前本机接入与独立体验状态见[当前验收](docs/ACCEPTANCE.md)，具体参考与取舍见[学习环节](docs/LEARNING_FLOW.md)。两处保留全部已完成词，十词以内一次完整带入测试，可休息后继续；完成页突出词数、测试主按钮和休息出口，移除重复规则、打卡和分散链接；待核验与四项正式通过保持区分，只有合法正式通过才计入动画奖励。明天从复习入口再回忆，也可主动加练。新建/最近明确继续的自选学习也会显示在顶部“继续学习”，旧轮保留在其他进度；选词和轮次预览标注“已学过/未学习”，已学过不代表测试通过。

隔离体验会承接上次这组词的学习位置。练完单词可点 **继续学短句**，也可点 **从单词开始**，按原来的词语范围走完整流程。页首标明 **测试版**，试用记录单独保存。该组英文单词和短句可使用独立准备的试听音色，刷新原试用页即可接着体验。

单词练习结束后，仍在学习阶段进入 **学会怎么用**：中文情境与完整英文短句自动示范两遍 → “我是 → I am”式中英搭配 → 选词补句练习 → 学习完成；随后可主动开始本轮测试。all、am、are、at、ate、be、black、brown、but、came 均有对应学习内容；例如先学习“I want to be a cook.”，再测同一句的be空白。补学进度单独保存，休息/刷新可继续；只看过页面、听过声音或做过引导练习都不算正式答对。没有先完成对应示范与练习的v2句式，服务端拒绝开始测试或录音；旧轮原题和回答保留。短句页以核对过的变形金刚主题配图、整句英文和中文翻译为主，顶部显示学习进度，底部突出练习；不再单列重复的单词/词义角标。句子旁的喇叭图标每点一次重听一遍，不另设下方播放按钮。短句播放只取所选音色的已有缓存；缺音如实提示并可请大人带读，来源与音频示范分开记录。`node --use-env-proxy --import tsx scripts/cache-sentence-audio.ts` 默认只查当前挑战/最近完成轮缓存，`--apply` 按所选音色补缺，`--all-enabled` 包含全部已交付词。Nova 在本机生成，云端音色只在确认有免费额度时准备。发音默认长期保留，新增短句不自动挤掉原单词缓存。

儿童页面累计连续前台用屏最多15分钟，随后强制休息5分钟；期间遮住学习、测试和动画，停止声音/麦克风并保留已保存进度。倒计时结束自动开放，也可由家长输入原PIN提前解锁。计时跨页面和标签页共用，多标签不重复累计，刷新/服务重启/恢复普通学习备份不能清掉休息；离开页面不继续累计用屏，连续离开5分钟也视为休息。家长空间不计儿童用屏；限制仅作用于本应用。

每约 8 个小任务出现保存休息点（成组玩法一起结束），只显示本小段进度；**先休息** 回大厅，下次继续原位置，**再玩一小段** 才继续。自选数量仍不限；休息点不发整轮奖励、不把没做完的词记为完成。真正完成后突出本轮完成结果，不自动开下一轮。认识、练习和奖励沿用大厅的轻色卡片与紫色主按钮；讲解自动接练习，回忆/朗读录好后点一次 **继续**，明确跳过直接接下一题。返回学习大厅保留进度；休息后从大厅点 **继续玩** 直接恢复下一小段，无需重复确认。新词完成页突出本轮测试并保留先休息；复习/游戏完成页突出返回，游戏可再玩一次。

按上海日期，认识后的次日可进入看图回忆；普通回忆与中译英弱项练习去重，额外自选加练不推迟到期提醒或正式测评。回忆、听辨、朗读分别记账；录音前后是否听过示范、保存与跳过分开。家长学习概览可查看未听示范/有帮助的回忆录音次数及正式核验状态。

看图回忆页突出当前词语，示范与词义放在同一张卡片；点示范才显示英文，播放时暂不录音。中央按钮是唯一主操作，依次为 **开始说 → 说完了 → 继续**，图标随状态切换为麦克风、停止和前进箭头；底部的跳过、示范、回听及重录共用描边辅助按钮样式。说完停顿也会尝试自动收音，保存失败可直接重试，已保存可回听或重录。确认版已应用正式本机。

**保存退出** 会先结束并保存当前录音，再保留这题的位置。保存失败会留在当前题，可重试；也可明确选择 **只保留已保存进度，继续退出**，这会放弃尚未上传的声音/草稿。正在等待时可选 **留在这题**。刷新或服务重启后，继续原轮可接回原题、已保存声音和部分拼写；强制关页前还没上传的声音不能保证保留。

新建推荐复习先让孩子回忆和自己读，再进入会给出英文发音的环节。不会读时可直接点 **还不会读，帮帮我**；先前的尝试和提示状态会保留，帮助后的录音是跟练。主任务后至多再想两个词，每词一次，可先放这里或保存退出；这部分不评分、不刷等级。整本复习、主动游戏及已有轮次保留原安排。

推荐复习中，今天已经结束的同一词义、同一方向不会再被普通提醒或弱项提醒重复拉回；其他方向和后续到期仍可出现。录好后尚未继续仍保留在原题，跳过和声音不可用分别记录，不能当成记牢。推荐、按书、自选与游戏各自保存；主动加练不推迟推荐提醒或正式测评日期。完成后无其他到期时显示 **今天的复习先到这里**，不会自动开新轮；想多练可主动选词。

录音每段最多 20 秒，空音不保存；失败可重试或跳过，不识别、不评分、不晋级。暂停或离页释放麦克风。原策略的 **自己说一说** 保留三遍示范后录一遍。网页已允许但系统拒绝时，检查 Windows **隐私和安全性 → 麦克风**；可换 Chrome/Edge 访问同一本机地址并单独授权。

**挑战测试** 可自主录音、提交并刷新恢复，无需 PIN；每轮最多 10 词 40 项，按中译英、朗读、英译中、看词选图排列。作答时只保留一条进度，录好后点 **继续** 保存并接下一题；暂停保留本页已录片段，退出或刷新前仍需保存。AI 转写和初判只是建议，家长在学习记录中授权回听、修改并批量确认后，才形成口头正式成绩；不提供发音分数。音频失败或跳过不记错。

**我的成长** 展示练过、会词、打卡与 128 枚奖章；点统计可直接看对应记录，从完成页进入可一步回完成页。会词按当前义项四项最新正式结果判断，历史奖章永久保留。**伙伴图鉴** 收录汽车人和霸天虎各50位，共100位；擎天柱和威震天的图片、故事默认可看，动画自动解锁门槛分别为累计新学会10词、20词，其余98位模糊锁定，每页20位。同时沿用其他角色的奖励节点：10词解锁大黄蜂的图片与故事，20词解锁它的普通话动画，30词、40词进入下一位，随后循环；复习不推进奖励。沿用四项正式独立通过标准，口头须家长核验，同英文跨书只计一次，已按词数取得的旧奖励保留。人物与动画分别显示解锁进度，详情显示对应动画还差多少词；未解锁不提供播放器或原站链接。上一位/下一位只切换已解锁角色。点击“看中文动画”在页内展开B站播放器，支持全屏；加载失败可重试或打开国内原站，需要网络；解锁永久保留，原20位人物的图片和解锁顺序保留。选词、挑战、成长、图鉴与家长空间共用轻色卡片、统一留白与主操作层级；家长课堂安排位于词表工具栏，设置有更改时显示 **未保存**。详细行为以 [产品规则](docs/MVP.md) 为准。

擎天柱也可获得家长单独授权的观看奖励，随伙伴奖励保存。自动解锁按四项测试的正式结果累计。

## 私有数据与维护

`data/` 保存词书、学习事实、图片、发音、PIN 和原音，`.env` 保存密钥，均不提交、不随源码包交付。家长设置可导出/恢复学习备份，但不携带 PIN、授权、密钥、两类原音或私有业务观察。迁移整个本机实例前停止服务并单独保存 `data/`；学习备份不能代替所有素材的迁移。

家长入口 → 学习记录 → **使用简记**：先只记“停在哪里”，其余可留“不知道”并以后补记。同一机会补记不重复计数；家长投入手工分记主动分钟与等待；延迟观察先冻结词/方向/间隔，再只读首次合法证据，口头结果仍需挑战核验。记录只存本机私有分表，可在家长授权后单独导出，不进入项目Dashboard或普通学习备份；测试、工程示例和孩子分开计算。界面运行片段不等于注意力、意愿或家长投入，当前没有孩子真实基线。

练习原音在 `data/practice-recordings/` 私有留存，当前活动可回放，历史回听须家长授权；挑战原音在 `data/assessment-recordings/` 暂存，核验后按规则删除。两者不进公共媒体、Git、日志或普通备份；恢复缺音如实显示。

家长测试结束、孩子准备从零开始时，可先停止服务，运行 `node --import tsx scripts/reset-learning-progress.ts` 预览，显式加 `--apply` 才清零学习记录、轮次、测评和奖励。执行前自动在私有 `data/maintenance/` 保存并校验完整数据库快照；词表、图片、发音、设置、PIN、用量及原音文件保留，旧原音仍在原私有目录，不复制进普通备份。普通学习备份会合并永久奖章，不能替代这份清零前快照。

忘记 PIN：停止服务 → `npm.cmd run reset-parent-pin` → 重启后自设新 PIN，词书和进度保留。PIN 保护网页家长入口，本机文件与 API 仍依赖系统权限。

```powershell
node --import tsx scripts/cache-word-audio.ts
node --import tsx scripts/prepare-game-materials.ts
```

以上默认检查；显式 `--apply` 才生成缺项，受额度/预算护栏约束。词书与素材不会因此自动启用，细节见脚本。
