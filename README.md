# 单词游乐园

给 6–8 岁中文母语孩子使用的 Windows 本机英语学习应用。家长准备词书和素材，孩子通过图片、发音、认听读与随机游戏学习；自主录音挑战由家长集中核验，成长页只汇总真实证据。

## 安装与启动

需要 Node.js 24，在项目目录运行：

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd start
```

打开 [本机入口](http://127.0.0.1:8787)。日常双击 **启动单词游乐园.cmd**，结束双击 **停止单词游乐园.cmd**；关闭网页不会停止服务。修改 `.env` 后先停止再启动。开发使用 `npm.cmd run dev`，页面在 [5173](http://127.0.0.1:5173)。当前只在本地使用，云端部署暂缓。

桌面快捷方式：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install-desktop-shortcut.ps1
```

桌面与浏览器共用黄色机甲图标。快捷方式自动启动或复用本机服务，再打开默认浏览器；移动项目后重新安装。图标源与重建见 [桌面说明](scripts/desktop/README.md)。

## 家长备课

1. 进入 **家长空间**，首次自设并确认 6 位 PIN；以后每次进入需验证，输错 5 次暂停 30 秒。
2. 在 **备课** 粘贴英文（每行一词或短语），也支持文件和中英两列。点 **让 Codex 补全**，审核中文、词性、多义提示和配图思路；草稿可修改、停止和补缺。
3. **确认词义并准备素材** 保存初始停用词书，自动缓存发音并串行生图。失败保留成功素材，由家长显式补缺或重试。
4. **审核图片** 支持放大、分页选择、批量批准和重画；只批准所见版本，重画后重新审核。
5. 显式 **给孩子学习**；也可先交付已备好子集。每个交付词都须有批准图片与发音缓存，批准图片不会自动启用整书。

**编辑词表** 可改书名、英文、中文、词性和增删词，保存才生效；删除整书需再次确认。改词撤回该词当前学习状态和图片批准，未改词保留进度；新增/改词须补齐素材再交付。删除停止受影响未完成轮次，保留历史、素材、费用和录音。12 个内置词仅为停用示例，不代表正式词书。

**学习记录** 分别查看挑战核验、练习录音与学习概览；游戏配套素材按需展开。候选关系、动作和短句须家长预览确认，缺发音另行准备，不自动批准。规则与高级格式见 [游戏素材](docs/GAME_MATERIALS.md)。

## 儿童学习

首页 **开始玩** 进入大厅，可继续原轮次、推荐学习、自己选词或挑战。默认推荐每日最多 3 个新词、每轮最多 6 个复习词、约 10 分钟；新词按书和录入顺序，复习跨书优先到期与弱项，未完成新词也占当天推荐额度。

自选可跨书、筛选和分页，全选覆盖当前筛选的所有页，取消全选清空全部。数量不限，可保存后下次继续；旧词可直接练习或重新认识，未学词先认识。额外练习不刷复习级别或推迟正式日期，其他未完成轮次保留。

新词覆盖 **认、听、读**：自动英中讲解后进入练习，游戏在合适的 50 种玩法中安排，题目冻结并支持刷新恢复；缺素材回基础题，不用示例凑数。拼写、亲子与进阶情境默认关闭。游戏配对、提示和录音完成不等于独立掌握。

认识与游戏页共用小任务进度和底部操作，讲解只显示当前阶段。完成页默认提供 **回学习大厅**、**看看我的成长**，再练、选词和挑战本轮收在 **还想继续玩** 中，不自动开始下一轮。

**自己说一说** 先实际示范 3 遍，再让孩子录 1 遍，保存后可回放或继续；口头游戏与朗读也保留本机录音。每段最多 20 秒，空音不保存，失败可重试或跳过，不识别、不评分、不晋级。暂停或离页释放麦克风。网页已允许但系统拒绝时，检查 Windows **隐私和安全性 → 麦克风**；可换 Chrome/Edge 访问同一本机地址并单独授权。

**挑战测试** 可自主录音、提交并刷新恢复，无需 PIN；每轮最多 5 词 20 项，按中译英、朗读、英译中、看词选图排列。AI 转写和初判只是建议，家长在学习记录中授权回听、修改并批量确认后，才形成口头正式成绩；不提供发音分数。音频失败或跳过不记错。

**我的成长** 展示练过、会词、打卡与 128 枚奖章；会词按当前义项四项最新正式结果判断，历史奖章永久保留。**伙伴图鉴** 可浏览 20 位角色。详细行为以 [产品规则](docs/MVP.md) 为准。

## 外部服务与配置

复制 `.env.example` 为 `.env`，只在本机填写：

| 用途 | 配置与条件 |
| --- | --- |
| 英文发音、中文讲解与缓存 | ElevenLabs：`ELEVENLABS_API_KEY`、`ELEVENLABS_VOICE_ID`、`ELEVENLABS_TTS_MODEL`；可分别设置 `_VOICE_ID_EN`、`_VOICE_ID_ZH` |
| 挑战文件转写 | 同一 ElevenLabs 密钥，需文件转写和账户读取权限；发送前确认免费包含额度与关闭超额计费 |
| 词义补全、生图、挑战初判 | 官方 Codex 客户端登录，使用项目锁定 CLI；`CODEX_BIN` 默认留空，不读取或复制 OAuth 文件 |
| 练习录音与缓存回放 | 本机浏览器与已有缓存，无额外识别服务 |

中文讲解沿用家长已确认的 C 款普通话男声，本机配置保留；不因整理更换音色。只使用已授权免费/订阅额度，不足或不明即停，不充值、升级或切换付费服务。重复播放复用缓存，本机费用是估算，非供应商账单。实时聊天与语音指令保持关闭。新环境须独立配置权限和登录，模拟测试不证明当前云端可用。

## 私有数据与维护

`data/` 保存词书、学习事实、图片、发音、PIN 和原音，`.env` 保存密钥，均不提交、不随源码包交付。家长设置可导出/恢复学习备份，但不携带 PIN、授权、密钥或两类原音。迁移整个本机实例前停止服务并单独保存 `data/`；学习备份不能代替所有素材的迁移。

练习原音在 `data/practice-recordings/` 私有留存，当前活动可回放，历史回听须家长授权；挑战原音在 `data/assessment-recordings/` 暂存，核验后按规则删除。两者不进公共媒体、Git、日志或普通备份；恢复缺音如实显示。

忘记 PIN：停止服务 → `npm.cmd run reset-parent-pin` → 重启后自设新 PIN，词书和进度保留。PIN 保护网页家长入口，本机文件与 API 仍依赖系统权限。

```powershell
node --import tsx scripts/cache-word-audio.ts
node --import tsx scripts/prepare-game-materials.ts
```

以上默认检查；显式 `--apply` 才生成缺项，受额度/预算护栏约束。词书与素材不会因此自动启用，细节见脚本。

## 检查与交付

```powershell
npm.cmd run check
npm.cmd test
npm.cmd run build
npm.cmd run package:project
```

`check` 包含 TypeScript、静态素材路径/哈希和当前文档链接检查。素材修改审核后运行 `npm.cmd run assets:update`；普通检查、测试、构建与打包不生成云端素材。

项目包：`artifacts/project-package/little-word-playroom.zip`，附 SHA-256 与包内 `PROJECT_MANIFEST.json`。含源码、必要测试、静态资产、当前文档、锁文件及启停入口；排除凭据、学习数据、依赖、构建、Git 和任务证据。包是当前工作区源码快照，使用前以 [当前验收](docs/ACCEPTANCE.md) 为准；解压后重新安装、构建和配置。
