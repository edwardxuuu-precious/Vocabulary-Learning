# 单词游乐园

给 6–8 岁、中文母语、英语零基础孩子使用的本机单词学习应用。家长准备指定词表，孩子用大图、读音和点击练习理解词义、听音辨认、看图回忆，并通过跨天复习检查记忆。图片与角色用于辅助学习；当前只提供单词正常发音，不提供聊天或语音输入。

每日安排会区分新学和复习：新词完整认识、听音选图、看图选音、自行说词跟练；旧词直接练到期的听辨或已启用拼写技能。家长配置的新词数、复习数是上限，实际还受小任务预算约束：按每步约45秒折算预计时长，默认10分钟最多13步。这个估算用于控制题量，不是作答倒计时。

## 本机运行

需要 Node.js 24（当前电脑已安装）。初次运行：

```powershell
npm.cmd install
npm.cmd run build
npm.cmd start
```

打开 `http://127.0.0.1:8787`。也可以双击 **启动单词游乐园.cmd**；启动器会检测已有服务并打开网页，缺依赖/构建时进行准备。开发模式为 `npm.cmd run dev`，网页地址 `http://127.0.0.1:5173`。

双击 **停止单词游乐园.cmd** 可关闭本项目的后台服务。修改 `.env` 后，先停止再启动；关闭网页标签不会停止后台服务。

界面和进度保存在本机；生图、语音识别和首次语音合成需要相应外部服务。内置演示插画明确标记为本地示例。

## 家长准备

1. 打开后直接进入学词首页，无需先聊兴趣；可用内置已批准词表开始。家长入口数字为 **2468**，页面也会提示。
2. 在家长空间“词书工坊”粘贴英文和中文两列。可以从 Excel 复制，或使用两列 CSV。
3. 检查导入结果，准备图片，确认词义对应后批准并启用词表。
4. 孩子点击“开始学词”或“继续学词”。默认每天 3 个新词、最多 6 个复习词、约 10 分钟，到期较早的复习优先；拼写默认关闭，可稍后开启。
5. “学习记录”按词查看听辨、看图回忆及可选拼写，分开显示独立答对、有提示答对、跟练/体验和复习安排；练习完成与独立答对都不直接代表长期掌握。只跟练不创建测评进度；尚无听辨证据的词可在之后安排简短听辨检查，口头跟练不会让整词持续重走完整流程。
6. 图片继续由家长在备课区准备并审核。当前不开放兴趣聊天；既有兴趣和学习历史保留。

```text
apple	苹果
cat	猫
jump	跳跃
```

同一个英文词的多个意思需要分别整理为本轮明确要学的义项，避免图片与中文不一致。未批准的图片不会进入儿童日常学习。

## 单词发音

当前仅使用已有ElevenLabs TTS读出英文单词，en-US、清晰语气、不加情绪标签；认识词时自动播放，也可点击喇叭重听，听音练习和声音选项复用同一播放器。本地缓存可重复播放，不经过Codex对话。中文操作提示保留在界面，不合成闲聊或奖励话语。

现有12个英文词已全部预生成并验证缓存。以后导入词表或更换音色/模型/语速后，可在应用运行时执行 `node --import tsx scripts/cache-word-audio.ts` 只检查，添加 `--apply` 才生成缺失音频。脚本去重但保留原词大小写，使用与喇叭相同的英文清晰参数；经现有本机预算接口请求，遇到服务/额度错误即停止，不重试、切换服务或充值。缓存报告在忽略的 `artifacts/word-audio-cache-YYYYMMDD/`，音频位于 `data/speech/elevenlabs/`。

无需新申请实时语音API、配置原生端到端服务或充值。现有配置保留在本机，儿童路径不录音、不启动对话；Codex仅保留家长生图能力。回忆页由孩子先自己说，再点听发音核对、跟读继续，未识别的口头回答不能自动算独立答对。

本机.env已保存专用key和原创女声。新安装可复制.env.example，只需配置SPEECH_OUTPUT_PROVIDER=elevenlabs、ELEVENLABS_API_KEY、ELEVENLABS_VOICE_ID、ELEVENLABS_TTS_MODEL=eleven_v4_turbo；可选ELEVENLABS_VOICE_ID_EN覆盖英文声音，修改后重启。

现有账号使用免费额度，未充值、未订阅升级；额度不足时停止云调用，可继续点击学习。缓存已有单词不增加合成请求。本地API预算默认30元/月，免费调用同样按保守单价记录估算，不代表实际扣款；预算或服务额度不足不会自动充值。

密钥只留在服务端.env，不进浏览器、日志、备份或Git。未配置时明确标记系统朗读演示，实际声音取决于设备。申请入口：[ElevenLabs API Keys](https://elevenlabs.io/app/developers/api-keys)。当前沿用已创建的“小栗 Xiaoli - 温暖欢快女声”，英文示范不添加欢呼、对白或语气标签。

旧版语音输入与对话接线、测速记录保留在docs/ACCEPTANCE.md；[原生语音研究](docs/NATIVE_VOICE.md)已停止实施，不是当前配置步骤。

生图发生在隔离的备课目录，图片完成后先进入家长待确认列表，确认后才能用于学习。程序不提取登录令牌，不把 Codex 登录变成通用 Images API，也不会自动改用付费图片 API。内置生图消耗 Codex 账号使用额度，与语音 API 预算分别计算。

## 数据和备份

运行数据在忽略的 `data/` 中，SQLite 保存词表、兴趣、分技能学习记录和复习安排。家长页可以导出带版本备份，恢复前保存旧数据快照。备份不包含 API 密钥或 Codex 登录凭据。

Codex 对话索引位于 `data/dialogue/`，对话历史由官方 CLI 管理，**不包含在学习数据备份中**。恢复学习备份会重新开始当前对话，避免旧对话把测试或旧资料当作当前事实。

学习结果区分听辨、主动回忆和拼写，记录是否使用提示。同一天反复答对不会直接提升多个复习级别；跨天间隔初始为 1、3、7、14、30 天。恢复备份保留本机已发生的费用记录，不会用旧备份冲销用量。

## 隔离浏览器验收（发音模式）

运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/make-voice-e2e-fixtures.ps1` 准备合成语音，再运行 `node node_modules/tsx/dist/cli.mjs scripts/voice-e2e-server.ts --live --model=gpt-6-luna`，打开 `http://127.0.0.1:5174/qa/voice-e2e.html`。当前模式通过真实TTS和学习界面验证单词播放、重播、选声音与跟读继续。历史合成麦克风面板保留，但当前儿童页没有录音或聊天入口，不会调用Scribe/Codex对话。

此命令会使用真实免费额度，隔离后端8788、网页5174、独立数据及预算账本在忽略的 `artifacts/voice-e2e-data-<model>/`；不改正式孩子档案。可用 `--run=latency` 创建独立的一轮目录，历史费用不会回滚。端口被其他验收占用时可显式使用 `--api-port=8789 --web-port=5175`，不停止其他进程。合成脚本显式指定中文文化并校验实际 PCM，防止静默生成空 WAV；`-Only interest2` 可只生成一段新内容。普通测试不调用云端。停止此验收进程后端口关闭；正式启动器不包含验收面板或合成麦克风。最新时延、修复和真实限制见 `docs/ACCEPTANCE.md`。

完整学词验收可在“下一段合成语音”选择apple、banana或cat；这三段由Windows的en-US语音生成。真实录音处理、识别定稿和答题请求会显示在验收时序中。分别检查无提示回答、点击“听小栗说”后回答，以及说出不同单词后跟练继续；提示和跟练都不得算成独立回忆。本轮证据在忽略的 artifacts/learning-voice-live-20261015/verification.json 与 parent-records.txt。
