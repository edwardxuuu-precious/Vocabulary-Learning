# 儿童成长、奖章与背景

## 入口与呈现
- 首页右上角“我的成长”默认进入总览：主卡显示真实已获奖章及“继续玩”，练过的词、会的词、学习天数三张统计卡直接打开对应记录。零记录显示开始学习，不虚构奖章或能力等级；学习入口复用首页词书准备门槛。
- 顶部使用“总览 / 打卡 / 能力 / 单词”四个紧凑入口，每次只渲染当前模块；子模块可返回成长首页，切换后回到页面顶部。留白、浅色卡片、紫色主操作及机甲伙伴与大厅统一。
- 打卡模块单独显示35天日历、累计/当前连续/最长连续天数；能力模块显示四项独立通过词数与挑战测试入口，判定规则和当前会词称号折叠查看。
- 单词默认显示练过的词，支持词图、英文/中文查找及练过/会的/待复测筛选，每页8条；点开词卡再看四项真实结果。统计中的英文去重与列表中的所学义项分开标明。空筛选提供恢复入口，无记录可去学习。本轮只调整呈现，不修改统计、奖章或测评规则。
- 完成页展示实际本轮练习词数、最多三张本轮词图、真实打卡及累计学习天数。默认保留“回学习大厅”和“看看我的成长”；“再练一轮 / 自己选词 / 挑战本轮”收在“还想继续玩”，不自动开始下一轮。
- “会的单词”“已经练习过”“累计学习”分开显示，不提供虚构分数或英语能力等级。

## 记录规则
- `shared/growth.ts`从原有学习会话、答题与独立测评记录只读汇总会词与打卡；奖章首次达成由`recordBadgeAwards`在原存储事务中记录，不修改答题事实、用量或复习调度。没有儿童手工刷奖章的接口。
- 有保存的学习尝试，或完成一轮学习，或实际提交测评判断，即形成学习日。仅打开页面/会话、只跳过测评不形成打卡。使用上海日期，每天只计一次；中断连续天数不清空累计天数。
- 会词：当前词义/学习版本在最近已完成测评中的中译英、独立朗读、英译中、看英文认意思均为独立答对。口头题必须来自家长确认，看词选图必须来自服务端核对。练习、跟读、提示、未确认、跳过、选项不足、未完成测评、旧词义成绩不算会词。
- 统计按规范化英文合并；逐词保留各义项。通过一个已学义项不代表懂得该词所有含义。暂停启用词书不会主动抹去已有能力记录；修改词义后旧版本不继承。
- 四项都在不同上海日期独立通过两次，单列“跨天巩固”。到期只表示需要复测，不自动判定忘记。最新完整测试未通过或义项变化时，当前会词量与称号相应更新；已获得的奖章永久保留，不重复记录。

## 奖章册与激励

奖章目录真源为`shared/badge-catalog.ts`，8个系列各16枚，共128枚。每枚有唯一图案、名称、稳定ID与编号；4种外框配合系列色彩。图案使用本机彩色符号字体和代码绘制的SVG外框，无图片生成请求或新静态素材依赖。

| 编号 | 系列 | 真实达成依据 |
| --- | --- | --- |
| D01–D16 | 坚持足迹 | 累计学习1/2/3/5/7/10/14/21/30/45/60/90/120/180/270/365天，不要求连续 |
| P01–P16 | 练词旅程 | 练过1/3/5/10/15/20/30/50/75/100/150/200/300/500/750/1000个不同英文词 |
| W01–W16 | 会词实力 | 四项独立通过1/2/3/5/10/15/20/30/50/75/100/150/200/300/500/1000词 |
| C01–C16 | 跨天巩固 | 四项各在不同日期通过，词数阶梯同W系列 |
| L01–L16 | 看词辨义 | 服务端核对独立通过，词数阶梯同W系列 |
| R01–R16 | 独立朗读 | 家长正式确认独立通过，词数阶梯同W系列 |
| E01–E16 | 英译中 | 家长正式确认独立通过，词数阶梯同W系列 |
| Z01–Z16 | 中译英 | 家长正式确认独立通过，词数阶梯同W系列 |

- 默认显示“已获得”，用彩色图案和勾选标识区分灰色待获得奖章。卡片只显示名称、系列、获得状态或剩余条件，完整编号、条件、进度、记录时间及奖励保留在详情。上方展示接近达成的目标与还差的天数/词数；另有“下一目标”“全部”、系列筛选、每页12枚及详情。
- 每个系列只推荐第一枚尚未获得的奖章，进度条和剩余数取当前事实。已得奖章保持获得状态；当前会词量及称号仍随最新正式测评变化，不将历史奖章冒充现在的能力。
- `badgeAwards`保存ID、首次记录时间、达成时数值和记录来源。升级仅按当前可核验证据补记；补记时间为记录时间，不虚构过去获得日期。重启、重复写入、恢复旧备份不会重复记录或清除本机已得奖章。
- 原8枚ID保持不变。`shared/badge-incentives.json`预留每枚激励文字，初始为空；可按界面编号或稳定ID配置，例如`{"D01":"一起选一本绘本","W01":"周末一起拼积木"}`，重新构建及启动后显示。内容以家长实际配置为准；发放和核销流程留待后续实现。
- “新晋探险家”等称号只映射当前会词里程碑，不映射CEFR或自动发音评分。

## 稳定背景
- 内置imagegen生成3张1672×941PNG：`public/assets/backgrounds/meadow-v1.png`、`lagoon-v1.png`、`cloud-garden-v1.png`。
- 使用`shared/learning-backgrounds.ts`对随机会话ID确定性选图；认识、全部游戏、暂停、刷新恢复与完成页共用一张。新会话才重新选择；成长页有当前会话时沿用，没有时按上海日期选择。首页保留原有机甲场景。
- 图片无角色、文字、界面或动画，低对比且中央留白，适应横屏与竖屏；图片无法加载时保留浅色底。学习过程中不轮播、不自动切换背景。
- [完整生成提示词与工具参数](learning-background-prompts.json)。仅此次生成素材使用内置imagegen；应用运行不请求图片生成，不新增语音服务配置或费用。

## 隔离体验与验证
- `node --import tsx scripts/growth-qa.ts --port=8795`，打开`http://127.0.0.1:8795/__qa`。
- 场景：全新档案、只练未测、已测成长、下一天。数据保存在忽略的`artifacts/growth-qa-*`，使用显式示例与合成历史；发音只复制已有MP3，云服务被禁止。
- `tests/child-growth.test.ts`覆盖练习/能力分离、每日去重、上海午夜、连续天数、旧义项、未完成测评、最新结果、判定来源、重复词、跨天巩固、只读汇总与背景资源。
