# 原生端到端语音接入方案

更新：2026-10-15。状态：用户已明确暂不需要聊天，只要单词正常发音；本方案停止实施，仅保留研究记录，无需申请或配置原生语音服务。

## 目标与分工

孩子点一次开始后连续听说；小栗说话时孩子能插话，旧回复立即停止。屏幕保留大按钮、角色与短字幕，结束或离开立即释放麦克风和连接。无需孩子输入或阅读操作说明。

候选分工：原生语音模型负责听说和日常聊天；本机服务校验应用动作；官方 OAuth Codex 负责受控任务与隔离素材目录生图。任务结果确认后由语音模型向孩子说明，后台工作不阻塞整段聊天。此分工会调整此前“每句都由Codex生成”的要求。

当前正式路径仍为Scribe转写、Codex文本回复、ElevenLabs朗读。尚无原生会话适配器；不以循环重开单轮录音冒充端到端语音。

## 可选接线与服务条件

- OpenAI Realtime：原生音频输入/输出、打断和受控工具调用；浏览器WebRTC，本机信令代理与服务端控制。常规聊天无需等待Codex每轮生成文本。[官方Realtime](https://developers.openai.com/api/docs/guides/realtime)
- GPT-Live：官方文档另提供全双工语音与client delegation，可对接应用自有agent；技术上适合语音前台与Codex任务后台的分工。具体账号可用性、费用和儿童项目数据条件仍需核实，不把文档能力等同本机接通。[官方Live](https://developers.openai.com/api/docs/guides/live)
- 独立API凭据仅保存在服务端；不提取Codex OAuth令牌，不把其登录或订阅额度用于原生语音。本机当前没有OpenAI/Gemini API key；已有ElevenLabs key仅识别/朗读。
- Realtime两款2.1模型官方Free档均不支持；账号试用金未核实，不承诺免费。保持暂不充值、不自动升级。[模型与价格](https://developers.openai.com/api/docs/models/gpt-realtime-2.1)
- 给13岁以下儿童处理个人数据前，OpenAI官方指南要求先实施API零数据保留（ZDR）；该设置需申请获批。本机不落盘、普通key或store=false不能替代获批项目配置。真实儿童接入前须核实；成人/合成样本可用于开发验收。[儿童指南](https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance)、[数据控制](https://developers.openai.com/api/docs/guides/your-data)
- Gemini Developer API现行条款排除面向或可能供未成年人访问的应用，不能以其免费档直接替代本儿童应用；不外推至其他Google产品。[现行条款](https://ai.google.dev/gemini-api/terms#age-requirements)

以上为候选，不代表已选定供应商、创建凭据、具备额度或已通过真实语音验证。

## 前后端边界

1. 前端持有单个连续音频会话，输入/输出状态分别管理，支持同时听说。新模式开启前停止旧录音、固定接话与TTS，避免双麦或双声；降级必须明确提示。
2. 一次手势申请麦克风并发起同源信令，真正ready才提示“可以说啦”。连接前不能假定服务会补发孩子抢说的音频。
3. 原生打断需取消供应商生成及未播音频，更新已播放位置；不能只暂停后恢复旧音频。会话epoch、turn/response ID拒绝迟到字幕、音频和动作。
4. 结束、离开聊天、页面隐藏/关闭、异常、预算或时长截止时，立即停止全部track、播放器与连接，再异步释放服务端会话；停止幂等。
5. 服务端仅接受白名单提案并校验schema、会话和真实输入依据。兴趣先pending，后续真实确认语音/按钮才写入；模型传confirmed=true不产生授权。
6. 不把现有profile/attempts/session的可信UI接口直接注册为模型工具。模型不能标对、晋级、发奖励、批准图片、提高预算或转发任意URL。学习判定继续走确定性路径。
7. Codex仅接已授权任务；生图继续在受限目录，结果先家长审核。打断聊天与取消后台任务分别记录，未确认成功前不宣称完成。
8. 新语音用量独立预留、结算，未知费用不擦除；按连接/生成实际计费规则实现硬限，不套用旧STT/TTS字符单价。

## 验收标准

- 完成聊天→开放询问兴趣→准确复述→明确确认→进入已批准词表学习；含糊表达先澄清，不能提前写兴趣。
- 覆盖2/3秒句中停顿、话未完继续说、噪声、快速插话、多次打断、离页、断网、配额停止与迟到结果；分别检查停止播放和后台任务状态。
- 从真实声学结束到远端音轨首次有声计时，独立统计有意义回复与接话。连续WebRTC的playing事件不能作为每轮首音；使用远端音轨电平与response ID记录。任务完成另计。
- 原生语音不保证固定3秒停顿和2–3秒出声同时无条件成立；按儿童实测调整轮换，报告慢样本，不以事件创建/字幕/固定接话冒充回答。
- 单元测试模拟只证明代码；真实云连接、声音、打断和费用必须分别验证。尚未发送任何儿童音频到候选服务。
