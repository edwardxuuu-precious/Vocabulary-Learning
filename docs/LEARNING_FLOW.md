# 学习环节与游戏取舍

适用6–8岁中文母语孩子。沿用批准的机甲主题、家长已交付词书和原图音；学习规则以[MVP](MVP.md)为准，实际接入/验证状态只见[任务树](TASK_TREE.md)与[当前验收](ACCEPTANCE.md)。以下是本项目根据参考作出的设计取舍，不能视为已证明孩子学习效果。

## 参考与采用理由

| 直接参考 | 核对到的机制 | 本项目采用方式 |

## 一份任务怎样结束

1. **单词学习与练习**：最多两词一组，先解释词义、展示批准原图并示范，再做听辨/认义，穿插先想后提示的回忆与自己朗读。原六项目标、原音参与和同日晋级边界保留。
2. **短句用法学习**：已完成单词练习的同范围词，凡有适配当前义项的短句，继续中文情境、完整英文两遍示范、中英搭配和引导补句。选项只用本任务中已认识的词；辅助句词不另计新词或测试目标。错误可再看搭配、再练，不写正式成绩。
3. **学习完成**：短句示范与引导练习真实保存后，明确结束学习。完成按钮返回完成页或学习入口，不自动建测试；孩子可以休息或主动开始独立测试。
4. **独立测试**：只检验已教过的当前词义、用法和方向；不自动插入示范、讲解或选词练习。历史内容缺教学资格时显示返回学习的入口，已有回答保留。口头回答仍由家长核验，提示/未知/跳过/录音参与与独立通过分开。

单词任务原有完成事实与奖励不改写；“还需学短句”来自独立教学记录，不将旧轮次重新标成未完成。短句按词义、原图和句式版本保存，刷新/休息接未完成处；内容更新时回学习入口核对。

短句配图按完整英文句子和中文语境审核。核对主体、动作、地点与关键属性，原词图只有符合整句时才可复用。已核对关系登记在 `shared/sentence-illustrations.ts`，绑定句式、译文与图片，短句教学和测试图片提示共用。缺匹配图时保留文字、音频和练习；无图不会改变既有学习证据。

### 短句配图验收

1. 先冻结英文整句与中文译文。列出这句中孩子需要从图里指认的主体、动作、地点、关系和关键属性。例如书包和黑色须同时出现。
2. 用图表达能看见的线索。介绍自己、对面的人与第三人时，分别通过指自己、面对视角和指向身旁人物区分。用动作或结果表达事件，像苹果核对应“吃了苹果”。“昨天”等时间信息由句子和发音表达。
3. 并排核对图、句和译文。确认孩子能指认关键对象，画面没有容易看成另一物体或另一动作的主体；用于测试提示的图里也不应出现英文答案。
4. 通过核对后登记准确的英文句式、译文及图片资源。句子、译文或图换版时重新核对。没有匹配图的句子以文字、发音和练习呈现。

短句场景统一沿用变形金刚机甲主题。以原词书已确认的 Q 版机甲造型为参照，配图中的机甲保留机械面罩和装甲轮廓。句子说的是孩子、朋友或物体时，清楚画出对应主体，机甲作为场景里的伙伴。验收时同时确认句意、主题和小图尺寸下的可辨识度。

## 游戏为什么出现在这里

| 当前方式 | 必须用到的语言能力 | 调整与条件 |
| --- | --- | --- |
| 先听后看、听音配对 | 把听到的词与词义图联系起来 | 真实播完后直接出图，去掉“准备好看图片”确认；失败仍可重试/跳过，不假称听完 |
| 双词排队/收集 | 听辨两个词；排队额外要求记住先后 | 只用已认识且图义可区分的词，最多双目标；保存原顺序，不加倒计时或无关移动 |
| 看图想英文、看词自己读 | 主动提取或朗读 | 先自己尝试，示范按需开放；保持原音真实保存，练过不等于读对 |
| 颜色工坊、位置摆放、部件归位 | 理解颜色/位置/部件含义并操作 | 只有匹配词义、已审核材料和缓存发音时出现；不为补齐游戏引入未选颜色或位置词 |
| 中文情境→完整短句→引导补句 | 理解这个词在句子中怎样用 | am/are/be按已确认例句区分，先教后练；明确属于学习，不冒充测试 |

自动主线先选择适配当前词义的已审核任务，再在同目标的方式间变化；每段仍控制操作机制。单步走格、原图切块、揭局部和未教的故事/改句不再默认轮入；完整目录和显式选择继续保留。既有冻结计划不重排，旧版显式升级仍保留已开始内容与快照。

## 体验时观察什么

先观察孩子是否明白现在在学还是在测、能否独立接下一步、是否需要家长解释玩法、是否愿意继续；再观察隔开后能否想起并使用词。工程回归、设备实听和真人结果分别登记，不能用通过题数或游戏种数代替。
