# 词表核对与就地修复设计

范围：家长确认词义之前的导入草稿。产品边界见 [MVP](MVP.md)，进度见 [TASK_TREE](TASK_TREE.md)，验证见 [ACCEPTANCE](ACCEPTANCE.md)。沿用原家长空间浅色卡片、紫色主按钮及项目主题，不替换批准素材。

## 采用的强参考

只借鉴交互，不接入上述服务或产生对应费用。英文词汇建议由现有受限 Codex 文字任务产生，不增加供应商或单独的纠错请求。

## 信息与动作层级

- 顶部：词表名字、已补全/总词数；存在拼写建议时说明需要核对的词数。处理中可停止，成功部分保留。
- 中部：全部/待处理筛选；保持原词序和原行号。英文旁可修改，中文和词性保持可编辑；配图思路与游戏折叠。
- 问题行：保留原英文、给出建议及短原因。采用建议清除该词旧义项/场景，只请求该词；保留原词不自动接受猜测词义，仍可人工补齐。重复词或无效英文就地阻止保存。
- 底部：一个“确认词义并准备素材”主操作；展示剩余词数。缺项、未处理建议、未保存的英文编辑或运行中禁止确认。窄屏取消底部悬浮，避免遮挡建议。

## 草稿身份与回退

按精确英文匹配，不按行号或相似度复用。新增/改英文只补对应词；删词不再进入本次范围。显式改输入中的中文使该词旧场景失效；未改源中文不能覆盖核对页的人工修改。行内改词同步构造新来源，服务端检查来源与词序一致；单词补全还须检查目标词存在。

本次导入前后步骤内保留草稿。刷新、关页或离开整个导入组件不承诺恢复；草稿不创建正式词书、素材任务或儿童学习事实。内容确认、音图审核和显式交付继续分别执行。

## 实现与复现入口

合并/纠词规则在 [import-draft](../shared/import-draft.ts)，草稿与建议合同在 [contracts](../shared/contracts.ts)，实际界面为 [EnglishImport](../src/english-import.tsx)。隔离预演运行 `node --import tsx scripts/import-draft-qa.ts` 后访问 `http://127.0.0.1:8794/__review`，先确认端口空闲。该页使用明确示例与模拟补全，所有外部服务禁用，不读取正式数据库或PIN；用于交互验收，不证明真实模型纠错准确率。
