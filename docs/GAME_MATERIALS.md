# 额外游戏素材与家长审核

50个模板均已实现；是否能用于某个词，仍取决于词数、义项、素材、已有发音与开关。原有20种、7种自动字母模板，以及复用已批准词图的四块拼图与原中文词义回忆，不需要额外语义表；其余21种使用家长确认的素材。字母玩法只抽2–6个字母的词。一个已批准词也可使用自己的拼图或中文回忆，不填入未选词。

家长交付正式词书时，自动启动拼图与中文回忆配音补缺，任务有每批5000字符上限、免费额度与预算护栏。准备失败不反复重试，缓存保留；家长可在游戏配套素材面板查看进度和停止。素材检查与孩子开局不触发生成。自动中文回忆只复述已确认释义；自定义情境线索仍需进阶开关。

## 使用流程

1. 在家长空间的“学习记录 → 游戏配套素材”，打开“让同一个词，有更多种玩法”。选择词书，先查看自动生成的候选。程序只对内置规则支持且当前中文词义匹配的内容提出颜色、分类、反义、动作、记忆字块、近形词和少量短句方案；无法确认的关系不推断。
2. 展开候选，核对题目、图示、完整句子和答案后勾选，补齐配套发音，再点“确认使用所选素材”。发音已准备不等于素材已批准，候选不会写入正式学习事实。需要自定义时继续下面的填写表流程。
3. 展开补充素材，选择玩法，下载当前素材填写表。填好图片、关系和题目后粘贴，点“预览素材”。高级填写格式如下；独立示例生成器在`scripts/game-material-fixtures.ts`，不会自动写入正式词书。
4. 实际查看图片、动画、关联词、线索、顺序和全部合理答案。涉及短句、否定或组合时，先确认孩子已熟悉这些表达；易混侦探仅填写实际观察到的混淆词对。分块是记忆提示，不是自然拼读规则。
5. 缺少讲解时，明确勾选预览确认后点“准备缺少的讲解音频”。已有缓存直接复用；新增仅使用已配置ElevenLabs的免费包含额度与预算护栏，不足即停止。这里不自动生图、不换供应商、不充值或升级，也不自动批准。
6. 点“确认这份素材”。审核要求家长PIN产生的授权，服务器再次检查义项版本、关联词版本、图片和缓存。素材就绪后，符合词数组合与家长设置时才加入新一轮随机安排。儿童开局只读缓存，不发起新云端生成。

亲子、进阶情境、拼写分别在设置中开启，默认关闭。进行中的旧轮次保持原题快照；修改材料不会重新抽题。纠正词义后旧材料不会被当作新义项的批准材料。

## 填写表字段

| 字段 | 用途与限制 |
| --- | --- |
| `version` / `wordVersion` | 格式1、下载时的义项版本。词义变化后重新下载，不手改成新版本冒充审核 |
| `wordIds` / `wordVersions` | 涉及的已批准词及对应版本；最多12个，ID取自词书，不放英文词串代替ID |
| `origin` / `approvedAt` | 自动候选为`proposal`且无审核日期，不进入儿童随机池；复用图词布局为`approved-word`，不冒充额外审核。最终语义审核由服务器去除候选标记并写入真实审核日期；旧填写表日期仍兼容 |
| `instruction` | 简短中文操作说明；最多300字，先准备缓存，避免暗含未学英语要求 |
| `prompt` | 可选题面：`{text,locale}`，locale为zh-CN/en-US。线索、故事、句子等必须填写 |
| `tiles` | 1–12个选项/部件；每项有唯一`id`、家长可读`label`，可带`wordId`、已查看的`imageUrl`、`text`、`color`或内置`motion` |
| `answer` | 答案ID；多选填写全部合理答案，排序填写实际先后顺序。故事、编程、组合固定两个目标，不能把更多目标偷偷算一步 |
| `slots` / `placements` | 放置区与部件到位置的关系。slot有id/label，可配图示symbol；部件热点用0–100的x/y百分比 |
| `acceptedSlots` | 分拣、部件、位置、任务分工中一个目标可接受的多个位置；有多个合理角色时全部列出 |
| `clues` | 交集恰好两条线索；每条带text/locale/matches。最终answer必须等于两条matches的交集 |
| `sentence` / `blank` | 已熟悉句子的词块与从0起算的空位。补空保留真实完整词，儿童揭晓前隐藏；改句则保留唯一错词供替换 |
| `chunks` | 已审核的2–3个记忆字块，连起来必须等于目标词 |
| `source` | 相似词变换的已学起始词，必须在关联词中 |
| `count` | 数量订单1–5件；数量词和物品词各占一个步骤 |

图片只接受本机已准备的词图或`/media/images/`素材，不接受远程地址、data URL或路径穿越。内置静默动作图示包含run、jump、wave、turn、sit、stand；请在预览中实际检查其可辨认性，再决定是否用于对应词。其他动画需要以后扩充图示实现，不能只改文字当作新动作。

词块示例（ID、版本使用下载表中的实际值）：

```json

  "wordVersion": 0,
  "approvedAt": "2026-10-17T05:00:00Z",
```

## 记录与验证边界

新增30种只记练习。无图听写也暂不直接授予独立拼写掌握；词汇进步继续依靠原有客观检查和正式核验。故事示例需要理解`after`所表达的事件关系，实际顺序可与听到词的先后不同；不是连听排队的换皮。

无声哑剧、中文线索、图示补空和亲子信息差均接入私有录音。先准备线索，录音或明确跳过后揭晓；保存不评分、不调用云端识别。已有声音选项的亲子录音保守记为跟练。保存位置和备份边界沿用README，普通备份不携带原音。

独立体验中的图示、关系、短句、Windows离线配音及模拟麦克风验收均为测试材料；它们不会批准家长正式词书，也不代表儿童真人录音或实际掌握。源码不依赖`artifacts`中的测试文件。
