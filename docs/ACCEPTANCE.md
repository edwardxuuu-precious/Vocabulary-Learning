## 声音、回忆与失败恢复

- 短音频完整下载/解码后播放，复用上下文与缓存；首播、静默、恢复和录音后预热，快速重播只保留最后一次。自动化覆盖首播/连播、取消、过期回调、后台恢复和缓存复用。
- 本机生成正确、再试与保存音，遵循单独反馈音/总静音开关，不盖住单词、不请求云服务。网络、播放或录音失败不播放答错音，不计成功。
- 示范与词语就近呈现，实际媒体事件决定播放状态；播放时不录音，暂停/离页释放资源。已保存可回听/重录，保存或继续失败保留当前题；明确跳过可接下一题。
- 桌面、390px手机与矮屏的关键流程在隔离环境验收；合成麦克风验证保存/回放/失败重试/限时/拒绝权限，不代表真实儿童收音。
- **原蓝牙设备尚待家长验收**：首次、静置至少5秒和录音后重播 `here / funny / yellow`，对照扬声器与家长声音检查。仍缺首音时，声音问题保持未验收，自动化不能替代实听。
