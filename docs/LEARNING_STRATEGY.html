核心方向：用稳定的学习闭环，串起兴趣与长期记忆

下一阶段优先做深“一个词怎样学会、怎样愿意继续、怎样隔天想起”。现有玩法、伙伴和素材成为服务这个闭环的工具；以孩子的延迟回忆和自愿参与，决定后续扩展。

优先做的五个决定

1

把默认学习做成可结束的小段

先试 2–4 分钟一个小段；整次 6–10 分钟只是待验证起点。自选仍可不限量，按小段推进和保存。

2

把回忆安排在示范之前

初次先教会；再次遇到已接触的词，先给尝试机会，再按需要提供示范。跟读与独立回忆各记各的。

3

先用熟悉机制形成稳定节奏

从现有机制选 4–6 类进入核心试验池，复杂玩法分层开放；数量为产品假设，依据实测调整。

4

让复习自然出现在主路径

保留到期与弱项优先；补上同轮隔项回忆、次日轻量回忆及以后复测，少依赖孩子主动找测试页。

5

用小规模真实观察决定取舍

先记启动、卡顿、提示与退出，再比较次日和第 7 天的回忆。没有儿童基线时，不给“效率提高多少”的结论。

保留项目已经做对的部分

  • 家长确认词义、批准图片、发音就绪、显式交付的完整边界。
  • 认、听、读及四项正式测试分别记账，跟读和录音不冒充掌握。
  • 题目与素材快照、会话恢复、幂等推进、同日不反复晋级。
  • 本机私有原音、真实失败状态、免费额度与预算护栏。
  • 刚统一的留白、卡片、主操作和简洁完成页。
架构路线：继续使用当前 React / TypeScript 与本机服务，以小步抽取学习策略、证据视图和会话编排实现优化。

审视范围为当前代码、规范和既有验收。未读取孩子私有录音或据此推断孩子能力；尚无本轮儿童观察样本。

03 / 学习闭环每一轮有起点、有努力、有收获、有结束

给零基础孩子的三条学习路线

  • 声音 ↔ 含义：先听懂、找对、敢表达；先用图片、动作与实物，不要求会读英文按钮。
  • 文字 ↔ 声音 / 含义：逐渐连接词形与已熟悉的口语词；“不会解码”不直接当作“不理解意思”。
  • 拼读与拼写：有独立的字母音 / 拼读前提。字母棋盘是扩展练习，按就绪程度出现。

现有认 / 听 / 读证据继续保留。调整的是教学先后与分布，不自动放宽四项正式掌握的定义。关联 C1。

帮助后仍有一次真正“再想”的机会

想一想→需要线索→看 / 听示范→穿插别的词→再次尝试
  • 提示出现之前，留出主动思考或主动请求帮助的空间；不倒计时施压。
  • 连续困难则缩短小段、降低选项负担或结束，不无限重试。
  • 录音只记录参与；家长确认之前，没有口头正式正确率。
  • 同轮帮助后的成功用于教学调整，不能伪装成跨天独立掌握。

更懂孩子 ≠ 增加云端依赖

最小本机观测、可解释规则和家长观察先行。新增素材继续审核，缺缓存保持真实状态。

增量落点

  • shared/：先在现有 learning / game-plan / contracts 附近抽取 evidence-view 与 learning-policy；规则纯函数可离线回放。
  • server/：Store 继续做事务边界；活动解析只接受冻结分支，观测接口不能写正式成绩。
  • src/：从 main.tsx 抽取学习运行器，复用 LearningTopbar、GameActionBar 和既有语音控制器。
  • tests/：保留现有正确性回归，新增分支恢复、线索泄漏、失败归因、旧计划兼容等有意义的覆盖。

本轮策略中的取舍

  • 先用规则与观察校准，不立即训练“个性化遗忘曲线”；单孩数据不足以支持复杂模型。
  • 现有 50 种玩法全部保留，默认路径先精选；每种扩展机制都说明服务哪个学习目标。
  • 继续支持不限量自选；将长队列切成小段，结束不会丢词，也不强迫做完。
  • 成长与奖励反馈真实努力、策略和已证实的收获；尊重休息，鼓励回到实物生活中用词。

05 / 方法与参考借鉴学习机制，并说明适用边界

研究、课程框架与产品设计参考承担不同角色。产品官方说明支持“它怎样设计”，不能代替这个孩子的学习效果验证。

方法与证据类型可靠启发项目落地与边界
检索练习 + 分散练习
研究综述 R1		检索与分散练习获得较高实用性评价；主动提取与重复看、听承担不同作用。R1把“先尝试→反馈→隔开再试”写进策略；不给被动听三遍同等的回忆证据。间隔和剂量要在本项目验证。
儿童词汇检索
原始研究 R2		一项小学词汇研究中，检索练习改善了一周后提示回忆，识别测试未出现同样差异；该研究的故事条件也未优于词对条件。R2分开测“想得起”和“认得出”；故事只在理解前提足够时加入。本研究并非针对该名中文母语零基础儿童。
自主、胜任、关系感
理论与研究综述 R3		自我决定理论把自主、胜任与关系需要作为动机的重要基础。R3给适量真实选择、可做到的挑战和稳定伙伴支持；把奖励设计当作需观察的假设，不保证奖章越多越有兴趣。
有引导的游戏
系统综述 R4		游戏中的儿童选择与成人指导值得结合；效益因学习结果而异，不能概括为所有方面都优于直接教学。R4先定义目标和必要练习，再让儿童选择适合的玩法。游戏完成率与词汇保持率分别观察。
输入、输出、形式与流利度
课程框架 R5		Nation 的四条线框架强调多种语言学习机会的平衡。R5为声音理解、主动表达、词形学习和熟词使用都留空间；不机械套用到每个幼儿小段的等时配比。
Khan Academy Kids

借鉴

默认个性化路径与可探索内容并存，角色帮助儿童进入活动；路径按表现调整。R6

一个推荐主入口，保留自选；通过能力与材料前提决定下一任务，儿童无需手选学习算法。

适用边界

其官方产品机制可参考；母语课程内容和效果不能直接移植到中文母语英语起步。

2022 年路径设计把复习和不同内容交错放进主线，减少学习者自行安排的负担。R7

07 / 验证与取舍同时看记忆、兴趣与操作负担

不把当场选对、玩得久或奖章多当作唯一成功。以下指标先建立基线，再决定目标值。“无提示”指只有正常题干，没有示范、首音或排除选项等额外答案帮助；图片或中文题干本身属于检索线索。

记忆结果：隔开后还能否想起

次日 / 第 7 天无提示回忆：分别报告正确、错误、提示、待核验和缺测数量
  • 按词、义项版本和任务方向分别统计；口头结果须家长确认。
  • 看词认义、看词读、由中文 / 图片想英文分别呈现，不混成一个分数。
  • 保持时间、测试方式和提示规则一致；补报批准异图 / 实物迁移。
  • 正确率分母标明“有效完成测试数”，同时列全部计划测试数与缺测，避免只看愿意测的词。

兴趣结果：是否愿意继续回来

记录主动启动、是否需催促、孩子是否愿意再选，以及拒绝 / 疲劳的具体情境
  • 主动启动由家长观察补充，不能仅从页面点击推断。
  • 结束时可选简单感受，但不强迫填问卷。
  • 把“愉快结束”视为成功路径；不追求无限延长屏幕时长。
  • 伙伴和奖励的效果单独观察，避免同时改变太多因素。

效率结果：记住一个词花了什么

匹配条件下：延迟确认回忆词数 ÷ 累计活跃学习分钟；同时展示家长投入与系统等待
  • 活跃时长排除暂停、后台和无操作等待；音频播放与有效思考单列，避免误删学习时间。
  • 记录步骤切换、失败恢复、重复示范、家长帮助次数。
  • 首次作答与提示后的作答分开；不通过牺牲困难词来美化效率。

正确性与体验护栏

未批准内容不出现；失败不判错；提示不冒充独立；旧会话与私有数据可恢复
  • 无密钥、缺音、静音、拒绝麦克风、暂停 / 刷新分别验收。
  • 观测日志没有原音、转写、密钥或个人敏感内容；仅本机最小字段，期限与清理由家长明确。
  • 按义项和证据版本核验，重复事件不重复计数或晋级。

适合单个孩子的验证过程

① 先观察当前路径

建议 3–5 次自然学习，记启动、卡点、提示与收尾；词数和时长由孩子承受程度决定。先不扩大新玩法。

② 用匹配词组比较一个变化

优先比较“固定重复示范”和“初次编码后隔项回忆”。新词组按熟悉度、词性、长度、可画性近似匹配，交替安排；两组学习时长、探测时间一致。

③ 按预先约定的门槛取舍

先过完整流程与安全恢复；再看延迟结果、主动参与与家长负担。样本不足、缺测明显或孩子疲劳时延长观察 / 调整方案，不宣布有效。

这是单孩探索性试验，不构成普遍有效性的证明。同一个已学词不适合重新当“未学控制组”；注意先后顺序、词难度、家长帮助、日常接触和测试本身带来的练习效应。G2 要在试验前写清成功标准与停止条件。

首轮完成的定义

可以进入小规模使用

  • 孩子在已准备内容中能走完“尝试→帮助→再遇→结束”，无需读长说明。
  • 音频故障、拒绝录音、离页恢复不丢记录，不伪造口头结果。
  • 策略能说明每一步为什么出现，旧会话仍能继续。
  • 能采集本机最小观测和次日复测的真实结果。

可以扩大默认范围

  • 事先约定的延迟回忆、兴趣与负担条件通过，原始计数可复核。
  • 尚未核验 / 缺测不被算作成功，失败原因有分类。
  • 新的材料和玩法逐个验收，不一次更换全部变量。
  • 家长能够退出试验、恢复默认策略，并保留已有真实证据。
