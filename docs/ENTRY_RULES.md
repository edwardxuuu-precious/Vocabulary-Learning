# 学习与复习：规则与场景矩阵

规则版本：entry-rules-v2。业务方向沿用已确认的business-v1；本轮按用户确认拆开工程准备与孩子验证。当前正式应用规则仍见 [MVP](MVP.md)，进度只见 [任务树](TASK_TREE.md)，验证只见 [验收](ACCEPTANCE.md)。

视觉与内容边界：保留原变形金刚主题、批准角色/背景及上传词书的原配图/缓存发音。业务流程调整没有换设计、换图片或替换成通用示例词的授权；正式体验使用家长已交付内容。

## 两个入口各自解决什么

| 项目 | 学习 | 复习 |
| --- | --- | --- |
| 默认目的 | 建立新词的声音、含义和初步词形联系 | 对已经认识的当前义项再尝试，发现需要帮助的方向 |
| 第一选择 | 继续当前任务，否则给默认5个未学新词 | 继续当前任务，否则给已学池的薄弱/到期目标 |
| 新候选 | 已交付、非示例、未删除、批准图片、发音就绪，当前义项尚未实际认识 | 同样就绪，且当前义项有实际认识/可信历史接触事实；认识不等于掌握 |
| 次级选择 | 按书选择、明确重学；重学标额外练习 | 按书/自选已学词、游戏；推荐以外标额外练习 |
| 无候选 | 没有新词可学；可去复习或找家长准备 | 无到期时明确完成；可主动练已学词或去学习，不偷偷加新词 |
| 完成与返回 | 描述认识与尝试，回学习页 | 描述练习与帮助，回复习页 |

默认量先沿用已有小组和上限，原型采用2词示例。词数、段长、非识字支持和帮助强度由后续A03/A04校准；原型参数不写进正式设置。

## L01 · 来源、冻结与续接

1. 正式单任务执行中，每个模式只有一个当前学习任务；学习和复习共享这个现场。入口只恢复当前题，不展示历史未结束任务列表。
2. 进入页面只预览，明确开始才创建任务。新任务创建成功后旧任务退役；失败保留当前题，重复请求返回同一结果，不重复替换。
3. 当前任务的词ID、义项、顺序、题目、原图及草稿保持冻结；保存休息后原题继续。新任务不删除逐词接触事实、作答、成绩或私有原音，旧任务不记完成或发奖。
4. 默认每日5个新词，明显的“调整词量”仅临时修改今天；自动新学只取未接触词，按今日实际已认识量扣除。人工选词可以选择已学词从头学或直接练习。
5. 兼容迁移只保留当前指针对应的未结束现场，其余旧活动标为被替换；历史保留，不能恢复成多份待办或重新占新词名额。
6. 冻结范围的词义、交付或素材变化时保留原快照并阻止过期继续；不静默删词、换词或记完成。
7. 帮助、设备失败、录音参与与正式正确分开；旧任务的迟到写请求不能推进或重新接管新任务。下文旧接口矩阵保留为兼容回归范围，不代表当前儿童端提供多队列管理。

## R01 · 已学候选边界

- 当前义项有完成首次认识的事实，才可进入新复习；不能因选中、预留、打开页面、完成其他词或拥有贴纸而入池。
- 已有可信接触事实按既有版本合同读取；只保留时间有效、义项版本相符且不早于重置的事实。新模块不把任意点击推断为已认识。
- “学校里学过”需要家长明确提供带版本/来源的标记，不能由应用猜测。本轮原型不实现正式课堂来源写入。
- 改义项须按新版本重新认识；原义项证据保留为历史。停用、删除、示例、未批准或缺音不得补入任何新候选。
- 按书复习只取该书已学池，其他词明确显示未学数量并引导去学习。默认推荐在跨书已学池内按到期目标挑选；未到期额外练习不推迟正式日期。
- 旧轮次冻结范围按L01保留，不把新的候选规则批量迁移到历史。口头录音只算参与，正式正确仍走合法核验。

## 原型、工程接入与真实孩子验证

- [原主题入口与隔离原型](ENTRY_PROTOTYPE.html) 默认进入正式应用并使用真实词书；只有勾选工程预演后才展示苹果/猫等明确标注的隔离示例，其流程包含双入口、推荐/按书、认识/认义/听辨/朗读/回忆、帮助、休息、恢复、完成和异常。
- 原型只保存自身浏览器命名空间；不访问应用API、不采集麦克风、不发云请求、不写孩子事实。音频/录音仅演示状态，页面明确标示，不冒充实听或真实保存。
- 正式L01/R01、L02/R02已接入来源/候选/默认推荐；新建纯新词学习轮采用meaning-recall-v1保护理解后隔项回忆，旧轮保留原序。O02私有简记承接机会/投入/冻结延迟计划和最小运行片段；工程验证见ACCEPTANCE，示例状态机不能替代真实孩子观察；整个G1按其余任务依赖推进。
- 正式L04在新建学习分段轮冻结guidanceVersion=1，优先核心操作；操作示意不含题目答案，与词汇示范分开。连续困难/静音/设备问题均有帮助、跳过与休息出口；旧轮保持原题，真实独立操作仍按A03/A04验证。

## 保存与续接的正式边界

- 普通回入口、暂停和保存休息共用保存关口：停止播放→等待当前操作→停止/保存实际录音→确认冻结位置→返回原来源。等待可留题；失败不显示已保存，可重试或明确只保留既有服务端事实退出。后一出口不声称保留未上传声音/草稿。
- 续接从服务器原活动、检查点/帮助状态和私有已保存声音恢复；基础题选择与部分拼写只作有界草稿，不授予完成。休息不发整轮奖，完成后不自动开轮；迟到回调不在退出后自动跳题/跳完成页。

## 新推荐复习的题干与帮助矩阵

| 方向 | 首次题干 | 正常线索 | 显式求助 | 留痕与有限后续 |
| --- | --- | --- | --- | --- |
| 看图/中文回忆英文 | 原词图＋中文，不显英文、不先播英文 | 图片和中文属于题干 | 听示范后才显示英文/词义；不会也可直接求助或跳过 | 保存先前录音/主动表示还不会；普通声音不判正确 |
| 看英文朗读 | 只给英文，不先播答案或给图义 | 英文词形属于题干 | 不会读可点帮助，无需先录出不会的词；之后可跟练 | 帮助后的原音标follow，不冒充独立朗读 |
| 看英文认义 | 英文＋范围内原配图选项，不先读答案/揭词义 | 选项图片属于题干 | 选择或明确求助后核对词义/听示范 | 首次实际选择保留，后续成功不覆盖首次；弱项辅助练习不冒充正式口头翻译 |
| 听音理解/看图选声音 | 任务音＋图片选项，或原图＋分开的声音选项 | 目标发音属于听辨题干，重听不自动算提示 | 还没听懂可看词图/词义并听示范；设备失败可重试/跳过 | 求助后同词保持练习/提示身份，音频不可用不计错误 |

新复习分段轮先回忆，再朗读，再认义，最后听辨；同词较早的帮助也会使后续方向保持有帮助身份。原目标结束后最多两词、每词一次再想；必须确实隔过其他词，补救过程不评分、不晋级或改正式日期。无法隔项或超出上限的困难留后续安排，不硬加题。旧轮、整本基础复习与主动游戏按冻结合同保留；真实理解与合适上限按A03/A04观察。

## 复习恢复与去重矩阵

| 条件 | 推荐与恢复口径 | 边界 |
| --- | --- | --- |
| 推荐/按书/自选/游戏交替 | 各自按原来源恢复同一范围、位置和帮助 | 不重抽、不自动重开；固定玩法仍固定 |
| 同词普通回忆＋中译英弱项 | 当前版本同方向只排一个；朗读/认义别名同理 | 听辨与英译中保持各自方向 |
| 原目标今天已结束 | 今日普通推荐不再拉回；无其他到期时显示结束状态 | 原音参与、帮助、跳过、不可用不写掌握；后续仍可再遇 |
| 录音已存但未继续/仅求助/再试 | 不提前记原目标结束 | 保存续接保留当前题，不隐含补完成 |
| 加练或重开 | 不推迟推荐提醒与正式到期 | 主动选择可重复，但不能伪装未到期的默认任务 |
| 跨午夜继续、完成后再加练、重启/备份 | 完成日来自原目标实际结束；所有有效历史参与去重 | 旧轮无时间不补猜；备份缺原音仍如实显示 |
| 核验晚到/改判/改义 | 当前合法证据决定方向与后续日期；今日已结束目标不反复召回 | 不让晚核验的旧答案覆盖较新答案；新义项另判 |
