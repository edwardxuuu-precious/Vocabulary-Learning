# 单词游乐园 UI 规范

以 Windows 电脑端为主，按浏览器内容区 1440×900 设计。首页延续已确认的机甲插画，学习、复习、测试和家长空间共用排版与控件。词图和短句图承担词义与情境。

## 商业产品参考

| 参考 | 对照问题与落地 |
| --- | --- |
| Duolingo 的核心页面与学习路径改版 | 首页学习与复习同排，降低伙伴与成长入口的视觉权重。学习页把待完成短句、待开始测试或当前任务提到首位，其他未完成任务使用描边按钮。 [核心页面改版](https://blog.duolingo.com/core-tabs-redesign/) · [学习路径改版](https://blog.duolingo.com/new-duolingo-home-screen-design/?lang=en) |
| Quizlet 的 Test 流程 | 测试准备集中展示范围、题数和开始按钮。答题看真实题数，提交前检查回答，提交后显示核验状态。 [Quizlet 测试帮助](https://help.quizlet.com/hc/en-ca/articles/360030642972-Studying-with-Test) |
| Shopify Polaris 的 Page 布局 | 用左上返回、页面标题、右侧范围操作建立固定阅读顺序。长词表和审核保留可见的保存或确认，删除和切换范围各有明确入口。 [Polaris Page 布局](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/page) |

## 布局与操作

| 项目 | 统一约束 |
| --- | --- |
| 色彩 | 页面用浅蓝灰 `#f5f7fc`，内容面板用白色，正文用深蓝灰 `#283a55`，次要文字用 `#58677e`。蓝紫 `#5653cf` 表示主动作、选中及进度；成功、待处理和错误使用各自颜色并配文字。首页保留基地背景与模块色。 |
| 排版 | Segoe UI、微软雅黑及系统后备字体。页面标题桌面 36px、窄屏 28px；题目标题 28px、窄屏 24px；说明正文至少 16px，操作、状态与字段标签至少 14px。英文题词、完整例句和重要数字按内容放大。 |
| 宽度和间距 | 内容、导航及操作栏对齐在同一条最高 1060px 的内容轴。边距使用 24px、16px，最窄 12px。间距以 4px 为基准，从 8、12、16、24、32px 取值。面板、控件、弹层圆角按用途统一。 |
| 电脑首屏 | 1280×640 内容区内，学习入口的当前任务、完成页的「开始测试」和常规题目的题干及下一步应可直接看到。学习图与作答区优先并排，较矮窗口收紧图高和留白。试题检查列表局部滚动，提交保留在首屏。家长编辑与审核优先显示表单及筛选，长列表可纵向滚动。1920×1080 时内容轴继续居中。 |
| 导航和进度 | 每个页面只有一个主要返回。连续任务用同一条顶部导航显示返回、真实进度和可用的帮助/休息。窄屏让进度独占一行，操作保留文字和图标。学习步数、短句和测试题数分别取实际数据。 |
| 页面结构 | 目录、成长、家长页使用返回 → 标题与页面操作 → 内容/筛选。题面使用导航 → 题目标题和必要指令 → 内容 → 操作。词书、自选和课堂安排的返回应回到实际入口。 |
| 家长工作区 | 电脑端使用侧栏导航，主区呈现当前分区、状态和操作。备课在同一张卡片显示当前词表、交付状态和素材进度。审核或交付待办就近显示主动作，已交付词表保留查看和编辑入口。家长测试固定在侧栏的独立区域，编辑与审核时优先显示当前任务。 |
| 操作与反馈 | 同一任务状态只有一个主动作。确认、提交和下一步靠右，跳过、取消或返回使用次级样式。主按钮蓝紫、56px 高，普通次按钮白底描边、48px 高，密集和图标按钮至少 44px。重听贴近内容，录音控制在录音区，状态在对应内容或操作旁显示。 |
| 小屏与弹层 | 320px 含滚动条仍能操作。通过换行、纵排、局部滚动处理列表、表格和棋盘。弹层留外边距，长内容内部滚动，关闭和主要操作可达。保留可见键盘焦点和无障碍标签。 |

设计数值由 `src/ui-tokens.css` 维护。跨页样式入口是 `src/ui-system.css`。页面标题、确认操作栏、任务导航和进度通过 `src/ui-layout.tsx` 复用。已有页面类负责局部排列、业务状态和原图尺寸。

| 页面 | 走查重点 |
| --- | --- |
| 首页、等待、休息 | 两个课程入口同排，等待态直接可回首页或找家长，休息计时独立。 |
| 学习、复习、词书、选词、词量、游戏目录 | 当前任务优先，备选入口清楚，返回对应来源，选词数量与确认同区。 |
| 基础题、旧题、扩展游戏、短句 | 导航显示实际进度。题面内重听和录音，操作栏统一。短句进入后自动示范两遍，句旁播放一次。 |
| 学习完成、测试准备、答题、检查和提交 | 单词与短句完成后突出「开始测试」。学习页也可进入本轮，续测用原题。 |
| 成长、图鉴与详情 | 共用页头和筛选控件，奖章、伙伴、学习记录使用实际状态。 |
| 家长备课、导入、编辑、图片、课堂、核验、记录、设置和测试模式 | 侧栏标明当前位置，子流程标题反映当前任务。长操作区可滚动，保存和确认保持可达。 |

按正式入口家族复查首页和等待态、学习与复习入口、选词和设置词量、词书和游戏目录、基础和扩展题、短句各阶段、完成与测试、成长和图鉴、家长备课/记录/设置/课堂/旧测试、家长测试模式和常用弹层。先验 1440×900，再验 1280×640 首屏和 1920×1080 居中布局。390px 和 320px 用于窄屏兼容复查。验收截图优先使用电脑视口。当前证据见[验收](ACCEPTANCE.md)。
