版本：1；工程准备版，真人使用后按O03收敛条件修订。

输入为任务ID、冻结范围/版本、变更和验收条件；真源为[PROJECT](../../PROJECT.md)、[入口规则](../../ENTRY_RULES.md)、[MVP](../../MVP.md)。

1. 查端口、来源和隔离数据前提；运行完整检查/测试/构建，日志留本轮Work_Progress。复用`scripts/entry-integration-qa.ts --continuity`或`--review-dedup`，默认不触达家庭档案/云端。
2. 验选择/取消不建轮、预览与开局、原主题/图片、提示身份、保存失败、刷新/重启、来源返回、完成与同目标去重。更改今日目标/范围另跑`tests/learning-choice.test.ts`。模拟原音必须明示。
3. 报告已实现/已集成/已验证，以及浏览器禁用、原音缺失和真人未验。服务/旧端口/fixture/选择器/并发问题先分层，再判产品错误。

范围过期或真实素材失败即保留原快照停止，不代孩子创建正式轮次。只关闭自建验收服务，保留正式应用。以当前证据更新[ACCEPTANCE](../../ACCEPTANCE.md)，不能把工程样例写成孩子结论。
