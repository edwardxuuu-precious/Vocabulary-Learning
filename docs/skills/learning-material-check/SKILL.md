版本：1；工程准备版，真人使用后按O03收敛条件修订。

输入为词书/范围、用途（新学/复习/迁移）与已有素材。先读[内容边界](../../MVP.md)和[W1](../../PROJECT_WORKFLOW.md)，沿用原机甲词图，不以示例补缺。

1. 只读核对交付、义项版本、图片批准版本和缓存；用[内容检查卡](../../TRIAL_HANDOFF.md)列清机械就绪与家长图义判断，未知保持未知。
2. 静态资源运行`npm.cmd run assets:check`；这是品牌资源检查，不能代替逐词私有图音检查。缓存只查现有清单，不发云请求。
3. 输出每类缺项/受影响范围及下一步；批准、交付、生成请求均等家长在正式入口按所见版本操作，技能本身不改变事实。

缺版本、素材未批准、额度/权限不明即停止该项准备，保留已成功部分。记录任务ID、技能版本、输入范围/用途、实际检查、输出位置和停止原因；不在项目日志保存私有原音、PIN或凭据。工程样例只证明流程，不算真人调用。
