description: 在单词游乐园任务结案或依赖变化时，把已验证事实回写任务树、验收和决策卡并生成固定Dashboard，不推断缺失的孩子数据。
---

版本：1；工程准备版，真人使用后按O03收敛条件修订。

输入为任务ID、现行代码/测试/运行证据、缺项和用户授权；先读[W5](../../PROJECT_WORKFLOW.md)和[业务记录](../../BUSINESS_RECORDS.md)的关联卡。

1. 工程事实与真实机会/延迟证据分开核对。收敛条件全部满足才改TASK_TREE；需要真人的任务只能回写准备和缺项，不靠改分母、改前置或模板填数结案。
2. 状态只写[TASK_TREE](../../TASK_TREE.md)，验证只写[ACCEPTANCE](../../ACCEPTANCE.md)，可改变下次行为的取舍写原决策卡；无新经验可明确无新增，不堆叠历史流水。
3. `npm.cmd run dashboard:build`后运行`npm.cmd run docs:check`；同输入哈希和叶子计数须一致。固定展示只读项目规划，不引入家庭词表或原音。

依赖未齐、真人分母未知、未获内容/核验授权时停止相应结案；其他独立工程仍可做。记录本次版本、输入任务/证据、输出、检查和异常；实际Skill是否减负须后续真实调用比较，不以新建三个文件宣称O03完成。
