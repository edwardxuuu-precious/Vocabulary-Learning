# 自然使用简记

用于A03了解孩子在现有应用里怎么操作，接到A04前不加入新的教学变化。流程与指标见 [业务工作流](PROJECT_WORKFLOW.md)，状态见 [任务树](TASK_TREE.md)。这是空白指引，不包含孩子基线。

先只看一件事：**孩子最近自己玩时，在哪一步需要大人告诉他下一步怎么做？** 例如停在选入口、没有听清、看不懂玩法、录音后不知道继续。没有观察过就记“不知道”。不需要先回答听说读能力清单。

## 一次机会怎么记

1. 先确认用的是家长已交付内容，声音和设备能用；不能用则记缺什么，不要求孩子开始。
2. 自然提供一次开始机会。孩子想开始、拒绝或暂不想，都如实保留。
3. 孩子停住时，记停在哪一页，以及大人实际做了什么；例如“指了一次继续按钮”，不要先写“能力差”。
4. 结束时只记实际发生的：本小段完成、主动保存休息、拒绝/疲劳、设备问题或还没观察到。
5. 若自然出现一次恢复机会，记能否接回原位置及是否仍需指点。没有出现就留未知，不为凑表反复重开。

可以只先说一句：“点了复习，到录音后停住，我指了一次继续。”其余由后续核对补齐，不让家长一次填完所有维度。

## 可选的简记字段

| 字段 | 填什么 |
| --- | --- |
| 机会ID与实际观察条件 | 同一次机会用同一个ID；学习/复习、现有内容版本、是否测试档案分别注明 |
| 事前是否可用 | 已交付且设备可用 / 不可用及原因 / 不知道 |
| 是否自己愿意开始 | 是 / 否 / 不知道；拒绝不删 |
| 停在哪里、帮了什么 | 可见页面/动作、帮助次数；没有停住也可记 |
| 怎么结束 | 完成预定小段 / 主动休息 / 拒绝或疲劳 / 设备失败 / 未知 |
| 下次接回 | 原位置及所需帮助 / 尚未观察 |
| 家长投入（有记才填） | 备课、补缺、指导、核验主动分钟；等待另记；没有记不估算 |

实际简记入口：家长入口 → 学习记录 → 使用简记。先只选择“停在哪里”；未知留空，同一机会选“补记”更新。投入按实际主动分钟记录；延迟观察先冻结条件，普通录音不算答对。工程示例和家长测试不构成孩子基线。

不要把孩子原音、转写或逐题私有明细写进项目文档、任务日志或Dashboard；O02在本机私有分表承接，家长授权可单独导出。项目看板只登记是否具备有效证据、缺项与限定结论。

## 如何结束这轮起点观察

取得一次小段与一次自然恢复观察，并能说明选择/帮助/结束/设备及未知项时，形成有限的起点描述；孩子拒绝或条件不足也可以形成“暂不可判断”的受限结论。未实际观察时保持未知，不用测试样例替代，也不补出记忆正确率。

A04据实际起点再约定一轮有限试验的材料、单一变化、观察上限和停止条件；次日/第7天仅是后续探测条件，没有项目日期排期。
