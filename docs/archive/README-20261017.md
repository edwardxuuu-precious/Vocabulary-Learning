# 单词游乐园

给 6–8 岁、中文母语、英语零基础孩子使用的本机单词学习应用。家长准备指定词表，孩子用大图、读音和点击练习理解词义、听音辨认、看图回忆，并通过跨天复习检查记忆。提供单词示范发音、三遍本地录音跟读和可选的自主录音挑战；挑战单独转写并由 Codex 初判，口头正式成绩由家长核验。聊天与语音指令停用。

## 看、读、翻译独立测试

学习完成后点“挑战测试”，孩子无需家长 PIN 就能开始、录音、提交和刷新恢复。本轮已学词自动选取最多5个，完整测试最多20项；准备页只显示题量。也可选择“到期复测”，只出到期能力项。家长空间 → 学习记录 → 集中核验与现场测试可核验已提交回答，并保留旧的现场判题方式。

首页右上角“我的成长”默认进入“奖章与词汇”，先展示当前会词量、练过的词和8枚奖章；“学习打卡”“能力进展”“单词记录”分模块打开，每次只显示一个模块，可一键返回成长首页。打卡模块查看日历与累计/连续天数，能力模块查看四项独立记录，单词模块保留筛选和搜索。完成页显示真实打卡及累计成长，练过和会的词分开；四项独立测试都通过才计入会词量，跟读/提示不计入。相同英文词合并计数，跨天四项通过另列巩固；到期显示待复测，不自动视为忘记。称号只对应会词里程碑，不是英语分级或发音评分。

学习、游戏与完成页使用晴空草原、宁静海湾、云端花园三套低对比背景，每轮按会话固定，暂停和刷新后不换；新一轮重新选择。[成长记录、奖章和背景规则](docs/CHILD_GROWTH.md)。无需新增外部服务配置；独立体验运行`node --import tsx scripts/growth-qa.ts --port=8795`后打开`http://127.0.0.1:8795/__qa`，场景使用示例与合成历史，不写正式档案、不调用云服务。

- 中译英自动播放中文提示，播放结束才可录音；读和英译中只显示英文，不先播示范。三类口头题逐题录音，最多20秒，保存后可在整轮提交前重录；权限拒绝、空录音和上传失败可重试或跳过。
- 看：只显示英文，从2–3张已批准图片中选意思，服务端按首次选择判定；选项不足明确记为暂无法测试。按中译英→读→英译中→看分组，每组打乱词序，整轮结束后统一核对，不提前播放答案。
- 整轮提交后显示“挑战完成，正在批改”，孩子可离开。Scribe v2 逐段转写成功即保存，再由 Codex 一次整轮初判。家长集中回听、修改并勾选批量确认，服务端校验所见版本；AI 不产生发音分数，也不提升正式复习级别。
- 家长核验、重试和原音回听需要30分钟内存授权；刷新或回儿童首页后重新验证。儿童挑战的创建、读取、保存与提交不要求 PIN。中断任务保留真实状态，由家长重试未完成阶段。
- 四项能力分别按1/3/7/14/30天复测，同日最多晋级一次；答错或有提示回到次日复习，未确认和跳过保留待测且不晋级。孩子先做图片辅助、独立尝试后核对的对应练习，练习完成不改变测试级别，口头能力仍需家长确认。
- 弱项练习与原有旧词复习共同占每日任务预算，必要时减少新词；同一弱项当天最多练一次，进行中的旧会话沿用原计划。家长记录分别展示四项结果、判定来源和下次复测，不合并成掌握分数。

原音暂存 `data/assessment-recordings/`，不经公共素材接口提供、不进入 Git 或常规备份。核验保存后删除对应原音，失败则持久化待清理并重试；文字与核验历史保留。备份恢复后未核验题缺失原音，须重新测试。正式进度按作答日期重算，保留核验日期；改判不重复计分。

沿用现有 ElevenLabs 密钥（需 `user_read` 及录音文件转写权限）和官方 Codex ChatGPT 登录。批量 STT 独立按 CNY 3/小时做保守消费估算；只允许确认的 Free 账户、关闭超额计费且仍有包含额度，服务端额度不足即停止，成功免费请求记0元并保留秒数。Codex 仅用已有订阅额度；不充值、不升级、不换付费服务。中文提示优先缓存，缺缓存仍经过现有免费额度护栏。

## 本机运行

需要 Node.js 24（当前电脑已安装）。初次运行：

```powershell
npm.cmd install
npm.cmd run build
npm.cmd start
```

打开 `http://127.0.0.1:8787`。也可以双击 **启动单词游乐园.cmd**；启动器会检测已有服务并打开网页，缺依赖/构建时进行准备。开发模式为 `npm.cmd run dev`，网页地址 `http://127.0.0.1:5173`。

双击 **停止单词游乐园.cmd** 可关闭本项目的后台服务。修改 `.env` 后，先停止再启动；关闭网页标签不会停止后台服务。

界面和进度保存在本机；生图与首次合成发音需要相应外部服务，学词复用本机缓存。当前不使用语音识别。内置演示插画明确标记为本地示例。

## 家长准备

认识单词页全程自动讲解：先显示英文并读一遍 → 词性标签与中文释义同时出现，只朗读中文释义 → 再读英文 → 展示完整配图 → 再读英文和中文释义 → 停留1秒后自动进入练习。孩子无需逐步点继续或玩一玩，可随时重听。静音或播放失败时显示真实提示，按阅读节奏自动展示；暂停、家长门、切后台或离开会取消推进，刷新从本词开头恢复。自动衔接只完成认识步骤，不产生答对或掌握证据。图文居中紧凑排列，英文短词桌面88–104px、窄屏64–76px，图片桌面230–300px、窄屏280px；长词缩字、短语按词换行。听辨、跟练和拼字保留原布局。

## 单词发音

当前仅使用已有ElevenLabs TTS读出英文单词，en-US、清晰语气、不加情绪标签；认识词时自动播放，也可点击喇叭重听，听音练习和声音选项复用同一播放器。本地缓存可重复播放，不经过Codex对话。中文操作提示保留在界面，不合成闲聊或奖励话语。

示例12词已全部缓存，保留用于明确的示例体验及相同英文发音复用。正式词表确认后自动准备，后台全局一个串行任务；另一本正在准备时，新书保留并可稍后点“补齐发音缓存”。语音额度、预算、认证或网络错误即停，不自动重试、降级服务、充值或升级，已成功缓存保留。当前仅支持现有ElevenLabs缓存准备；页面不读取供应商实时剩余额度，使用实际请求结果反馈不足。

维护时可运行 `node --import tsx scripts/cache-word-audio.ts` 仅检查正式词表；添加 `--apply` 才生成缺失项，`--include-samples` 才显式包含示例。脚本保留词条大小写，参数与喇叭一致。音频位于忽略的`data/speech/elevenlabs/`，缓存报告在`artifacts/word-audio-cache-YYYYMMDD/`。

无需新申请实时语音API或充值。跟读通过浏览器麦克风录音，每遍最多20秒，无静音倒计时；未录到声音不增加遍数。录音仅保留在本次页面内存，不上传、不落盘，离页/刷新释放；麦克风失败可重试或点“这次先跳过”。完成记录为correct=false、practiceOnly=true，录音完成用source=speech，跳过用source=click，不创建独立回忆进度。Codex继续负责家长词义补全和生图，无需新增密钥。
