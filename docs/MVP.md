# 单词游乐园产品规则

面向 6–8 岁、中文母语、英语零基础孩子的单孩 Windows 本机应用。家长备课，儿童通过图片、英文发音和点击完成学习；不包含公开部署、多用户账号、跨设备同步或自动发音评分。使用流程见 [README](../README.md)，模块入口见 [PROJECT](PROJECT.md)。

## 备课、词书与交付

1. 默认导入英文，每行一词/短语，兼容中英两列、Tab 与 CSV，每次最多 500 行；坏引号、缺列、重复英文或含混义项须先修正。编辑输入后旧预览失效。
2. Codex 通过官方登录提出中文、词性、配图思路和多义提示；草稿不写正式事实。补全每批 20 词、全局单任务、进程内最多 8 份，可停止与补缺。缺少必要内容不能确认；内部导航保留草稿，刷新不保证恢复。
3. 家长确认后保存初始停用的正式词书，分别启动发音与图片准备；一项失败不回滚词书或成功素材。12 个内置词是 `isSample` 示例，默认停用，不自动补入正式词书。
4. 发音按英文/音色/模型/语速/音调复用精确缓存，全局串行；只有实际请求 owner 预留/结算预算。图片只为缺失 draft/error 排队，全局串行；review/approved 不被自动重画覆盖。GET、服务重启和失败不自动重发生成；停止阻止迟到结果。
5. 图片审核逐项绑定所见 URL、英文、义项和学习版本；有任一过期项整批拒绝，不能隐式批准全部。选择只包含已加载的待审图；重画、翻页、换书或义项变化清理旧选择。
6. 审核不等于交付。家长显式交付全部或已备好子集；交付词必须有已批准图片和当前英文缓存，已启用书新增批准词也检查音频。失败保留成果、显示缺项，不默许使用占位图。

词表编辑带 `packContentRevision`，过期返回 409；改名、改词、增删和启用分别提交。词义/词性变化使当前学习版本与图片失效，旧证据保留为历史，未改词保留素材与进度。删除采用软删除并挂起受影响未完成轮次，保留历史、素材、费用和原音，不发云请求。生图快照绑定义项、词性、配图说明与兴趣，旧任务不得覆盖新版本。

## 儿童学习与调度

- 首页 → 学习大厅 → 推荐/自选/恢复 → 认识与练习 → 本轮完成；另有挑战、伙伴图鉴与成长。儿童不需打字或读懂长说明；无可学词书时提示找家长，不自动开启示例。
- 推荐默认每日最多 3 个新词、每轮最多 6 个复习词、约 10 分钟。新词按词书创建时间和批内顺序，复习跨已交付书按到期与弱项优先，同优先级交错批次。
- 按上海日期累计当前版本首次接触；未完成轮次的新词预留也占推荐额度。手选可超推荐上限，仍计入接触数量；停用示例不占正式额度。
- 每步按 30 秒估算题量，任务预算为 `floor(sessionMinutes*60/30)`；先容纳复习，再放完整新词，不截断目标凑数。到期积压超过复习上限时线性减新词，达到两倍暂停；复习上限为 0 时不减新词，仍遵守总预算。
- 新词完整覆盖 learn/recognize/listen/sound/read/recall；开启拼写且适合字母词时再加 spell。认词先不播英文；听音题先听再选；独立朗读先录音再开放示范。认、听、读分别记录，录音保存只算练习。
- 自选图片多选数量不限，完整保留所选词，预计时长只作参考。全选覆盖当前筛选的所有页并保留其他选择，取消全选清空全部；选择接触过的词后并列显示“从头学”（完整讲解再练习）与“直接练习”（旧词跳过讲解），各点一次即开始；未接触词始终先认识。“接触过”来自实际讲解/练习，不能表示已掌握。
- 自选重学与追加旧词练习由服务端强制 `practiceOnly`，不推进或推迟正式复习日期。当天推荐完成后可混练旧词；少词可重复，不拿示例凑数。
- 整本复习使用 `practice/relearn + packId + wordIds`：儿童直接选择整本已交付且非示例词表的所有已批准词，不受每日推荐额度或单轮时长估计截断。未备好词显示数量并排除；未学先认识，已学直接练习，沿用家长选择的编排策略（缺省分段回忆）。题目、选项和配套游戏词池限定该书；服务端拒绝跨书、停用书与示例书范围。
- 游戏入口追加 `game: random | GameKind`，仅在指定已交付词表的练习中使用。服务端按真实缓存、素材版本、词类及家长开关生成可玩目录；固定玩法只出该玩法，无法参与的词如实排除，条件不足拒绝，不降级为其他玩法。随机队列仅创建时抽取，冻结活动、分组、选项和种子；游戏只记练习，不执行新词讲解或自动写正式成绩。
- 复习、随机游戏、每个指定玩法以词表及玩法区分未完成轮次；同类重复开始接回原轮次，不覆盖其他进度。`packGame`保存选择和原始范围，备份校验/清洗、重启、从头再玩和完成后再玩均保持来源；旧版组合轮次不改写。新建整本复习采用基础认识/回忆题面。
- 词表练习冻结书标识、书名、词序与任务，以 `practiceOnly` 记参与，不写虚构掌握或推迟正式日期。同一本同类未完轮次复用，独立于推荐和课堂安排；默认小段只显示本段进度，整本范围不会因此缩成2词。恢复、备份清洗和显式从头再练保留词表来源，新增词不静默塞进已开始的轮次。
- 每轮持久化词序、任务、随机种子、题图音选项、已完成步骤和当前活动。新轮次不覆盖旧轮次；恢复必须指定轮次，旧会话保持原合同。当前未完成与最近完成指针分开；重复提交不重复推进或发奖。
- 到期复习优先错/提示/跳过目标，再练尚未核验和其他目标。听辨与可选拼写按独立证据推进，跨天间隔 1/3/7/14/30 天，同日最多晋级一次；提示、体验、跟读、录到声音不算独立掌握。改义项只重置当前版本。

### 轮次管理与课堂范围

- 大厅以当前轮次与继续玩为主，其他玩法保持次要层级；卡片内“更多”打开独立调整弹窗，换词或从头练须二次确认，取消不改变进度。普通学习可明确结束重选或从头再练。结束采用挂起并记录原因，不记完成、不发奖、不删除历史或原音；仅释放未接触新词的预留，已经发生的接触仍计入当天。重开原子创建新的练习轮次，重复请求返回同一个替代轮次，旧轮次不能继续作答。
- 家长授权后保存一份当前课堂计划：整课范围、本次重点与顺序、学习版本及每段5–15分钟的估计预算。新建另一课使用新计划标识；更新带版本号，过期整份拒绝。
- 儿童开始课堂小段免PIN，按当前重点顺序选取完整词任务，不能截断单词凑预算。新词先认识，已有接触的词跳过讲解；课堂练习不受每日推荐3新词的默认量限制，整课范围不直接变成单轮任务。
- 本课范围、本次重点、实际本段词数分别显示。单段计划冻结，调整重点只影响下一段；已完成词只按同一课堂、同一学习版本的真实完成记录累计。素材或词义过期须家长重新确认安排，不静默替换。
- 课堂练习和重开均为练习，不晋级或推迟正式复习日期；接触记录、正式测试与家长核验保持原有边界。备份保留课堂安排、实际进度和轮次结束关系，校验进度与历史一致。

### 分段回忆策略

- 儿童页面启动新轮次显式选择 `memory-loop`（家长可选 `classic`）；API 未指定且设置缺省时保持旧调用兼容。策略冻结在轮次 `learningPolicy`，恢复不重新排课；设置切换仅影响以后新建轮次。
- 新词每组最多 2 个，按 learn → listen → recognize → recall → sound → read → 可选 spell 穿插；一词时不虚构隔项间隔。当前新词不按识字水平分层，C1 仍待实施。
- 回忆采用完整图片与词语发音卡，中文线索为首要文字，点词语旁的“听示范”才显示英文；播放状态与进度来自实际媒体事件，播放时不录音。开始录音、说完、保存后继续保持同一位置，回放/重录为次要操作。先隐藏英文与示范，孩子显式点录音；按需听示范立即持久化 hinted，后续录音为 follow。有效私有录音保存后才能提交 recorded，也可明确 skipped。均 `correct:false / practiceOnly:true`，不直接写掌握或口头正式成绩。
- 每 8 个原子任务设保存休息点，成组活动延后到组尾，不拆目标。服务端阻止未确认休息点之后的新答题/完成；旧请求重放不重复推进。回大厅或关闭页面保留休息点，只有显式继续才开放下一小段；小段不发整轮贴纸。
- 新主线v3按目标、词性、已认识词池、审核素材和缓存自动排课：原8类基础上加入宾果、排队、双目标收集、局部揭秘、词义寻路等；明确可做手势的动作词可进入听词模仿。语义类优先匹配颜色/位置/分类/反义及动作，不能凭词性臆造关系；语义素材必须已审核、词义版本一致、所需发音已缓存，情境/拼写继续遵守家长开关。主线共有41类适配（含稳定的回忆/朗读传送门），不代表每份词表全部可玩。
- 编排按本轮使用频次优先少用玩法、抑制连续重复，控制小段内听辨/拼写机制数量；相同种子恢复不重新抽。配对任务必须相邻且位于同一休息点内，共用棋盘与真实两个目标，不增加或重排目标、不借未选或尚未认识的新词。参与型听音后保留客观sound检查；仅有单个到期听辨目标时仍需客观题，单词不足不凑任务。认义、朗读和主动回忆的证据保持独立。
- 主动回忆维持先想后提示的录音流程，不为增加游戏而重复口头任务。自由绘画、亲子出题和额外口头情境仍在独立游戏入口；整本复习保留原基础认识/回忆和独立保存的游戏入口。
- 新策略按上海日期在首次接触的次日安排未评分回忆提醒；同目标中译英测评练习去重。只有推荐内回忆参与可把该提醒移至后一天，额外自选不推迟；正式测评日期/分数仍由原独立合同维护。不是自适应遗忘曲线，也不提供自动回忆正确率。
- 认识、练习与奖励共用轻色卡片和稳定操作位置，儿童页不重复展示认听读状态条；返回直接到大厅并保留轮次。回忆/朗读有效原音保存后，单次继续先提交参与再推进；明确跳过同样先保存再推进。请求失败、离页或暂停不自动连跳；独立答题保留反馈及显式继续。
- 到休息点先停下；大厅点击继续玩视为显式继续当前小段，免去再次确认，但刷新/后台不会自动确认。完成页表述实际参与，温和提醒明天回来；家长概览展示当前版本的回忆已录、未听示范、有帮助和跳过，正式核验独立展示。实际记忆、兴趣和合适段长待儿童使用验证。

### 发音播放与体验升级

- 短单词、释义与录音回放完整下载并解码后播放，复用一个输出 AudioContext；当前及随后两个目标仅预取已有缓存。首次、后台恢复、录音结束及静默超过5秒后，先输出约400ms轻预热。预热不计示范或学习证据；快速重播仅保留最后请求，暂停/离页取消旧播放。蓝牙开头截断仍须同设备实听验收，不能由自动化替代。
- 本机合成轻提示音：正确、再试和录音保存分开；与文字/图形并用，不覆盖单词。跳过或服务失败不播放答错音。默认开启，家长设置可单独关闭，总声音关闭时提示音同时关闭；重复响应与刷新不重放。
- 新主线使用v3；v1/v2在下一个已完成休息点点击继续时，由 `POST /api/session/upgrade-experience` 原子升级并确认休息点。只替换未开始题面，保留ID、词表、目标和顺序、已完成题面/状态、原音、奖励及有界旧编排快照链。不在后台自动推进。写入携带当前planVersion，过期页面返回409并刷新；重复升级幂等，兼容既有v1→v2请求及旧备份，测试模式同样隔离。
- 家长设置的“声音检查”只读现有缓存，支持原始/新版对比，不记接触、成绩或奖励；蓝牙与扬声器、静置重播由家长判断。源文件缺音未经证实前不重生成、不替换音色。

## 自动讲解、游戏与原音

v2及以后认识页同时显示完整图片、英文与中文，默认英文一次、中文释义一次，再自动进入练习；重听由孩子主动点击。旧编排未升级部分保留原有讲解顺序。词性随家长确认的释义显示，不另读或推断；长词适配、短语换行，方形图片 contain 完整显示。讲解仅记录接触，不写独立答对。静音不请求音频，播放失败显示真实提示并按阅读节奏继续；暂停、后台、离页或义项变化取消旧推进。英文读缓存，中文首次合成受免费额度和预算约束，不切换系统音色。

当前 50 种玩法以 [注册表](../shared/game-registry.ts) 为准，逐项条件见 [机制库](VOCABULARY_GAME_LIBRARY.md)，界面见 [游戏 UI](GAME_UI_DESIGN.md)。按技能、词数、词性、已审核素材、缓存和开关筛选；经典编排维持每组最多 3 类、每轮最多引入 1 种新机制；新版主线按目标与素材条件轮换简短玩法。故事、编程、双词组合、数量订单和双词分料按实际两个目标计步，不把整组视为一步。新增 30 种只记练习，保留必要客观听辨检查。

- 题目、棋盘和动作检查点冻结，服务端核对选择与移动轨迹；通用完成接口不能绕过活动顺序。多选排除、重试、揭晓或提前听答案后持续标记提示；目标英文作为听辨题面本身不算提示。
- 不足两个清晰选项、缺素材或缺音频时回基础练习并如实记体验；不得编造关系或拿未选词、示例凑数。亲子、进阶情境和拼写默认关闭。
- 已批准词图可派生四块拼图，中文回忆复用原确认释义。关系/动作/短句候选必须由家长预览确认；素材记录词义及关联版本。开局只读缓存，儿童路径不触发生图或补发音。
- 家长交付时可授权后台补两类派生玩法的缺失发音，每批最多 5000 缺失字符，受免费额度/预算约束，可停止；其他额外素材须按所见版本确认。详见 [游戏素材](GAME_MATERIALS.md)。
- 原策略的“自己说一说”先实际示范 3 遍并显示进度，再让孩子录 1 遍；一段已保存录音即可继续，可回放或重录。中断示范从第一遍重听，失败可重听或跳过，不虚记次数；减少动态效果时使用静态高亮。
- 所有口头游戏、朗读和中译英练习复用私有本机录音，每段最多 20 秒，保存/跳过分别记录，不识别、不评分、不晋级。空录音不保存，失败可重试/重录/跳过；暂停、后台、离页释放麦克风和临时 URL，刷新/重启可恢复已保存原音。
- 练习原音仅在 `data/practice-recordings/` 私有留存，当前活动可回放，历史须家长授权；普通备份只有元数据，恢复缺音标 missing。麦克风失败区分网页拒绝、系统拦截、无设备和占用；失败不记成功。

## 自主挑战与正式证据

- 儿童创建、作答、录音和提交无需 PIN，每轮 1–5 个已学且可学词、最多 20 项，顺序为中译英 → 朗读 → 英译中 → 看词选图。到期测试只出对应维度；推荐优先到期，其次初学次日起缺少的首次测试，进行中/待核验/同日已测不重复推荐；完成页可显式挑战本轮。
- 中译英直接显示中文，不播放答案或等待语音；朗读不先示范。口头题每段 0.1–20 秒，规范 16kHz 单声道 PCM16 WAV，最多 640044 字节；空录音/权限/网络失败可重试或跳过，不记错。提交前可重录，选图首次选择不可替换；提交冻结题目、版本、原音与实际作答时间。
- 每段转写成功立即保存，再由 Codex 整轮一次受限结构化初判。AI 的 matched/practice/unclear 是建议，转写匹配不等于发音评价；看词选图由服务端核对，口头正式结论只能由家长按所见回答/建议/核验版本批量确认。
- 后台持久化 queued/transcribing/grading/review/failed/interrupted 及 runId；重复提交不重复派发，重启标中断，由家长显式重试；已有结果不重发，迟到响应不覆盖核验或新义项。
- 核验、回听、重试及旧现场测试/actions 要求 PIN 产生的 30 分钟 Bearer 授权，仅存页面/服务内存；刷新、回儿童首页、改 PIN、恢复和重启失效。旧家长现场流程显式选择 `workflow=parent`。
- 正式记录保留作答时间 `createdAt` 与核验时间 `confirmedAt`，按作答日期重放 1/3/7/14/30 天规则；同日不重复晋级，错误/提示次日，未确认/跳过不晋级。改判保留审计并重算，旧义项不影响当前；AI 弱项建议只进练习，不进正式进度。
- 挑战原音仅存 `data/assessment-recordings/`，不提供公共媒体，不进 Git、日志或普通备份；核验后标 purge-pending 并删除，失败维护重试。恢复备份缺音标 missing，不据此判对。练习原音不套用此删除流程。

## 家长、成长与数据

- 家长首次自设两次一致的 6 位 PIN，无默认口令；服务端只存独立加盐哈希到 `data/parent-pin.json`，输错 5 次暂停 30 秒。改 PIN 需当前口令；本机停止服务后可用维护命令重置。PIN 只保护家长网页入口，非多用户/全量 API 鉴权。
- 家长空间以备课、学习记录、设置组织，课堂安排与新建词表并列在词表工具栏；按需展开低频工具，显式保存，设置页签标明未保存更改；检查缓存未完成不能报成 0。
- 成长的练过与会词分开：当前义项四项最新完整测评均独立通过才算会词，同英文合并计数，跨天巩固另列。8 系列 128 枚奖章首次达成在事实事务写入，已得永久保留；当前能力随最新证据更新。规则见 [成长](CHILD_GROWTH.md)。
- 成长从完成页进入时返回原完成页，各子页的返回均一步退出成长；不会因浏览记录重领奖励。图鉴默认展示短介绍，长文按需展开，详情可连续切换角色。
- 20 位伙伴仅作图鉴和学习陪伴；学习背景按会话固定，刷新/暂停不轮换。素材修改不改变学习证据，原批准图片不因主题变更批量替换。
- SQLite 保存学习事实，旧备份/会话兼容；备份保留本机用量和删除状态，严格校验版本、顺序与证据。PIN、密钥、授权和两类原音不导出；恢复前保留旧副本，运行任务未结束时拒绝恢复。

## 接口与外部边界

数据形状以 [shared/contracts.ts](../shared/contracts.ts) 为准，路由与验证以 [server/index.ts](../server/index.ts) 及 `tests/*api*` 为准。失败返回 `{error,code?}`；同源、题序、快照、版本、上传和预算检查在服务端执行。主要接口族为 `/api/parent-gate`、`/api/import`、`/api/packs`、`/api/words`、`/api/session`、`/api/attempts`、`/api/practice-recordings`、`/api/assessments`、`/api/speech`、`/api/backup` 与 `/api/restore`；不要在多个文档维护第二份完整路由合同。

ElevenLabs 负责缓存发音与挑战文件转写，Codex 官方登录负责词义、生图与初判。免费账户/剩余包含额度/关闭超额计费及本机预算满足后才发相应请求；失败或额度不明即停，不充值、升级或静默换服务。缓存可独立于新增请求预算播放；本机费用是估算，不冒充账单。没有配置或登录时显示真实状态。

聊天、兴趣访谈、语音指令与实时云端识别保持停用，旧数据及仍被引用的适配器保留；状态查询不触发预热/生成。Codex 不复制 OAuth 凭据，文本初判禁用工具与文件写入，图片仅在隔离素材目录生成，批准前不能进儿童词书。

## 验证边界

完整门槛为类型/资源/文档检查、全部自动测试、生产构建及隔离本机启动。恢复、备份、版本冲突、提示/独立证据、录音私有边界、免费额度和取消幂等须保持覆盖。模拟服务只能证明本机编排；真实云端可用须真实请求证据，不能由整理任务自动发起。儿童实际理解、口音与长期记忆效果另行观察，当前结果只写 [ACCEPTANCE](ACCEPTANCE.md)。
