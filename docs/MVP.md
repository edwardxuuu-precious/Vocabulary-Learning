# 单词游乐园产品规则

面向 6–8 岁、中文母语、英语零基础孩子的单孩 Windows 本机应用。家长备课，儿童通过图片、英文发音和点击完成学习；不包含公开部署、多用户账号、跨设备同步或自动发音评分。使用流程见 [README](../README.md)，模块入口见 [PROJECT](PROJECT.md)。

## 逐词执行与兼容

当前儿童入口由逐词档案与统一执行合同承接，完整规则见[体系重构](LEARNING_REFACTOR.md)。已学事实长期保留；旧会话和下文原API规则继续兼容读取与显式恢复，新默认推荐不把旧预留当已学习。正在进行的题、录音和草稿原位保护；未来已被证据覆盖的题另记覆盖账本，不填入原完成步骤。

初学、短句补学、定向巩固、缺项检查和正式到期检查按明确目标衔接。检查只覆盖合法当前义项与已教用法；未提交回答继续原检查，已提交口头回答待家长核验。听辨/拼写、录音参与、正式四向证据和永久奖励保持原含义。新启动与保存有模式、版本、请求回执及休息限制，重试和迟到响应不能覆盖别处的新进度。

## 备课、词书与交付

1. 默认导入英文，每行一词/短语，兼容中英两列、Tab 与 CSV，每次最多 500 行；坏引号、缺列、重复英文或含混义项须先修正。编辑输入后重新解析并绑定新预览；按英文精确身份保留未改词的词义、词性、配图及人工修改，重排不重做。改英文或显式改源词义只使对应词的旧草稿失效。
2. Codex 通过官方登录提出中文、词性、配图思路、多义提示及结构化拼写建议；原英文始终保留，建议须家长明确采用或保留原词，不能自动更正或虚构词义。核对页可原行修正并只补该词，也可筛选待处理/批量只补缺项；未确认拼写建议不能提交。草稿不写正式事实。补全每批 20 词、全局单任务、进程内最多 8 份，可停止与补缺；内部前后步骤保留草稿，离开导入或刷新不保证恢复。交互依据见 [词表核对设计](IMPORT_REVIEW.md)。
3. 家长确认后保存初始停用的正式词书，分别启动发音与图片准备；一项失败不回滚词书或成功素材。12 个内置词是 `isSample` 示例，默认停用，不自动补入正式词书。
4. 发音按英文/音色/模型/语速/音调复用精确缓存，全局串行；正式本机默认保留旧音频，只有显式配置裁剪限制的调用方才清缓存，新增短句不自动移除已备词音；只有实际请求 owner 预留/结算预算。图片只为缺失 draft/error 排队，全局串行；review/approved 不被自动重画覆盖。GET、服务重启和失败不自动重发生成；停止阻止迟到结果。
5. 图片审核逐项绑定所见 URL、英文、义项和学习版本；有任一过期项整批拒绝，不能隐式批准全部。选择只包含已加载的待审图；重画、翻页、换书或义项变化清理旧选择。
6. 审核不等于交付。家长显式交付全部或已备好子集；交付词必须有已批准图片和当前英文缓存，已启用书新增批准词也检查音频。失败保留成果、显示缺项，不默许使用占位图。

词表编辑带 `packContentRevision`，过期返回 409；改名、改词、增删和启用分别提交。词义/词性变化使当前学习版本与图片失效，旧证据保留为历史，未改词保留素材与进度。删除采用软删除并挂起受影响未完成轮次，保留历史、素材、费用和原音，不发云请求。生图快照绑定义项、词性、配图说明与兴趣，旧任务不得覆盖新版本。

## 儿童学习与调度

- 首页采用已确认的插画式学习大厅：学习/复习是整块可点击的主模块，伙伴图鉴/成长为次级模块，家长入口独立放在右上；基地建筑与地面作为整页环境背景，欢迎区只保留文字；复用原批准机甲、基地和品牌图标，图鉴数量来自实际目录与解锁状态。学习进入新词推荐/恢复，复习进入跨书已学到期推荐/恢复；按书、自选与游戏作为显式次级选择；词语、机甲词图与缓存发音沿用家长已交付内容，停用示例不作为正式词书。之后进入认识与练习 → 本轮完成。另有挑战、伙伴图鉴与成长。儿童不需打字或读懂长说明；无可学词书时提示找家长，不自动开启示例。
- 自动新学默认每天5词，标题旁直接调整今日目标；临时调整只影响今天，次日恢复常用目标。自动选择跨已交付词书、素材就绪且当前义项未实际认识的词；不把旧活动范围或旧预留当成待教词。复习只用当前义项已学词，按薄弱能力及到期目标安排。人工自选允许已学词再学。
- 按上海日期累计当前义项实际首次接触；自动新学只安排今日目标剩余的新词。手选可以包含新词和已学词，实际新认识仍计入今天。新任务不创建多份预留队列，已学事实、成绩和原音独立于任务是否结束；旧无entry接口的兼容规则保留。
- 每步仍按30秒估计时长；统一自动新学按今日目标安排完整词任务，不受旧10分钟预算裁成3词，仍按小段保存和15/5用屏锁执行。复习与旧接口继续按其预算取有限目标，显式maxUnits上限始终生效。预计时长不等于实际效果，个体剂量仍由真实观察校准。
- 新词完整覆盖 learn/recognize/listen/sound/read/recall；开启拼写且适合字母词时再加 spell。认词先不播英文；听音题先听再选；独立朗读先录音再开放示范。认、听、读分别记录，录音保存只算练习。
- 自选图片多选数量不限，完整保留所选词，预计时长只作参考。全选覆盖当前筛选的所有页并保留其他选择，取消全选清空全部；选择接触过的词后并列显示“从头学”（完整讲解再练习）与“直接练习”（旧词跳过讲解），各点一次即开始；未接触词始终先认识。“接触过”来自实际讲解/练习，不能表示已掌握。
- 自选重学与追加旧词练习由服务端强制 `practiceOnly`，不推进或推迟正式复习日期。无新词/无到期不会自动转成加练；只有孩子主动选按书、自选或游戏才额外练习，不拿示例凑数。
- 新整本复习使用 `entry: review + practice + packId + wordIds`：只取已交付、非示例书中当前义项有真实认识/可信历史接触且已批准的词，完整所选范围不受推荐额度或时长截断。未学与未备好分别计数；未学显式转学习，复习不夹带讲解新词，沿用家长编排策略（缺省分段回忆）。题目、选项和配套游戏词池限定该书；服务端拒绝跨书、停用书与示例书范围。
- 游戏入口追加 `game: random | GameKind`，仅在指定已交付词表的练习中使用。服务端按真实缓存、素材版本、词类及家长开关生成可玩目录；固定玩法只出该玩法，无法参与的词如实排除，条件不足拒绝，不降级为其他玩法。随机队列仅创建时抽取，冻结活动、分组、选项和种子；游戏只记练习，不执行新词讲解或自动写正式成绩。
- 复习、随机游戏、每个指定玩法以词表及玩法区分未完成轮次；同类重复开始接回原轮次，不覆盖其他进度。`packGame`保存选择和原始范围，备份校验/清洗、重启、从头再玩和完成后再玩均保持来源；旧版组合轮次不改写。新建整本复习采用基础认识/回忆题面。
- 词表练习冻结书标识、书名、词序与任务，以 `practiceOnly` 记参与，不写虚构掌握或推迟正式日期。同一本同类未完轮次复用，独立于推荐和课堂安排；默认小段只显示本段进度，整本范围不会因此缩成2词。恢复、备份清洗和显式从头再练保留词表来源，新增词不静默塞进已开始的轮次。
- 页面与开局共用entryRecommendation；GET只读核对已批准图片与当前英文精确缓存，缺缓存不生成或降级替代音。打开/刷新不建轮；无候选开局返回真实原因。仅同用途纯推荐轮次占主卡；旧混合、课堂、按书、自选与额外轮次保留为显式入口，不重写计划。
- 学习新词页同时保留新学习与续学：无未完成推荐时主卡预览新词，有进度时主卡继续上次、次级入口开始新的学习。打开新预览不写事实，确认开始使用显式startNew与requestId新开推荐轮；重复请求返回同轮，不结束、覆盖或挂起已有轮次。新候选继续扣除实际认识与全部未完成纯新词推荐的预留；已安排/额度用满/缺素材分别说明，允许调整今日词量或显式自选。原轮可在其他进度恢复，复习及旧API的默认续接合同保持。
- 新轮次持久化entrySource（学习/复习＋推荐/自选/按书/玩法/课堂来源），默认续接只取同入口同来源；旧轮不补猜来源，在学习大厅的其他进度中显式选择。新HTTP请求携带entry，缺entry的旧综合调用保留兼容；不能借此作为新复习合同。
- 新来源轮次的词义/素材失效时保留完整快照并阻止继续，不静默删词、换题或记完成；重复开始/请求ID不能跨入口接管。
- 每个模式只保留一个可继续的学习任务，持久化词序、义项、任务、种子、原图及当前位置。新任务创建成功后旧任务记replaced并退役；失败不替换，重复请求不重开。迁移保留当前指针对应现场，其他未结束旧活动只作历史；不删接触、回答、成绩或原音，不记为完成。当前与最近完成指针分开。
- 到期复习优先错/提示/跳过目标，再练尚未核验和其他目标。听辨与可选拼写按独立证据推进，跨天间隔 1/3/7/14/30 天，同日最多晋级一次；提示、体验、跟读、录到声音不算独立掌握。改义项只重置当前版本。

### 今日词量与自选新词

- 学习入口标题旁提供明显的“调整词量”按钮，今日目标可在1–20词中选择；调整页在选项上方显示“仅调整今天、明天恢复常用目标”。常用默认5词，既有其他自定义长期目标保留。保存本身不创建或推进任务，也不重排当前现场；下一次明确开始新任务才替换。
- 人工“自己选词”使用已交付、非示例且原图音就绪的全部可用词，可选择已学词从头学或直接练习。自动安排只选未学过的词；人工选择不变成跨天的自动待办队列。
- 当前任务继续时保留原题目、范围和来源；新任务明确替换旧现场，原学习事实仍按词义版本记录。词义或素材变化会阻止过期范围继续，不能补示例或其他词；过期今日设置请求拒绝，取消不写入。
- 今日选择与学习档案及备份一起保存；孩子/家长测试档案独立，不修改共享长期设置，不写正式成绩/到期。个体剂量是否合适仍由A03/A04真实观察验证。

### 轮次管理与课堂范围

- 学习页只有一个当前任务入口，不显示“继续已保存的学习”或历史任务选择列表。保存休息后继续原题；显式新任务原子替换旧任务，不增加覆盖确认或要求孩子清理旧任务。旧活动及原音保留为历史，不影响已学词状态；兼容重开请求仍保持幂等。
- 家长授权后保存一份当前课堂计划：整课范围、本次重点与顺序、学习版本及每段5–15分钟的估计预算。新建另一课使用新计划标识；更新带版本号，过期整份拒绝。
- 儿童开始课堂小段免PIN，按当前重点顺序选取完整词任务，不能截断单词凑预算。新词先认识，已有接触的词跳过讲解；课堂练习不受每日推荐5新词的默认量限制，整课范围不直接变成单轮任务。
- 本课范围、本次重点、实际本段词数分别显示。单段计划冻结，调整重点只影响下一段；已完成词只按同一课堂、同一学习版本的真实完成记录累计。素材或词义过期须家长重新确认安排，不静默替换。
- 课堂练习和重开均为练习，不晋级或推迟正式复习日期；接触记录、正式测试与家长核验保持原有边界。备份保留课堂安排、实际进度和轮次结束关系，校验进度与历史一致。

### 分段回忆策略

- 儿童页面启动新轮次显式选择 `memory-loop`（家长可选 `classic`）；API 未指定且设置缺省时保持旧调用兼容。策略冻结在轮次 `learningPolicy`，恢复不重新排课；设置切换仅影响以后新建轮次。
- 新词每组最多 2 个，按 learn → listen → recognize → recall → sound → read → 可选 spell 穿插；一词时不虚构隔项间隔。当前新词不按识字水平分层，C1 仍待实施。
- 回忆采用完整图片与词语发音卡，中文线索为首要文字，点同一卡片底部的“听示范”才显示英文；播放状态与进度来自实际媒体事件，播放时不录音。开始录音、说完、保存后继续保持同一位置，回放/重录为次要操作。先隐藏英文与示范，孩子显式点录音；按需听示范立即持久化 hinted，后续录音为 follow。有效私有录音保存后才能提交 recorded，也可明确 skipped。均 `correct:false / practiceOnly:true`，不直接写掌握或口头正式成绩。
- 每 8 个原子任务设保存休息点，成组活动延后到组尾，不拆目标。服务端阻止未确认休息点之后的新答题/完成；旧请求重放不重复推进。回大厅或关闭页面保留休息点，只有显式继续才开放下一小段；小段不发整轮贴纸。
- 新主线v3按目标、词性、已认识词池、审核素材和缓存自动排课：原8类基础上加入宾果、排队、双目标收集、局部揭秘、词义寻路等；明确可做手势的动作词可进入听词模仿。语义类优先匹配颜色/位置/分类/反义及动作，不能凭词性臆造关系；语义素材必须已审核、词义版本一致、所需发音已缓存，情境/拼写继续遵守家长开关。主线共有41类适配（含稳定的回忆/朗读传送门），不代表每份词表全部可玩。
- 编排按本轮使用频次优先少用玩法、抑制连续重复，控制小段内听辨/拼写机制数量；相同种子恢复不重新抽。配对任务必须相邻且位于同一休息点内，共用棋盘与真实两个目标，不增加或重排目标、不借未选或尚未认识的新词。参与型听音后保留客观sound检查；仅有单个到期听辨目标时仍需客观题，单词不足不凑任务。认义、朗读和主动回忆的证据保持独立。
- 主动回忆维持先想后提示的录音流程，不为增加游戏而重复口头任务。自由绘画、亲子出题和额外口头情境仍在独立游戏入口；整本复习保留原基础认识/回忆和独立保存的游戏入口。
- 新策略按上海日期在首次接触的次日安排未评分回忆提醒；同目标中译英测评练习去重。只有推荐内回忆参与可把该提醒移至后一天，额外自选不推迟；正式测评日期/分数仍由原独立合同维护。不是自适应遗忘曲线，也不提供自动回忆正确率。
- 主线七类基础题面与错配维修共用蓝色主题、自然比例原词图及统一底栏：跳过左侧、提示/重听中间、主操作右侧；选择题单击即答，不增加暂选确认。帮助的头尾按钮保持可达、内容内部滚动；基础题按需打开，复杂机制保留有限帮助。调整题面不更换词图、不重排冻结任务，不修改已有进度、原音或成绩口径。
- 认识、练习与奖励共用轻色卡片和稳定操作位置，儿童页不重复展示认听读状态条；返回直接到大厅并保留轮次。回忆/朗读有效原音保存后，单次继续先提交参与再推进；明确跳过同样先保存再推进。请求失败、离页或暂停不自动连跳；独立答题保留反馈及显式继续。
- 到休息点先停下；大厅点击继续玩视为显式继续当前小段，免去再次确认，但刷新/后台不会自动确认。完成页突出实际完成结果与下一步主动作，复习入口承接后续提醒；家长概览展示当前版本的回忆已录、未听示范、有帮助和跳过，正式核验独立展示。实际记忆、兴趣和合适段长待儿童使用验证。

### 保存退出与原位置续接

- 回大厅、休息与保存退出先停止播放，等已发出的学习操作结束；正在录音先停止并保存。只有录音保存与当前位置确认成功才显示已保存/返回。失败留在本题，可重试或明确只保留服务器此前已保存的进度退出；后者不承诺保留未上传声音或草稿。保存等待中可留在本题，迟到回调不应把页面自动带走。
- `pauseState`只保存实际暂停/休息/返回、冻结活动位置、检查点及有界基础题/拼写草稿，不写答对、完成或奖励。重开页面与服务恢复以冻结计划为准；已经保存的原音从私有接口恢复，缺音如实显示。强制关页/刷新时未上传的声音仍可能丢失，不能显示为保存成功。
- 休息不完成整轮、不自动开下一轮；整轮奖励幂等。完成反馈分别描述实际认识、口头练习、有提示、跳过及无评分再试，提示下次从复习入口再想一想，不宣称记牢。

### 复习先尝试再帮助

- 新建非整本/游戏的复习分段轮冻结`reviewSequence=1`与`reviewSupport.version=1`：先全部回忆/中译英辅助练习，再朗读，再认义，再听辨；只重排已有方向，不加新词或讲解。旧轮、整本基础题和主动游戏保留原计划。
- 四方向题干与求助矩阵见[入口规则](ENTRY_RULES.md)。不会时可显式求助；朗读无需先录出不会的词才获得示范。帮助记录先前已作答/已保存录音/主动表示还不会及实际引用，示范失败不是答错；普通原音和“想过了”都不算正式正确。
- 帮助后同轮同词的后续方向仍保留提示/练习身份，不能用旧页面声明独立；之后的原音标跟练。既有正式核验与首次延迟探测不被后续成功替换。
- 原目标结束后，仅对后面确实隔过其他词的目标再遇；每轮至多两词、每词一次，标成额外练习且可跳过或保存。再试不补正确率、不晋级、不改正式到期，不完成或明确跳过前不发整轮奖励；其他困难留后续安排，单词独练不虚构间隔。这是可解释的工程上限，非已证实的个体剂量。

### 复习续接与提醒去重

- 推荐、按书、自选与固定/随机游戏各自续接冻结范围；保存、刷新、跨天或更换入口不重新抽题或静默删掉原目标。缺音仍保留原进度并如实解释，不伪造补录或成功。
- 普通提醒与弱项练习按当前词义版本和方向合并：回忆/中译英辅助、认义/看词选图辅助、朗读各归同一目标；听辨和英译中仍是不同方向。新推荐每目标只排一次，家长概览与预览/开局使用相同调度。
- 推荐复习实际结束一个原目标后，服务器保存完成时间；同一上海日期不再由另一条普通/弱项提醒拉回，最早下一自然日再考虑，已有更晚合法日期仍保留。录好但未继续、仅看提示或额外再想不算原目标结束。跳过/设备不可用可结束该次安排，但不算答对或记牢，后续仍可再遇。
- 只有有合法完成来源的推荐复习影响该提醒；按书、自选、游戏、重开等加练不推迟普通提醒或正式日期。已结束目标的只读历史投影供页面刷新使用，不以最近一次完成轮替代全部历史。旧轮无完成时间时只读取既有合法证据时间，不补猜新的完成日。
- 原始记录与家长概览分别保留录音参与、帮助、跳过、设备不可用和无评分再试；完成页只保留完成结果和主动作；完成不自动新开推荐或发重复奖。今天已结束且无其他到期目标时显示结束状态，主动加练仍可选择；若同词另一方向或后续日期到期，仍可推荐。正式挑战为单独的显式核验，不被练习参与代替；同日不重复晋级、晚核验与改判仍走原正式证据合同。

### 发音播放与体验升级

- 短单词、释义与录音回放完整下载并解码后播放，复用一个输出 AudioContext；当前及随后两个目标仅预取已有缓存。首次、后台恢复、录音结束及静默超过5秒后，先输出约400ms轻预热。预热不计示范或学习证据；快速重播仅保留最后请求，暂停/离页取消旧播放。蓝牙开头截断仍须同设备实听验收，不能由自动化替代。
- 本机合成轻提示音：正确、再试和录音保存分开；与文字/图形并用，不覆盖单词。跳过或服务失败不播放答错音。默认开启，家长设置可单独关闭，总声音关闭时提示音同时关闭；重复响应与刷新不重放。
- 新主线使用v3；v1/v2在下一个已完成休息点点击继续时，由 `POST /api/session/upgrade-experience` 原子升级并确认休息点。只替换未开始题面，保留ID、词表、目标和顺序、已完成题面/状态、原音、奖励及有界旧编排快照链。不在后台自动推进。写入携带当前planVersion，过期页面返回409并刷新；重复升级幂等，兼容既有v1→v2请求及旧备份，测试模式同样隔离。
- 家长设置的“声音检查”只读现有缓存，支持原始/新版对比，不记接触、成绩或奖励；蓝牙与扬声器、静置重播由家长判断。源文件缺音未经证实前不重生成、不替换音色。

## 自动讲解、游戏与原音

新建学习入口的纯新词 `memory-loop` 轮次冻结 `teachingSequence=meaning-recall-v1`：先认识含义，完成理解，再穿插回忆。双词保持原编排；奇数尾词先认识/理解，再穿插前面词的既有声音/朗读/拼写任务，最后自己回忆，不增加词、目标或题量。穿插题不能把尾词的英文作为选项/线索暴露，无法安全适配则回基础题；单词独学如实说明没有其他词可穿插。旧轮次不改序；升级体验仍保留目标和已开始题面。家长学习概览可看计划覆盖与实际隔项数，它们不证明孩子理解或记住。

基础听音/选声音可明确跳过；设备不可用与跳过分别保存 `responseStatus`，不记答错、成功、晋级或推迟到期。原有口头参与与正式核验边界不变。

新建学习入口的分段轮次冻结`guidanceVersion=1`，优先使用六类核心机制与基础题；按书主动游戏保留完整目录，旧轮不重排。基础听图、听选、回忆及朗读以题面直接操作与真实状态反馈为主，不自动弹操作示意、困难或设备说明；跳过、保存休息与顶部“帮助”保持可达。其他游戏继续使用首次三步无答案示意、连续困难帮助和设备出口，同档案复用已确认看过的操作。示意不含本题答案、不播放词音、不录音，不替孩子作答；不自动写入看过状态，看过也不等于会操作。弹窗阻止背景操作、停止媒体并按暂停区间观察。操作帮助只记`session.guidance`，词汇示范仍沿用hinted与口头核验边界；原学习/复习目标、正式标准及题量不变。操作负担目录见[游戏UI](GAME_UI_DESIGN.md)。

基础听选先依次播放原有选项发音，并同步突出当前播放项；全部确实播完才开放选项，点一个直接作答，不再复用为试听或追加确认。重听为独立动作，播放、暂停、失败和跳过不生成正确作答；中断/失败时保持禁答并允许重试或跳过。原批准图片完整圆角呈现，并显示既有中文义项帮助辨认图片指代，不显示英文选项。

独立朗读显示大单词，孩子的任务是自己读出来。本次学习首次须明确开启麦克风；只有本页签保留本次开启意愿且浏览器已授权时，后续未录词才自动开始听，不自动请求新的权限，不在后台开启。真实音量条只表示设备输入；检测到持续音量后停顿约1.8秒尝试收音，未检测到持续音量10秒结束并提示重试，20秒硬上限保持。可手动点“读完了”，暂停/离页取消和保存关口、私有原音、最多三段、失败重试保持；保存成功才可继续、回听或再读。噪声与停顿可能影响收音，应保留重试和真人校准，不把端点检测或录音保存当识别正确。示范仍在独立尝试保存后开放，推荐复习的显式求助保持原有例外，不显示虚构波形或分数。

v2及以后认识页同时显示完整图片、英文与中文，默认英文一次、中文释义一次，再自动进入练习；重听由孩子主动点击。旧编排未升级部分保留原有讲解顺序。词性随家长确认的释义显示，不另读或推断；长词适配、短语换行，方形图片 contain 完整显示。讲解仅记录接触，不写独立答对。静音不请求音频，播放失败显示真实提示并按阅读节奏继续；暂停、后台、离页或义项变化取消旧推进。英文读缓存，中文首次合成受免费额度和预算约束，不切换系统音色。

当前 50 种玩法以 [注册表](../shared/game-registry.ts) 为准，逐项条件见 [机制库](VOCABULARY_GAME_LIBRARY.md)，界面见 [游戏 UI](GAME_UI_DESIGN.md)。按技能、词数、词性、已审核素材、缓存和开关筛选；经典编排维持每组最多 3 类、每轮最多引入 1 种新机制；新版主线按目标与素材条件轮换简短玩法。故事、编程、双词组合、数量订单和双词分料按实际两个目标计步，不把整组视为一步。新增 30 种只记练习，保留必要客观听辨检查。

- 题目、棋盘和动作检查点冻结，服务端核对选择与移动轨迹；通用完成接口不能绕过活动顺序。多选排除、重试、揭晓或提前听答案后持续标记提示；目标英文作为听辨题面本身不算提示。
- 不足两个清晰选项、缺素材或缺音频时回基础练习并如实记体验；不得编造关系或拿未选词、示例凑数。亲子、进阶情境和拼写默认关闭。
- 已批准词图可派生四块拼图，中文回忆复用原确认释义。关系/动作/短句候选必须由家长预览确认；素材记录词义及关联版本。开局只读缓存，儿童路径不触发生图或补发音。
- 家长交付时可授权后台补两类派生玩法的缺失发音，每批最多 5000 缺失字符，受免费额度/预算约束，可停止；其他额外素材须按所见版本确认。详见 [游戏素材](GAME_MATERIALS.md)。
- 原策略的“自己说一说”先实际示范 3 遍并显示进度，再让孩子录 1 遍；一段已保存录音即可继续，可回放或重录。中断示范从第一遍重听，失败可重听或跳过，不虚记次数；减少动态效果时使用静态高亮。
- 所有口头游戏、朗读和中译英练习复用私有本机录音，每段最多 20 秒，保存/跳过分别记录，不识别、不评分、不晋级。空录音不保存，失败可重试/重录/跳过；暂停、后台、离页释放麦克风和临时 URL，刷新/重启可恢复已保存原音。
- 练习原音仅在 `data/practice-recordings/` 私有留存，当前活动可回放，历史须家长授权；普通备份只有元数据，恢复缺音标 missing。麦克风失败区分网页拒绝、系统拦截、无设备和占用；失败不记成功。

## 单词用法与短句补学

- 单词练习完成后，支持已确认义项的词先接“学会怎么用”，学中文情境、完整英文和必要用法，再做引导选词补句。当前内容对应十词v2题面，测试沿用所学的同一句，不把新句式临时放进测评。此环节不扩改旧词汇轮的冻结计划。
- 私有`sentenceStudies`按词/义项/原图/短句版本记录开始、示范来源与实际练习；只读预览不记学习，完整音频成功或明确大人带读后才允许练习，选对仅结束这段引导学习，不写正式测评/晋级/奖励。失败不记已听，词义或图片变化不沿用旧学习资格。
- 已开始的挑战先补尚未学过的句式，再显式进入原测试；保留原ID、词序、40项及所有回答，不把原坏题改记已答对。v2新建与录音准备/保存均检查已完成对应短句补学，未知或旧词义不放行。暂停、后台、休息立即停播，恢复/备份保留真实阶段。
- 儿童页面只播已有缓存，不因点播放生成云音频；缺音和静音时提供清楚的大人带读入口，分别记录来源。发音准备仅沿用所选提供商、音色和免费账户额度，权限或额度未知即停止。真人理解、泛化与剂量仍需观察。

## 自主挑战与正式证据

- 儿童创建、作答、录音和提交无需 PIN，每轮 1–10 个已学且可学词、最多 40 项，顺序为中译英 → 朗读 → 英译中 → 看词选图。到期测试只出对应维度；推荐优先到期，其次初学次日起缺少的首次测试，进行中/待核验/同日已测不重复推荐；完成页可显式挑战本轮，只突出完成词数、测试主按钮和清楚的休息出口。
- 中译英显示中文与必要语境，不播放答案或等待语音；题面v2为当前十词all/am/are/at/ate/be/black/brown/but/came按原确认义项提供中文情境和单空英语短句，区分be原形、am/are主语及过去动作；例如be使用“I want to ___ a cook.”，只说一个词，不显示目标英文。未知且仍歧义的其他题保留不可用边界。已开始轮次可展示补好的题；原不可用回答不自动改成已测，未提交时显式重录才原子保存新语境与回答版本，不改题数、词序、其他回答或已提交历史。必要语境与自选图片提示分开：图片沿用批准原词图，首次打开时持久记录，之后的回答只能记有提示；保存后才看图不追改原回答，重录则记有提示。新版题面随题冻结，旧录音未见区分语境不补写为已见，新增核验只能未确认或不可用；朗读不先示范。口头题每段 0.1–20 秒，规范 16kHz 单声道 PCM16 WAV，最多 640044 字节；空录音/权限/网络失败可重试或跳过，不记错。提交前可重录，选图首次选择不可替换；提交冻结题目、版本、原音与实际作答时间。
- 每段转写成功立即保存，再由 Codex 整轮一次受限结构化初判。AI 的 matched/practice/unclear 是建议，转写匹配不等于发音评价；看词选图由服务端核对，口头正式结论只能由家长按所见回答/建议/核验版本批量确认。
- 后台持久化 queued/transcribing/grading/review/failed/interrupted 及 runId；重复提交不重复派发，重启标中断，由家长显式重试；已有结果不重发，迟到响应不覆盖核验或新义项。
- 核验、回听、重试及旧现场测试/actions 要求 PIN 产生的 30 分钟 Bearer 授权，仅存页面/服务内存；刷新、回儿童首页、改 PIN、恢复和重启失效。旧家长现场流程显式选择 `workflow=parent`。
- 正式记录保留作答时间 `createdAt` 与核验时间 `confirmedAt`，按作答日期重放 1/3/7/14/30 天规则；同日不重复晋级，错误/提示次日，未确认/跳过不晋级。改判保留审计并重算，旧义项不影响当前；AI 弱项建议只进练习，不进正式进度。
- 概览、复习弱项与成长共用当前正式证据规则：已完成挑战、题目与词义版本一致、来源正确；按实际作答时间选最新，同一作答按核验版本修订。晚核验旧答案不覆盖较新作答，孤立/未完成/未来/旧义项证据不授予成功。练习、录音与正式正确分开，读取不重写原始成绩。
- 挑战原音仅存 `data/assessment-recordings/`，不提供公共媒体，不进 Git、日志或普通备份；核验后标 purge-pending 并删除，失败维护重试。恢复备份缺音标 missing，不据此判对。练习原音不套用此删除流程。

## 家长、成长与数据

- 家长首次自设两次一致的 6 位 PIN，无默认口令；服务端只存独立加盐哈希到 `data/parent-pin.json`，输错 5 次暂停 30 秒。改 PIN 需当前口令；本机停止服务后可用维护命令重置。PIN 只保护家长网页入口，非多用户/全量 API 鉴权。
- 家长空间以备课、学习记录、设置组织，课堂安排与新建词表并列在词表工具栏；按需展开低频工具，显式保存，设置页签标明未保存更改；检查缓存未完成不能报成 0。
- 成长的练过与会词分开：当前义项四项最新完整测评均独立通过才算会词，同英文合并计数，跨天巩固另列。8 系列 128 枚奖章首次达成在事实事务写入，已得永久保留；当前能力随最新证据更新。规则见 [成长](CHILD_GROWTH.md)。
- 成长各子页的返回均一步退出成长；不会因浏览记录重领奖励。图鉴默认展示短介绍，长文按需展开，详情可连续切换角色。
- 伙伴图鉴共100位，汽车人和霸天虎各50位；擎天柱、威震天仅图片和故事默认开放，动画分别须累计新学会10词、20词解锁，0词时均锁定。只累计首次四项正式独立通过的不同英文；其他角色同时沿用10/20/30/40词节点：10词开大黄蜂图文，20词开大黄蜂动画，30/40词开下一位，随后循环。领袖动画门槛应用于旧/新账本，原先默认开放不算已经赚取的奖励；其他按词数获得的历史角色/动画保留。复习不推进奖励；提示、录音/练完不直接记为学会，同英文跨书只计一次。
- 扩充保留原20位ID、批准图片与原18位解锁顺序，新增人物接在其后，双方都有剩余角色时交替安排；不将同一人的升级/改名重复计数。全部及阵营筛选每页20位，分别5页和3页；总数按人物库计算。
- 解锁按固定人物顺序，永久奖励账本与当前能力分开；读取不发奖，重启/备份保留，家长测试档案隔离。v1旧奖励迁入v2，冻结旧复习已得人物及动画，新复习不再新增奖励。图片/故事与动画分别授权：人物未开不能进详情，人物已开但动画未开时显示剩余新词数，不挂载播放器或资源入口；独立学习伙伴限已开人物。动画已开后点击才在页内加载B站标准播放器，手动开始、可全屏，收起/关闭详情/切换角色即卸载；失败可重试或打开对应集国内原站。观看不写学习成绩，具体来源与网络前提见[伙伴规则](companion-library.md)。
- 学习背景按会话固定，刷新/暂停不轮换。既有首页/背景、批准词图不因角色锁定重画或替换，素材修改不改变学习证据。
- SQLite 保存学习事实，旧备份/会话兼容；备份保留本机用量和删除状态，严格校验版本、顺序与证据。PIN、密钥、授权和两类原音不导出；恢复前保留旧副本，运行任务未结束时拒绝恢复。

### 私有业务观察

- 家长学习记录的“使用简记”包括一次使用机会、固定词组投入与预先冻结的延迟观察；默认未知，同一ID修订补记，冲突拒绝覆盖。意愿、逐步指导与主动分钟由家长观察，不能从点击/停留补出。
- 延迟观察锁定词义/方向/间隔与首次尝试；重试或重录不能替代首次，口头未经合法核验保持待核验。缺测、跳过、设备失败、错过窗口/改义与课外接触分别显示，不改写学习/正式成绩或到期。

## 接口与外部边界

数据形状以 [shared/contracts.ts](../shared/contracts.ts) 为准，路由与验证以 [server/index.ts](../server/index.ts) 及 `tests/*api*` 为准。失败返回 `{error,code?}`；同源、题序、快照、版本、上传和预算检查在服务端执行。主要接口族为 `/api/parent-gate`、`/api/import`、`/api/packs`、`/api/words`、`/api/session`、`/api/attempts`、`/api/practice-recordings`、`/api/assessments`、`/api/speech`、`/api/backup` 与 `/api/restore`；不要在多个文档维护第二份完整路由合同。

ElevenLabs 负责缓存发音与挑战文件转写，Codex 官方登录负责词义、生图与初判。免费账户/剩余包含额度/关闭超额计费及本机预算满足后才发相应请求；失败或额度不明即停，不充值、升级或静默换服务。缓存可独立于新增请求预算播放；本机费用是估算，不冒充账单。没有配置或登录时显示真实状态。

聊天、兴趣访谈、语音指令与实时云端识别保持停用，旧数据及仍被引用的适配器保留；状态查询不触发预热/生成。Codex 不复制 OAuth 凭据，文本初判禁用工具与文件写入，图片仅在隔离素材目录生成，批准前不能进儿童词书。

## 验证边界

完整门槛为类型/资源/文档检查、全部自动测试、生产构建及隔离本机启动。恢复、备份、版本冲突、提示/独立证据、录音私有边界、免费额度和取消幂等须保持覆盖。模拟服务只能证明本机编排；真实云端可用须真实请求证据，不能由整理任务自动发起。儿童实际理解、口音与长期记忆效果另行观察，当前结果只写 [ACCEPTANCE](ACCEPTANCE.md)。

## 学完后的验证与连续用屏

- 学习完成页直接接本轮测试，保留全部已完成词，十词以内一次完整安排，最多10词40项；超过单轮上限时再接余词，已开始的旧五词轮保持原冻结题目，刷新当前挑战保留整轮词ID范围。已提交待核验不反复自动开测，也不当正式通过。四方向仍为中译英、独立朗读、英译中和看英文选图；口头核验及10/20词动画门槛不变。当天验证与次日/跨天复习分别呈现，不把即时通过宣称为长期记住。
- 学习主卡只接当前任务；没有当前任务时展示自动新学。新任务替换当前任务；词图预览与选词按当前义项真实接触标“已学过/未学习”，不表示掌握。
- 儿童页面连续前台用屏上限15分钟，满后强制休息5分钟。所有儿童页面/动画共用服务端计时，多标签按时间并集计；后台停止续租，不把长时间关闭算在用屏内，离开满5分钟清连续计时。家长空间/设置不计，不能通过未验证家长入口继续儿童学习。
- 休息使用原家长PIN产生的临时授权提前解锁，或者到期自动开放。私有SQLite独立表保存用屏与休息，不写成绩/奖励、不进入普通学习备份；读取不清计时，刷新、重启或恢复学习备份不能绕过。计时连接失败暂停儿童操作，可重试。限制只覆盖本应用，不控制Windows或其他网页。
- 休息时原题保持，禁止新开/推进学习与测试。后台保存当前练习录音仍允许，录制中的练习尝试结束并保存；挑战尚未上传的短录音先结束并留在当前页面，不虚称已保存，刷新前须实际上传。已开启动画卸载，退出全屏；解锁后不自动重新播放动画或开启麦克风。
