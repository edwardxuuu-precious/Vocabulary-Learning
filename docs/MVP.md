# 单词游乐园 MVP 规格

## 目标与完成边界
- 6–8 岁、中文母语、英语零基础；单孩、Windows 本机浏览器。
- 业务目标：帮助孩子学习家长指定的英语单词，通过练习与跨天复习检查记忆。核心成果为理解词义、听音辨认、看图主动回忆及跨天独立答对记录。
- 家长备课，孩子通过单词发音、大图卡和点击独立学习；默认新词上限3、复习上限6、预计10分钟。新词完整学、旧词只练到期技能，复习优先并按任务预算和积压自动减少新词。
- P0 包含词表与素材准备、直接学词入口、认识词与练习、分技能学习记录、跨天复习、孩子今日结果、家长逐词概览、恢复与备份。
- 当前语音保留英文单词发音与点击重播；“自己说一说”和口头学习游戏提供本机私有录音留存与回放，保存不判对、不调用云端识别。聊天、兴趣访谈、语音指令和实时云端识别停用；可选自主挑战单独录音转写、Codex初判并由家长核验。角色奖励、家长生图与可选拼写保留，图片先由家长审核，拼写默认关闭。
- 不包含公开部署、多用户账号、开放闲聊、自动发音评分、手机跨设备同步。语音识别不能冒充发音评测。

## 儿童成长与稳定背景（2026-10-17）

- 首页“我的成长”与完成页展示真实学习打卡、累计/连续天数、逐词能力与8系列128枚差异化奖章；奖章有稳定编号、获得状态与剩余进度，支持系列筛选、分页及逐枚激励文字预留。不把贴纸、提示或跟读计为会词，不设自动发音分数。
- 成长入口默认显示“奖章与词汇”；学习打卡、能力进展、单词记录分模块打开，每次只展示当前模块，保留模块切换和返回成长首页。
- 会词标准：当前义项和版本的四项最近完整测评均独立通过；口头题由家长确认，看词选图由服务端核对。相同英文合并计数，不宣称掌握全部词义；跨天四项通过另外记录，到期仅标记复测。
- 奖章覆盖累计学习、练过、会词、跨天巩固与四项能力的16级阶梯，依据真源`shared/badge-catalog.ts`。首次达成记录在原存储事务中，已得奖章永久保留，重启/重试/恢复旧备份不重复发章；会词量与当前称号随词义和新正式测评更新，保持与历史奖章分开。
- 晴空草原、宁静海湾、云端花园三套静态低对比背景按会话ID选择；同轮认识、游戏、暂停、刷新恢复与完成页保持统一，不轮播。详见`docs/CHILD_GROWTH.md`。

## 看、读、双向翻译测试（2026-10-17，自主挑战修订）

- 大厅“挑战测试”无需 PIN，默认推荐跨批1–5词短测；完成页“挑战本轮”显式选择本轮已学且启用/批准的词，准备页只显示词数和题量。自选测试仅接受已学词，图片多选页可明确选择范围。最多20项，分组顺序中译英→读→英译中→看；到期复测只出对应维度。旧家长现场测试和判定来源保留。
- 口头题逐题手动开始/结束录音，最多20秒；空录音、权限拒绝、网络失败可重试或跳过，不记错。中译英直接显示当前义项的中文文字，不播放题面，也不等待语音准备；进入后可立即录音。读不先播放英文。提交前允许重录，提交后冻结题目、录音与作答时间；选图首次选择不可替换，整轮提交时服务端判题。
- 自主挑战使用四关路线、已有大黄蜂伙伴与蓝紫色层级；题面大字居中，中文/英文区分，录音前/录制/已录状态清晰。准备页不展示答案；提交前按能力分组重录，结束只显示完成与待核验状态，不将参与或AI建议显示为掌握。窄屏使用大录音按钮与可滚动布局。
- AssessmentSession.workflow=recorded，response记录版本/作答时间/类型/私有原音元信息，transcript保留原始转写，proposal独立保存matched/practice/unclear与依据，reviews保留逐次家长判定。completedAt/submittedAt表示儿童完成；AssessmentAttempt仅保存服务端选图或家长核验的正式证据，createdAt为实际作答时间，confirmedAt为核验时间。
- POST /api/assessments默认创建录音挑战（wordIds?,mode?:full|due|recommended；recommended由服务端选范围，不接受wordIds）；GET /api/assessments/:id恢复；POST /responses {itemId,expectedVersion,action:choose|skip|unavailable,selectedId?}保存回答；POST /recordings?itemId=...&version=N上传规范16kHz单声道PCM16 WAV（0.1–20秒，最多640044字节）；POST /submit冻结并入队。这些接口只要求本机同源、题序、快照及上传限制，不要求家长授权。
- POST /review {items:[{itemId,responseVersion,proposalVersion,reviewVersion,result}]}整轮内原子批量核验；GET /audio?itemId=...授权回听；POST /retry只重试失败/中断阶段。这三类接口以及旧现场测试/actions必须校验PIN产生的30分钟Bearer授权。授权只在页面/服务内存，刷新重新验证，回儿童首页撤销，改PIN/恢复/重启失效。创建旧现场测试须显式workflow=parent并授权。
- 逐段调用官方ElevenLabs Scribe v2文件接口，成功转写立即保存，随后Codex整轮一次受限ephemeral结构化初判；不启用聊天、工具、文件写入或应用操作，不把转写匹配说成发音评价。Free账户/关闭超额计费/剩余包含额度须确认，STT独立估算CNY3/小时并经过本机预算；已确认免费成功请求记0元与秒数，未知失败保留预留。Codex验证官方ChatGPT登录及订阅限额，认证、额度不明或服务异常留待处理，不升级或换服务。
- 后台job持久化queued/transcribing/grading/review/failed/interrupted、阶段与runId；重复提交不重复派发。重启把未结束任务标为interrupted，由家长显式重试。已有转写/建议不重发，迟到响应不得覆盖已核验题或新义项。
- 原音在独立assessment-recordings目录，公共/media不提供、不进入Git/日志或常规备份。家长结论提交后标记purge-pending并删除，失败在启动/定时维护重试；文字及改判历史保留。恢复备份未核验原音标missing，不能据此判对，须未确认并重新测试。
- 1/3/7/14/30天按作答日期重放正式记录，跨天才延长、同日最多晋级一次；错误/提示次日，未确认/跳过不晋级。改判更新原题有效结论并重算，保留reviews审计。旧义项留历史，不影响当前版本。AI practice建议可进入图片辅助弱项练习及任务预算，不写正式进度；每天同能力最多练一次。进行中的学习计划保持冻结。
- 四维报告逐词展示正式来源、待核验、历史与复测日期；部分核验可独立更新已核验词。旧备份缺少测评数组初始化为空，新备份严格校验版本、来源、题序、作答/核验与重放进度，不携带原音或授权。
- 隔离自主挑战脚本8798使用成人合成声音、明确测试替身与独立档案；单独真实云端冒烟只发送合成apple。旧8799体验保留家长现场流程，均不进入正式首页导航。

## 首次入口与学习闭环
- 儿童单词图统一方形1:1，图片使用contain完整等比显示，不用cover、自动裁切或图片圆角遮罩。认识页图片作为联想辅助：桌面300–360px框、820px以下280px框；其他题型按原布局最大520px、手机跟练最大340px，拼字图也保持方形。生成提示匹配1:1、至少1024px原图，重要主体四周至少10%边距，动作、头盔、双手与道具完整；已有批准图仅在家长明确确认后替换，不改变学习证据。
- 家长入口使用家长首次设置的6位数字PIN，无默认通行码、明文提示或儿童可点的重置按钮。设置须输入两次；验证与修改在本机服务端完成，连续输错5次暂停30秒；设置中修改须当前PIN。返回儿童首页或刷新后重新验证。这是本机网页入口隔离，不是多用户账号或全量API鉴权。
- PIN只保存独立加盐哈希到忽略的data/parent-pin.json，不进入AppState、素材接口或词表备份；恢复学习备份不重置PIN。忘记时家长停止服务后在本机执行npm.cmd run reset-parent-pin，再启动并自设PIN。
- 首次和再次打开均进入双入口首页：“开始玩”为儿童主操作，下方同宽蓝白“家长空间”通往备课室，成人入口常用且醒目，仍需原PIN验证。当前家长指定Q版变形金刚机甲主题，擎天柱、大黄蜂、阿尔茜为小型右侧远景伙伴，小队较v4稍左移；左侧标题下两个入口成组，竖屏同组居中、伙伴在下方。三角色与基地同一场景呈现，共用地面、透视和光影；横竖屏分别构图，无卡片外框，不单独叠放角色或显示“汽车人小队”标签。角色保留机器人光学镜、金属面罩与装甲，不使用拟人眼球、睫毛或嘴唇。首页不展示统计、每日计划细节、长说明和示例词；点击开始进入学习大厅，可显式恢复原步骤或选择其他学习，学习不依赖兴趣或 onboardingCompleted。
- 没有可学习词书时，孩子点击开始才显示“单词还在准备中”次级页面，可找家长或回首页；不跳过家长误触门槛，不自动启用示例。学习安排与记录保留在学习及家长页面。
- 视觉参考 [ASTRO BOT 的场景探索感](https://www.playstation.com/en-us/games/astro-bot/)、[Pok Pok 的玩具质感](https://playpokpok.com/)与 [Khan Academy Kids 的儿童入口](https://www.khanacademy.org/kids)：场景层次、少文字、大按钮。角色按家长另行指定的变形金刚主题生成；当前真源与提示词见`shared/visual-theme.ts`、`docs/autobot-theme-assets.md`。
- 儿童路径：首页 → 学习大厅（继续上次 / 推荐学习 / 自己选词 / 挑战测试）→ 认识与练习 → 本轮结果（再练一轮 / 自己选词 / 挑战本轮 / 返回大厅）。本轮完成不再阻止同日继续学习。
- 首页次级“伙伴图鉴”提供20位变形金刚（汽车人和霸天虎），全部可浏览并放大查看；详情提供每位约200字的中文简介，介绍身份、性格与本领，可左右切换及在短屏滚动阅读。学习及小游戏按已保存任务位置轮换，刷新同一任务角色稳定。后续单词配图使用完整人物库，家长明确指定人物优先，已批准词图不批量替换。角色与素材真源见`shared/companions.ts`及`docs/companion-library.md`。
- 当前没有聊天或兴趣访谈入口；保留既有兴趣数据，不新增未确认事实。英文示范只读单词本身；认识页按用户确认新增中文释义朗读，其他提示仍显示在界面。
- 儿童学习、暂停和贴纸页保留柔和底色，头像同步为机甲伙伴；每页一句提示、大图、大按钮，顶部单条小任务进度与单词计数。新词仍完整学、旧词直接练到期技能；省略儿童页重复说明和统计，家长逐词证据保留。答对后刷新会恢复正确选项高亮。
- 认识单词卡片的中文释义以深蓝色、650字重强调（桌面28px、820px以下24px）；家长已确认的词性以14px、常规字重的小号缩写标签置于释义左侧，例如“[动] 制作”“[名] 苹果”“[形] 黄色的”。恢复浅蓝底色与蓝色边框，横向间隔桌面12px、820px以下10px，不另起词性行；长释义在标签右侧正常换行。标签保留完整词性提示，随释义一起出现；旧词未保存词性时不显示标签、不留空位，不推断补填。家长空间展示保持原样。
- 认识页全程自动分步讲解：英文显示并朗读 → 词性与中文释义同时出现，只读“意思是，{家长确认的释义}。” → 英文重读 → 完整图片出现并停留650ms → 英文和同一中文释义复述 → 停留1秒后自动进入练习。词性无独立展示或朗读步骤，不要求儿童点击继续/玩一玩；保留可选重听。短词桌面88–104px、窄屏64–76px，图片桌面230–300px、窄屏280px，保持1:1完整等比显示。长词自适应、短语按词换行，中文桌面28px/窄屏24px、同排词性标签14px，引导18–20px、头像44px。其他题型不增加英文答案。
- 讲解仅为接触学习；自动衔接通过既有接口完成认识步骤，不写答题/掌握证据，单次完成去重。静音不请求语音；播放失败显示真实提示并自动按阅读节奏展示，英文阶段1400ms，中文/复述按释义长度2200–6000ms。暂停、家长门、切后台、离开和词义变化取消旧讲解及自动衔接，恢复当前步，刷新从当前词开头讲解。提交失败保留真实错误及重新连接操作，不冒充完成。英文只读缓存，中文首次成功合成后缓存，沿用现有ElevenLabs音色，不回退系统声。新增中文合成在服务端检查免费方案、剩余额度与禁用超额计费；未知或不足则拒绝，不发起合成、不预扣本地预算。没有新增API路由或持久化字段。
- 未配置或语音失败时显示真实提示，点击学习与跟练继续始终可用；跟练不计独立答对。可选聊天的成人代录保留，不制造识别成功。
- OAuth Codex负责家长词义/词性/配图思路补全与生图；学词和单词发音不依赖对话。回忆页三遍录音及跳过都只记跟练，不计独立答对；不识别或评测发音。

家长备课：只粘贴英文 → Codex建议中文、词性、配图思路 → 家长检查并确认词义 → 自动缓存发音、准备图片和配套游戏 → 审核图片并交给孩子。已有中英两列仍兼容。示例词表默认停用，仅可由家长显式开启体验。
- 家长空间与儿童页统一奶油/蓝/鼠尾草绿，主导航收为备课、学习记录、设置；默认只突出当前词表。新建时隐藏旧词表切换器，检查、修改、确认逐步呈现；草稿在内部切换页面时保留。缓存尚未读完显示“正在检查”，不把未知状态报成0。
- 素材卡单独显示发音缓存和图片准备进度，失败保留已有素材；图片备好进入审核。审核页选择和确认只授权所见版本，待审核图未选时引导选择；确认后同页显式交给孩子。部分交付入口显示实际可学词数，已启用词表新增图片批准后会明确提示加入学习，服务端音频门槛继续保留。
- 儿童不会因网络、麦克风或识别失败被判错；点击操作始终可用。
- 听辨、主动回忆、拼写分开记录；有提示和纯体验不晋级；复习间隔 1/3/7/14/30 天。
- 同一题的干扰图片保持相近风格，选项位置随机；不使用倒计时惩罚和连续签到损失。
- 图片与音频先备课缓存，儿童学习时不等待图片生成。
- 家长学习记录按词展示听辨、看图回忆、可选拼写的尝试与独立答对，并单列有提示答对、跟练/体验及到期时间；记录由现有数据计算，不推断掌握分数。“跨天独立答对”仅表示同一技能在多个日期有独立答对记录。

## 学习大厅、多轮与跨批调度（2026-10-17）

- 大厅提供推荐、图片自选与挑战；未完成轮次可逐轮恢复，开始其他词保留原检查点。完成页绑定明确的完成会话，主操作为再练一轮，另有选词、挑战本轮、奖章和返回大厅。
- 新词按词书createdAt、批内原顺序；跨批复习按到期时间和弱项优先，同优先级交错批次并打散。只从家长已交付的词中选取，保留原packId与历史；不会重新启用词书或示例。
- 每日新词推荐额度按上海日期累计首次接触时间；未完成新词预留也占额度。完成认识步骤记录实际接触时间，旧档案由有效版本答题/已完成认识步骤推导；手选新词可超推荐额度但仍累计。已停用示例不占正式词书额度。
- 推荐任务为空后改为已学词混合练习，优先较久未练和弱项，充足时避开刚完成一组；词少允许重复。所有手选重学与追加练习由服务端强制practiceOnly，不改变复习级别/日期；无正式听辨进度的首次短复习锚定初次接触，不能被反复练习延后。
- 手选每轮最多5词，按时长预算显示本轮可选数量并整组校验，超额拒绝而非截断；默认直接练习，旧词可选完整重新认识，未学词强制先认识。新轮次独立ID与随机种子，旧轮次不重新排题。
- 推荐短测优先到期能力；无到期能力时补齐已学词缺失的首次正式能力测试，初学次日起推荐。本轮可立即手动测，进行中/口头待核验及同日已测项目不重复推荐；不启动后台提醒、自动提交或云调用。
- AppState.activeSession只含选中的未完成会话；resumableSessions列出所有可恢复轮次，lastCompletedSession独立供结果展示；learningHistory为当前义项首次接触的派生摘要，learningNow为服务端时间。存储保留可选mode/practiceOnly/requestId/exposures及当前/最近完成会话指针；旧会话与备份兼容，不清空历史。

## 当前发音模式（2026-10-17）
- 麦克风打开失败区分网页拒绝、系统拦截、没有设备及设备不可用；网页授权granted不代表系统已允许。系统拦截时明确提示检查当前浏览器的系统授权，Codex部分安装包在Windows显示为ChatGPT，不再统一声称“麦克风还没打开”。只读查询网页授权，不修改网页/系统权限，不把失败记为录音成功。
- 当前正式默认聊天关闭，/api/chat/status返回disabled；对话生成/准备/取消/重置接口返回CHAT_DISABLED，不探测或预热对话。旧适配器只为维护与显式测试保留。
- 实时云端语音输入停用，自主挑战文件转写按上节单独授权；孩子点击喇叭听英文单词；跟读使用浏览器本地MediaRecorder，不需要新语音API或充值，TTS继续使用现有本机密钥、清晰英文和音频缓存。
- “自己说一说”：点击跟读按钮申请麦克风→示范播放结束→录音→孩子点“说完啦”收好→重复共3遍→完成跟读；每遍可回放。只检测是否录到声音，不判断词是否正确。每遍最多20秒，孩子可停顿；空录音不加次数。录音失败、拒绝权限、示范播放失败可重试或跳过。暂停/后台/离页立即释放麦克风，已保存录音在刷新/重启后恢复；离页释放临时录音与blob URL。
- 口头练习原音按用户要求仅提交到本机私有practice-recordings目录；普通备份只含PracticeRecording元数据，恢复后标missing。三遍完成用source=speech，跳过用source=click；均correct=false、practiceOnly=true，不创建或晋级回忆掌握进度。保存录音本身不创建LearningAttempt或推进步骤。
- 传送门、谁不见了、两词联想回想、先想再选，以及朗读/中译英复习，在揭晓/打开选项前提供录音；已有揭晓状态可补录练习，服务端标follow。录音区每环节最多3段，每段0.1–20秒；空音/格式错误不保存，保存失败保留本页待重试，上传UUID与内容哈希幂等。普通跟读仍为3遍。
- GET/POST /api/practice-recordings?sessionId&activityId（POST追加takeId，WAV正文）只允许当前口头活动及当前义项；GET /api/practice-recordings/:id/audio?sessionId&activityId提供当前题回放。无活动参数的历史列表/原音需要PIN产生的Bearer授权；不经公共/media提供，不交给STT/AI或写入掌握。
- 示例和正式词书的英文发音按各词实际缓存状态检查。维护脚本scripts/cache-word-audio.ts默认只检查，--apply仅补缺失项，通过同一本机TTS预算路径生成，失败即停止；缓存命中不新增合成请求；历史示例验证计数见归档。新词表或发音配置变化后可手动再运行。
- 跟读完成记practiceOnly，提示后不晋级。既有兴趣、单词、进度和费用不清空。

## 游戏化强化环节设计与实现（2026-10-17）

### 现状与目标

- 扩展设计见[五十种单词游戏玩法与随机安排方案](VOCABULARY_GAME_LIBRARY.md)。当前50种已实现；新会话按资格随机选择，不改变进行中会话。新增分三批在独立8803/8804/8805体验，不重启正式8787；素材与证据边界见本文五十种扩展及ACCEPTANCE。
- `wordGamePlan` 保留五类基础步骤；正式 `/api/session/start` 创建新会话时额外冻结 `activities` 与 `activityStates`，在原步骤上使用游戏呈现和跨词顺序。未带新字段的既有会话继续旧流程。原基础口头环节包含本地录音跟读控件；新传送门不用录音、不做识别或发音评分。
- 面向6–8岁零基础儿童，首批声音翻翻乐、基地补给、神秘传送门已实现；后续三种玩法仍未实现。以下规则区分实际行为和后续设计。
- 扩展第一批新增听词宾果、错配维修、词汇守门员、声音藏宝格、先听后看、谁不见了、先想再选。宾果/维修/藏宝格/先听后看/谁不见了只记练习；守门员与先想再选的客观部分按服务器题目判断，仅形成听辨证据。
- 扩展第二批新增连听排队、双目标收集、双向切换、局部揭秘、画词回忆、动作模仿秀、两词联想、我来出题、词义寻路、字母路径，均只记练习。连听/收集两目标对应两个原步骤和两条证据，整组提交及推进原子完成；孤余词回基础题且保留本轮已教选项。两词联想先在sound搭主词与伙伴场景，穿插其他任务后在recall提取圈出的主词，每步只要求一个目标词。
- 动作模仿只选动词；亲子出题由家长设置familyGamesEnabled开启，默认关闭；字母路径要求spellingEnabled开启及2–6字母词。画板草稿96格、配对选择、揭图区域、私人场景、亲子交接/猜测、字母轨迹与路线位置保存本地；口头环节原音仅保存至本机私有接口，无新增云端识别；动作和绘画不自动评分。
- 设计依据：[IES 学习与记忆实践指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)支持分散练习、图文结合和主动提取。具体小游戏及题量是本项目的设计推导，效果与适龄难度仍需孩子实际体验。

### 玩法与优先顺序

| 玩法 | 孩子的操作与反馈 | 练习目的 | 首版记录边界 |
| --- | --- | --- | --- |
| 声音翻翻乐（首批） | 2张图片与2张声音卡；翻声音卡听英文，再点对应图片。配对后两卡归位；熟悉后最多3对，每轮随机位置 | 在混合词中建立声音与图片联系，避免只配相同图片 | 卡片翻开和排除选项带来提示，整轮只记配对练习；不能因最后只剩一对记独立答对 |
| 基地补给（首批） | 大黄蜂需要一件补给，播放英文单词；从2–3张已学物品图中点选，再点运输车送达。操作先用手势示范，送达产生短动画 | 在一个有目的的小任务中辨认词义，隔题再遇见相同词 | 首次、无答案提示且有至少2个有效选项的选择可作为听辨；重试后的完成只记有提示或练习，不重复计证据 |
| 神秘传送门（首批） | 学过其他2–3个词或任务后，旧图再次出现，先不展示英文和答案声音；孩子尝试说，再主动点喇叭核对后通关 | 从即时模仿过渡到延迟回想，逐步减少提示 | 未经独立验证的口头回答、揭晓和自行勾选均只记练习，不制造口头掌握记录 |
| 易混侦探（后续） | 从实际误选过的已学词中选一组；听一个词，在两张清晰图片中辨认，换位置后在后面的任务再遇见 | 针对具体混淆安排对照，避免一直做容易的题 | 仍归听辨；一次误选只作为候选线索，不推断稳定混淆；同义、同图或有歧义的词不互作干扰项 |
| 动作模仿秀（后续） | 对 jump、run 等已确认动词，听单词、看动作图，起身做一下，再点继续；也可坐着用手势参与 | 把动作词和身体经验联系起来，提供短暂活动变化 | 系统不观察身体动作，只记参与；不能显示动作做对、发音合格或独立掌握 |
| 跨天寻宝（后续） | 用到期词组成2–3个短任务，换位置和任务外观，再寻找昨天或更早学过的词；新场景图片须另经家长审核 | 让游戏承接真实复习，检查离开当天流程后能否辨认 | 仅使用到期技能与当前学习版本；沿用1/3/7/14/30天规则，同日完成不同游戏不能重复晋级 |

### 每轮安排

- 不建立要求孩子读懂文字的游戏菜单；新词按2–3词一组串联补给/翻牌/传送门，声音入口有点击手势，图片均为大按钮。选项数量由实际有效词决定，不声称已实现自适应难度，也不按反应速度判定难度。
- 新词每组最多3个，先认识全部，再做听音辨认、声音联系、延迟回忆和已启用拼写。同一阶段使用同一种模板，每组最多3类，每轮最多引入1类未完成过的新交互；最近6个会话实际完成的玩法降低重复权重。补给限名词；listen若选中练习类游戏，sound保留客观选音题。复习不提前展示答案，listen/sound只选客观模板或保留基础题。
- 默认10分钟按现有预算最多13个原子步骤。游戏替换原有步骤，不增加题量：3个新词为3次认识、3次听辨、3次配对、3次传送门，共12步。到期复习继续优先占预算，不强行凑满时长；旧会话保持原计划，不中途插题。
- 可选 `activities` 固定跨词顺序、逐题ID、目标词义版本和图音选项快照，`gameSeed`固定抽选种子，守门员另外固定来访声音`cueWord`；`completedSteps`仍逐词保存原步骤。服务端按活动顺序推进，前端恢复用同一计划，不能因第二个词提前认识而跳回第一个词。
- 选图游戏可替换同技能、同证据标准的基础题；配对、动作和自主说词不能替代必要的独立听辨检查。多次选择按实际动作逐题占预算，不能将整轮游戏视为一步。
- 多词玩法至少需要2个义项清楚、图片不同且音频已缓存的可学词。不足时回到单词练习并如实记体验，不自动启用示例词或编造干扰词。补给只用于可表示物品的名词；动词、形容词和短语使用合适玩法或基础题，不强塞进运输车。
- 首批复用已批准图片和英文单词缓存，用本地布局与短动画构成场景；游戏朗读携带 `cacheOnly:true`，缓存缺失立即返回 `AUDIO_CACHE_MISSING`，不新增云调用或静默换系统声音。播放失败保留体验记录，不判能力错误。新图仍由家长审核。

### 正确性与实施验收

- 儿童通过点选、听音与可选动作完成；不用键盘，不把识字、拖拽精度、反应速度或麦克风权限设为通关条件。不设置惩罚倒计时、丢奖励或强制连续签到。
- 错误时温和反馈并允许重听；出现答案揭示、选项排除或错误后重试，就保留提示状态直至该题结束。听辨题播放目标英文是题目本身，不算答案提示；主动回忆题提前听到答案则算提示。
- 游戏完成、贴纸、听辨独立答对和口头回忆分别处理；现有 `Skill` 不增加“游戏掌握”。`LearningAttempt.activityId`关联逐词游戏证据，配对/回忆始终practiceOnly；补给按选项由服务端判断，不接收客户端自报correct。
- `POST /api/session/activity`接收 `{sessionId,activityId,action,selectedId?}`，基础action为listen/choose/reveal/skip/next/audio-failed/conceal/show-options/listen-option；第二批增加pick/undo/submit/uncover/draw/compare/finish/compose/hand-over/guess/letter。检查点保存已听、揭晓、提示、藏图、展开选项、已听声音选项、所选答案和结果；next与证据一起原子推进，重试幂等。通用答题/完成步骤接口不能绕过游戏。备份保留新字段、校验顺序和证据，旧备份兼容；词义/图片失效时移除陈旧目标，受影响选图退回有提示基础练习，不带入未批准素材。
- 当前游戏整体验证见[验收](ACCEPTANCE.md)，历史批次结果留在归档与任务证据。测试覆盖逐题完成、随机抽选、恢复/备份、素材不足回退、提示和音频失败；浏览器验证手机、短屏及整轮到奖励页。口头练习不产生recall掌握，同日重复客观听辨最多晋级一次；儿童本人体验仍需继续观察。

## 每日任务与针对性复习

- 同一dailyLearningPlan用于首页和服务端，筛选已启用且图片批准的词。现阶段只有听辨、可选拼写参与客观复习；已关闭的口头识别不触发自动口头测评。
- 新词完整steps为learn/listen/sound/recall，启用拼写且为字母单词时再加spell。复习词只包含已到期技能：听辨在listen/sound间变化，拼写仅在启用且到期时加入；不先展示答案。
- 小任务上限为floor(sessionMinutes*60/45)，每步45秒是初始题量估算，不是学习效率结论或强制作答时间。先安排不超过复习上限的旧词，再放得下的完整新词；不会为凑数截断新词流程。
- 到期词数量不超过复习上限时保留配置的新词上限；超过后按floor(新词上限*(2*复习上限-到期词数)/复习上限)减量，最低0，达到两倍暂停新词。家长显式关闭复习（上限0）时不应用积压减量，但仍有总任务预算。
- 新会话持久化tasks、completedSteps、taskLimit、estimatedMinutes，刷新/重启/备份按服务器计划恢复；每步对应同会话/词/题型的正确或练习证据，有提示可完成但不晋级。listen答案不能充当sound证据；重复提交不重复推进或发奖。
- 旧无tasks会话保留原词序和完成合同，不在中途重新排题。跨夜完成按完成日期计入当天，避免同日再开新任务。
- practiceOnly仅保存参与记录，不创建或修改SkillProgress。历史纯跟练进度保留但不当测评；只有练习、尚无听辨进度的词，根据最近尝试在至少一天后派生一项听辨检查，不虚构熟练程度。
- 编辑词义通过learningResetAt/learningVersion重置当前学习语义，旧尝试保留为历史，当前排程与同日晋级只使用当前版本；固定时间或同毫秒操作也可区分。
- 语音仍仅英文词条、clear与已有缓存，不恢复聊天、录音或发音评分。不会为本轮调度测试请求新语音/生图服务或充值。

## 家长指定词表与发音预备

- 示例WordPack.isSample=true，默认enabled=false；旧starter首次升级也默认停用，未完成示例会话增加suspendedAt并完整保留原词序、已完成词、尝试和进度，不伪造完成或贴纸。只有家长显式开启才体验示例。新正式词表由确认操作保存confirmedAt/isSample=false，预览不写数据、不合成。
- 词表支持tab/CSV/中文逗号/英文短语与中文间空格，每次最多500行；重复英文和多义项需先修正，坏引号/空列不允许确认。编辑粘贴内容立即让预览失效。
- 确认后保存词表再自动启动全局单个串行缓存任务。精确按英文/音色/模型/语速/clear键复用已有MP3，实际供应商请求owner才预留/结算；GET状态只读实际缓存，不保存伪ready，不自动恢复付费任务。准备可取消，重启后显式补缺；错误/额度/预算不足即停，保留成功文件和未知用量预留。
- 正式启用要求至少一个已批准图片的词，且该书所有已批准词均已缓存发音；可以先启用已备好子集。未准备图片继续待备课；Codex新图必须家长确认，占位图不能批准或被称作内置插画。已启用书的新图片批准也先检查当前英文发音。
- 同义同英文可复用现有内置插画和英文发音，不把整本12词示例混入正式词表。题目干扰项去除同英文/同图重复；不足两个有效选项只记practiceOnly，不计独立听辨。
- 语音仅英文词条，不开启聊天/录音/评分。仅使用现有ElevenLabs免费额度，不充值或自动升级；页面不能声称已读到实时供应商剩余额度，使用实际请求错误反馈。

## 英文导入与 Codex 备课草稿

- 默认只填英文，兼容原中英两列；preview仅解析，不猜词义。enrich通过官方OAuth、受限无工具权限、ephemeral文本任务，每批20词，输出严格同序英文、一个中文义项、词性、配图说明和多义提示；不识别的词保留空义项并提示，不能确认。
- 补全任务进程内最多8份、全局一个运行任务；支持查看、停止、失败后补缺，保留先前完成批次。草稿不是正式事实层；新版确认要求全部词义/词性/配图说明完整。内部导航保留草稿，刷新或退出不保证恢复。
- ImportRow/Word新增可选partOfSpeech/pictureHint/usageNote，备份兼容旧词。词义/词性变动清除旧配图说明并使图片及学习版本失效，旧记录保留；图片任务同时绑定词性和配图说明版本，旧任务不能覆盖新语义。
- 生图使用审核后的义项、词性、场景及已有兴趣；游戏由固定安全模板绑定该词图音，动词与形容词认识页按词性提示。听音选图/看图找声音/自行跟练、可选纯字母拼搭自动配齐；相同中文义项不互作听辨干扰项，选项不足仍只记体验。儿童只听英文词条，不开启聊天/输入。

## 自动图片准备与批量审核

- 家长确认词表就是按现有服务准备音图的明确操作，创建成功后分别启动发音和图片队列；某项失败不能回滚已保存词表。仅缺图draft/error进入Codex队列，同义内置approved图可复用；review/approved不被自动补缺覆盖。跨书全局串行，重复start幂等，生成失败停止当前书但不丢成功图；GET和服务重启不自动发新生成请求。
- 自动生图在官方OAuth配置检查后通过既有单词job路径发起，等待真实终态。取消在配置探测、排队或生成期间均阻止迟到派发/结果写入；账号/额度错误不充值、不切换供应商。素材仅隔离目录写入，现有受限word_assets权限、最小环境与ephemeral线程维持。
- PackImageStatus报告queued/running/review/ready/stopped/error、approved/reviewing/pending/failed和当前词。词义/学习版本/兴趣快照变化时停止旧批次；图片审批和词书标签变化不会误停其余缺图任务。
- 家长按书每页24张预览，可放大、单选或全选本页已经成功加载的待审图。ImageReviewSelection明确wordId、imageUrl、term、meaning、learningVersion，服务端一次事务检查所有条目；有任何过时/跨书/占位/失效则整批拒绝，没有隐式approveAll。undefined学习版本仅与0等价；已批准的同一快照重提幂等。
- 图片加载失败、重画、词义/URI/version变化清理对应旧选择，跨书/分页清理选择。批准不自动启用；已启用词书增加批准词仍须当前发音缓存就绪。纯单词发音和示例隔离保持。

## 五十种随机游戏与额外素材

- 注册表现有50种。新增30种与既有原子学习步骤对齐；新增均只记练习，不把录到声音、结构操作或路径完成算独立掌握。仍保留每词客观听辨检查；每组最多3类、每新会话最多引入1种未完成过的新机制。拼写开启时轮换基础回想/拼写界面，保护所选新机制不被固定挤掉。
- Word.gameMaterials存父母确认的关系、异图、部件、动作、熟悉短句与答案。记录义项版本、关联词版本、审核时间；不从儿童输入临时生成。开局只检查批准图片和题目音频缓存，缺失回基础题。字母模板按2–6字母词筛选。亲子、contextGamesEnabled进阶情境及拼写默认关闭。
- LearningActivity冻结material、spellingBoard及两目标快照；ActivityState保存选取、放置、阶段、输入字母、箱子位置与可验证移动轨迹。故事、编程、双词组合、数量订单及双词分料各消费两个原子步骤，整组一致恢复，重试不重复写证据。
- 家长空间学习记录提供素材预览与明确审核。POST /api/words/:id/game-materials/:kind要求家长授权、approve:true、完整material；先校验所见义项、素材及缓存，再保存。POST同一路径/prepare仅在家长明确预览确认后准备缺少讲解：已有缓存复用，新增限ElevenLabs freeOnly及预算护栏，不足停止；不自动批准。
- 无声哑剧、听线索猜词、口头补空、双人信息差统一复用私有口头练习录音。界面先准备线索，再录音或明确跳过，然后揭晓。亲子已听声音选项后的录音保守归为跟练。录音遵循当前活动和选中会话，支持恢复旧轮次，不调用识别或自动打分。
- 示例与验收详见VOCABULARY_GAME_LIBRARY、GAME_MATERIALS及ACCEPTANCE。源码集成与独立体验不等同于已更新运行中的8787或重新制作项目ZIP；正式服务和项目包有独立交付记录。
