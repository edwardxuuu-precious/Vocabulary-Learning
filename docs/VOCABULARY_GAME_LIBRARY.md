# 五十种单词游戏玩法与随机安排方案

本方案面向6–8岁中文母语、英语零基础孩子，把家长确认的词放进不同操作中反复辨认和回想。共50种候选玩法，分为听音配对、词义辨别、主动回忆、情境运用、字母拼写五组。它们共用听辨、词义理解、提取与拼写等学习目标，不代表50种独立的记忆理论。

已实现全部50种，分批增加剩余30种：第三批为11、13–20、25，第四批为27、28、31–37、39，第五批为40、42–50。正式新会话只从符合条件的模板中随机选择；旧会话保持冻结安排。关系、异图、短句和动作先由家长审核，题目发音先缓存；素材不足回基础题，不临时捏造关系。亲子、进阶情境及拼写默认关闭，新增30种均只记练习，不直接提升掌握。

独立体验：[第三批30种](http://127.0.0.1:8803/__qa)、[第四批40种](http://127.0.0.1:8804/__qa)、[第五批50种](http://127.0.0.1:8805/__qa)。使用示例材料与本机离线示例讲解，正式词书仍须家长确认。录音保存在各自独立档案；旧8795不重置。

## 玩法的区分标准

每种玩法说明孩子接收什么线索、怎样操作、需要记住什么、用什么规则结束。只换角色、背景、奖励、车船或按钮外观，归为同一玩法的皮肤。候选表中的复合玩法必须保留其操作差异；开发时若删去差异、只剩普通选图，应合并模板，不能继续计为不同机制。

之前提过的“跨天寻宝”作为到期词的任务编排容器，可以使用下表中的多种机制，不单独凑入50种操作玩法；易混侦探和动作模仿秀分别归入14与24。

素材条件中，“现有图音”指家长已批准的图片与缓存发音；“补素材”指需要家长审核的关系、额外图片、动画、线索或短句；“进阶”指孩子具备相应词汇或字母基础，且家长开启对应功能后才能进入候选池。素材不足、未确认或阶段未开启的玩法不进入儿童随机池。

## 随机安排规则

先确定“今天哪些词需要练哪项技能”，再选择玩法。儿童不需要在50个菜单中挑选；家长将来可在备课侧查看该词实际可用的玩法数和缺少的素材。

1. **只抽已实现的玩法。** 同时检查目标技能、词性、孩子阶段、最少词数、图片与音频准备、语义关系和拼写开关。未实现、素材不足或未批准的项目权重为0；不会随机调用生图或付费服务。
2. **到期复习优先。** 沿用已有到期顺序和题量上限。复习sound仍需要能形成对应独立听辨证据的题；翻牌、绘画或动作体验不能顶替这项检查。口头活动不能凭按钮自行写入独立掌握。
3. **先保留学习方向，再随机操作。** 同一词在不同天可换玩法，在新一轮改变位置和干扰项；当天正在进行的题保持同一快照。不能把增加规则、陌生英语或缩短时间当作随机难度。
4. **降低近期重复。** 当前按最近6个会话实际完成的玩法降低重复权重；未完成的计划不算熟悉经历。逐词经历权重仍待扩展，候选不足时正常复用。
5. **限制每轮变化。** 当前每组新词最多3类游戏，每个新会话最多引入1种未完成过的新机制；已有三种视为基础交互。开启拼写时保留选中的新机制，轮换由回想或拼写使用基础界面，不固定排除回想。数量是待体验调整的产品初值，不是研究确定的最优值。跨日熟悉度和无字动画示范仍需继续完善。
6. **逐步计入预算。** 宾果4格、双词分料、连听两词等按实际目标与判断拆成小步骤，不能将整盘算一次。到期复习占预算后减少新词或游戏；不强迫玩满50种，不因跳过失去奖励。
7. **保存抽选结果。** 创建会话时固定玩法、词义版本、素材版本、随机种子、选项、题目顺序与目标数；提示、错选、音频失败和完成状态持久化。刷新和重启不重新抽题，重复提交不重复晋级或发奖。
8. **没有合适玩法就回基础题。** 使用已确认的同一词练习；不启用示例凑数，不临时捏造同义词、反义词、分类关系或句子答案。只有一个有效选项时只记体验。素材格式和家长审核步骤见[游戏素材](GAME_MATERIALS.md)。

实际注册表`shared/game-registry.ts`包含50个有界面与服务器规则的模板，保存编号、技能、词数、词性、亲子限制与练习边界；`shared/game-rules.ts`、`shared/game-batch-two.ts`及`shared/game-extended-rules.ts`统一逐步核对。多目标一次操作对应两条逐词证据和两个步骤；两词联想每个步骤只要求主词。每词保留客观听辨检查；练习类游戏占listen时，sound保留客观题。加入拼写后仍最多3类游戏，必要时基础回忆替换传送门。额外素材通过版本化审核，冻结在活动快照；声音、图片或关系不足时不进入新会话。

## 研究依据与适用范围

[IES 学习与记忆实践指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)支持间隔安排、图示与语言结合以及主动提取。[IES 英语学习者教学指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/19)建议用多种教学活动，跨数天反复练习一组重点词汇。这些原则支持“同一批词多次再现、改变任务、保留回忆机会”的方向；具体50种玩法、每轮3类和每天新增1类是本项目的设计推导，未逐一经过效果研究。进阶指南中的学术词汇情境也不等同于本项目零基础孩子的当前能力。
