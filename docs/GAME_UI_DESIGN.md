# 游戏界面与体验工具

本轮针对儿童操作区拥挤调整层级与留白，保留机甲伙伴、词义图片和场景。视觉调整不改变题目快照、证据判定或复习级别。

## 官方参考与采用方式

| 参考 | 已核对的设计说明 | 本项目采用方式 |
| --- | --- | --- |
| [Duolingo：核心页面设计复盘](https://blog.duolingo.com/core-tabs-redesign/) | 统一标题、字体层级和间距，留白服务内容，容器有选择地使用 | 游戏名降为辅助标题，当前任务突出；收起测试控件；统一底部操作位置 |
| [Pok Pok 官网](https://www.playpokpok.com/)及[Apple Design Awards 官方介绍](https://www.apple.com/ca/newsroom/2021/06/apple-announces-winners-of-the-2021-apple-design-awards/) | 低刺激的儿童探索环境、平静的声音与画面、清楚的互动反馈 | 减少手指动画、多层阴影和重复按钮；听音与答题分区，保持大触摸目标 |

以上是本项目的设计取舍，不复用第三方素材，也不把参考产品介绍当作背词效果证据。

## 页面规则

- 新建学习入口的分段轮次冻结`guidanceVersion=1`，先按词义和目标选择听音配对、双词听序/收集及已审核语义任务；走格、切图、揭局部等保留主动入口，具体取舍见[学习环节](LEARNING_FLOW.md)；基础题继续承担必要客观检查。已有题面/次序不改写，按书主动游戏保留完整目录。
- 基础听图、听选、回忆及朗读直接显示主操作和真实状态，不自动弹示意、困难或设备说明；帮助在顶部导航内，避免遮挡伙伴和进度。其他游戏第一次遇到尚未看过的操作，保留三步抽象图形示意；不读取本题词语、配图、线索或答案，不播放词音、不调用麦克风。点“回到这题”仅记看过操作，不宣称会玩，后续轮复用已确认状态。
- 操作求助和词汇求助分开：前者只留`guidance`元数据；“看看意思/听示范”沿用题目原提示事实与口头权限。回忆仍先隐藏英文，朗读仍先保存录音；没有新正确、晋级或正式成绩。
- 其他游戏同题两次有效错误后主动给有限支持：看玩法→回题尝试，或跳过/保存休息；基础题在题面反馈并保留帮助与跳过。无效操作请求不当词汇错误；声音不可用给重试/跳过/休息，主动静音明确显示关闭。支持面板不自动选答案或无限重播，跳过不冒充答对。
- 引导打开时停止正在播放/录音并阻止题面操作，关闭回原题；更新失败保留面板及重试/休息。键盘取消也须保存看过状态；本机观察将引导区间列为暂停，不能当家长指挥或词汇错误。

### 玩法目标与操作负担

此目录用于解释默认范围，不代表孩子已经理解；实际指挥次数、误操作和求助仍按A03/A04观察。完整映射真源为`shared/learning-guidance.ts`，素材条件仍见[机制库](VOCABULARY_GAME_LIBRARY.md)。

| 操作族 | 学习目标 | 额外操作负担 | 当前采用 |
| --- | --- | --- | --- |
| 听后点图、看词点图 | 声音/词形与含义联系 | 低：听/看→点→继续 | 默认主线；认词不先播放答案 |
| 一对/不是一对 | 比较词或声音与图片 | 低：分别示意勾与叉 | 默认主线，不以单次二选一当掌握 |
| 看图选声音 | 客观听辨 | 低：播放与选择分别点 | 基础检查/双向切换 |
| 自己说、保存、继续 | 朗读/主动回忆参与 | 低：麦克风→停止→继续 | 默认主线；玩具示意不录音，实际原音仍须真实保存 |
| 记位置、顺序、移动、拼装/交换 | 空间记忆、序列或字母等额外要求 | 中：记忆/撤回/检查等更多步骤 | 主动游戏保留；不作为新学习默认切换 |
| 自由绘画、亲子猜测/信息差 | 表达与互动探索 | 高：自由操作或家人参与 | 仅显式选择/原条件开启，不用于自主主线默认路径 |

- 游戏名与伙伴为辅助信息，当前操作提示为主标题。50种玩法共用跳过、阶段确认、继续栏；满足条件才出现确认。
- 新词固定认/听/读，儿童页只显示当前小段进度，认听读证据继续独立保存；读词只显示英文，保存原音后才开放图片与示范。已录待核验、跳过与已完成分别显示；认词不先播放答案。桌面与390px手机保持大触摸区域，进度计数不换行，完成后只保留回放与继续。
- 连听排队、双目标收集：宽屏左侧听音、右侧答题；窄屏纵向展开，保留独立槽位和候选图区。撤回不会挤动布局。
- 底部操作区为内容预留空间；窄屏与矮屏单独适配。绘画和棋盘等专用结构保留其区别。
- 认识、基础题、认听读与全部游戏共用 `LearningTopbar`，进度显示已完成小任务数；旧会话无任务计划时按已完成词数显示。顶部保留回学习大厅和休息；返回保留进度。任务轻色卡片、留白和紫色主操作与大厅统一，休息使用原生模态窗口。
- 自动讲解只展示当前阶段，不重复显示五阶段圆点；英文、词义、图片的原有出现顺序不变。图片区域提前预留但不提前揭示，原图完整圆角显示；音频失败就近反馈。基础听选依次自动播放原选项并同步亮起，听完才开放单击作答，重听单独提供，不再暂选/再次确认；手机缩小词图，跳过保持单行。朗读首次明确开启本次麦克风、已授权后后续词直接听，显示实际音量，停顿后尝试自动收音；保留手动结束、回听、再读和成功保存后继续，不伪造评分。
- 回忆/朗读录音保存后点击一次继续，先持久化参与结果，再进入下一题；可先回放或重录。明确跳过直接接题，保存失败或暂停/离页不继续连跳，正常答题仍保留反馈与继续。小段停点不发整轮奖，休息后从大厅继续不重复确认。
- 学习完成页突出实际完成词数、最多三张原词图、显式开始测试与休息出口；未学完短句则继续学习，不显示“开始测试”。过程只记真实参与，不以练完宣称掌握，不自动续开测试或下一轮。
- `__qa` 的选择器和说明是临时体验工具，默认折叠为“体验设置”。开关设置不重置进度；明确点“开始新的体验”才重置隔离档案。
- “第二批20种”不作为正式儿童导航。50种已实现游戏在主动目录保留，自动学习按语言目标及已审核材料选择适配方式。

## 本地体验

```powershell
npm.cmd run build -- --outDir artifacts/game-ui-dist
node --import tsx scripts/game-library-qa.ts --serve --batch=2 --port=8795 --dist=artifacts/game-ui-dist
```

打开 `http://127.0.0.1:8795/__qa`。升级同一独立体验用 `--resume-data=artifacts/原体验目录` 续用数据库、原音与体验工具令牌，启动不跑会重置档案的夹具；仅允许项目artifacts内现有目录。`--restore`只用于导入普通备份，原音不随备份恢复，不能代替整个目录的续用。

体验只复用已有英文缓存，不写正式孩子记录，不新增云调用、密钥或付费配置。中文讲解缺少缓存时如实提示并自动继续画面。

新增三批入口为8803/8804/8805，对应30/40/50种；构建分别位于artifacts/games-batch3/4/5-dist。开发用的Windows离线图示与配音只进入独立体验目录，不替换正式配音。宽屏口头线索与录音分两区，手机纵向；拼写键盘与6×6推箱盘保留底部操作区空间。新玩法都提供图示或可听说明，音频失败保持真实提示与跳过。
