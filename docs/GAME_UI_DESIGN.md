# 游戏界面与体验工具（2026-10-17）

本轮针对儿童操作区拥挤调整层级与留白，保留机甲伙伴、词义图片和场景。视觉调整不改变题目快照、证据判定或复习级别。

## 官方参考与采用方式

| 参考 | 已核对的设计说明 | 本项目采用方式 |
| --- | --- | --- |
| [Duolingo：核心页面设计复盘](https://blog.duolingo.com/core-tabs-redesign/) | 统一标题、字体层级和间距，留白服务内容，容器有选择地使用 | 游戏名降为辅助标题，当前任务突出；收起测试控件；统一底部操作位置 |
| [Pok Pok 官网](https://www.playpokpok.com/)及[Apple Design Awards 官方介绍](https://www.apple.com/ca/newsroom/2021/06/apple-announces-winners-of-the-2021-apple-design-awards/) | 低刺激的儿童探索环境、平静的声音与画面、清楚的互动反馈 | 减少手指动画、多层阴影和重复按钮；听音与答题分区，保持大触摸目标 |

以上是本项目的设计取舍，不复用第三方素材，也不把参考产品介绍当作背词效果证据。

## 页面规则

- 游戏名与伙伴为辅助信息，当前操作提示为主标题。50种玩法共用跳过、阶段确认、继续栏；满足条件才出现确认。
- 新词固定认/听/读，认词和读词页显示三项目标状态；读词只显示英文，保存原音后才开放图片与示范。已录待核验、跳过与已完成分别显示；认词不先播放答案。桌面与390px手机保持大触摸区域，进度计数不换行，完成后只保留回放与继续。
- 连听排队、双目标收集：宽屏左侧听音、右侧答题；窄屏纵向展开，保留独立槽位和候选图区。撤回不会挤动布局。
- 底部操作区为内容预留空间；窄屏与矮屏单独适配。绘画和棋盘等专用结构保留其区别。
- `__qa` 的选择器和说明是临时体验工具，默认折叠为“体验设置”。开关设置不重置进度；明确点“开始新的体验”才重置隔离档案。
- “第二批20种”不作为正式儿童导航。50种已实现游戏保留，按单词、已审核素材和家长设置进入随机学习。

## 本地体验

```powershell
npm.cmd run build -- --outDir artifacts/game-ui-dist
node --import tsx scripts/game-library-qa.ts --serve --batch=2 --port=8795 --dist=artifacts/game-ui-dist
```

打开 `http://127.0.0.1:8795/__qa`。升级同一独立体验用 `--resume-data=artifacts/原体验目录` 续用数据库、原音与体验工具令牌，启动不跑会重置档案的夹具；仅允许项目artifacts内现有目录。`--restore`只用于导入普通备份，原音不随备份恢复，不能代替整个目录的续用。

体验只复用已有英文缓存，不写正式孩子记录，不新增云调用、密钥或付费配置。中文讲解缺少缓存时可点击继续。

新增三批入口为8803/8804/8805，对应30/40/50种；构建分别位于artifacts/games-batch3/4/5-dist。开发用的Windows离线图示与配音只进入独立体验目录，不替换正式配音。宽屏口头线索与录音分两区，手机纵向；拼写键盘与6×6推箱盘保留底部操作区空间。新玩法都提供图示或可听说明，音频失败保持真实提示与跳过。
